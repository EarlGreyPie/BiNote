# マビノギモバイル 楽器の音色境界 実測レポート

[한국어](timbre-boundaries.md) · 日本語

2026-11-28 · EarlGreyPie · 自作DLS v0.5基準 · 非公式ファン制作資料

## 概要

マビノギモバイルの音程のある楽器13種は、音域を3-5個の区間に分け、区間ごとに別のサンプルを使っています。その境界は楽器によって異なります。このレポートは、ゲーム内で実際に演奏した音を半音単位で測定して確定した境界値(ゲームの録音を測定して作った自作の分析用DLS v0.5の区間値、2026-11-01確定)をまとめたものです。

- ピアノ、ハープ、フォークギター、ハーモニカは o3e・o4e・o5f・o6f で切り替わります。リュートとマンドリンは o3e・o4e・o5f までです。
- 蓄音機、シロフォン、オルゴールは中間の境界が o4f・o5g で、半音ずつ高くなっています。
- バイオリン(o4c・o4f+・o5c+)、フルート(o5d+・o6d+)、シャリュモー(o3g・o4a・o5a+)、猫ハーモニカ(o5g・o5b)は、それぞれ別の位置で切り替わります。
- 全音間隔だけで聴いて決めた境界は、半音高くずれやすくなります。今回の測定では、そのような箇所が11か所見つかりました。
- 大太鼓とシンバルは、音程に関係なく同じ音が鳴ります。

## 音色境界とは

ゲームは楽器ごとに録音されたサンプルを数個だけ持ち、1つのサンプルを速く、または遅く再生して区間内のすべての音を鳴らします。区間が変わる音では別のサンプルに移るため、音色、音の長さ、減衰の速さが同時に変わります。この音を「音色境界」と呼びます。

楽譜を作るときには、次の3点が変わります。

- **音の長さ**: サンプルにはループ区間がなく、一度鳴って終わります。フルートやバイオリンのような持続音の楽器でも、サンプルが終わると音が切れます。同じ区間の中では半音上がるごとに長さが約0.94倍(2^(-1/12))に短くなり、境界の音で再び長くなります。
- **&(スラー)**: 異なる音を&でつなぐと、再発音せずに音程だけが変わります。つないだ音が境界をまたぐと新しい区間のサンプルに乗り換えるため、音色が跳ねます。
- **旋律の音色**: 境界をまたぐ旋律は、同じ音量で書いても境界の両側で明るさと響きが違って聞こえます。フォークギターは o5e までは20dB減衰するのに3.7-3.9秒かかりますが、o5f からは1秒以内に減衰します。

## &の動作

マビノギモバイルは異なる音の間の&も受け付け、再発音せずに音程だけを変えます。音楽用語ではタイよりスラーに近い動作です。音色境界に関係する規則は次のとおりで、すべてゲームの録音で確認しました。

| 書き方 | ゲームで鳴る音 |
| --- | --- |
| 同じ音 `c&c` (タイ) | 再発音せずに続きます。&の後の v(音量)は無視されます |
| 異なる音 `c&d` (スラー) | 再発音せず、&の位置で音程だけがすぐに変わります(グライドはしません)。1オクターブ差まで確認 |
| 境界をまたぐスラー `o4d+&e` | 新しい区間のサンプルに乗り換えますが、サンプル内の再生位置は引き継ぎます。そのため再発音の音はなく、音色だけが変わります |
| 長い&の連鎖 | 最初の音を鳴らした時点から、サンプルの長さ分だけ鳴ります。ピアノ o4c は20秒つないでも3.3秒で終わります |
| 休符の前の& `a4&r4` | 無視されます。`a4r4` と長さも音量も同じです |

境界をまたぐスラーを避けるには、つなぐ2音が同じ区間にあるかを下の表で確認してください。

## 測定方法

楽器ごとに半音階で境界の候補を探し、境界の両側の音を6秒ずつ鳴らして確定しました。ゲーム内で下の楽譜を実際に演奏して録音し、音域全体(o1e-o7e)を半音単位で漏れなく調べました。

1. **半音階**: 1音0.6秒で、間に休符を入れます。音域の狭い楽器はその音域から始めます。

   ```
   MML@t150v12l4o2er8fr8f+r8gr8g+r8ar8a+r8br8o3cr8c+r8dr8d+r8er8fr8f+r8gr8g+r8ar8a+r8br8o4cr8c+r8dr8d+r8er8fr8f+r8gr8g+r8ar8a+r8br8o5cr8c+r8dr8d+r8er8fr8f+r8gr8g+r8ar8a+r8br8o6cr8c+r8dr8d+r8er8fr8f+r8;
   ```

   両端の音域(o1e-o2d+、o6g-o7e)も同じ方法で別に録音しました。
2. **境界の両側の6秒音**: 候補ごとに、境界のすぐ下の音と境界の音を両方鳴らします。たとえば候補が o4f と o5g なら、次のように書きます。

   ```
   MML@t40v12l1o4eff+o5f+gg+;
   ```
3. **判定**: 隣り合う2音を比べ、次のどれかが跳ねたらサンプルが変わったと判断します。

| 基準 | 同じサンプルの場合 | サンプルが変わる場合 |
| --- | --- | --- |
| 倍音の形の差 | 0-2dB | 6-25dB |
| 6秒音の長さ | 半音上が約0.94倍に短くなる | 境界の音で再び長くなる |
| 音程の誤差(セント)、減衰の傾き、音量 | 滑らかに続く | 同時に跳ねる |

倍音がほとんどないシロフォンとオルゴールは3番目の基準で判断しました。音色がまったく変わらない境界(シャリュモー o3g)は、6秒音の長さにだけ現れます。

## 楽器別の音色境界

表の音は新しい区間が始まる音で、かっこ内はMIDIノート番号です。その音から上のサンプルが使われ、すぐ下の半音までは下のサンプルが使われます。

| 楽器 | 区間が始まる音 | 全音間隔で測ると出る値 | 根拠 |
| --- | --- | --- | --- |
| ピアノ | o3e・o4e・o5f・o6f (52・64・77・89) | 同じ | 倍音の差 14.8・14.5・20.7dB |
| リュート、マンドリン | o3e・o4e・o5f (52・64・77) | 同じ | 倍音の差 10-19dB |
| ハープ、フォークギター、ハーモニカ | o3e・o4e・o5f・o6f (52・64・77・89) | 同じ | 倍音の差 5-20dB、隣の音は1dB前後 |
| 蓄音機 | o3e・o4f・o5g・o6f (52・65・79・89) | 中間の2つが 66・80 | 6秒音の長さと倍音 |
| バイオリン | o4c・o4f+・o5c+ (60・66・73) | 一番上が 74 | o5c から o5c+ で 12.9dB、o5c+ から o5d で 0.0dB |
| フルート | o5d+・o6d+ (75・87) | 76・88 | 倍音の差 10.9・6.8dB、6秒音は o5d 1.51秒から o5d+ 5.71秒 |
| シャリュモー | o3g・o4a・o5a+ (55・69・82) | 下の2つが 56・70 | o3g は長さでのみ判別: o3g 5.42秒、o3g+ 5.11秒 |
| シロフォン | o3e・o4f・o5g (52・65・79) | 上の2つが 66・80 | 倍音の差 11.1・10.0dB、セント誤差も同時に跳ねる |
| オルゴール | o3e・o4f・o5g・o6f (52・65・79・89) | 中間の2つが 66・80、一番上が 90 | 音量 +11.6dB、減衰の傾きの変化 |
| 猫ハーモニカ | o5g・o5b (79・83) | 80・84 | 6秒音の長さ: o5f+ 0.39秒から o5g 0.47秒、o5a+ 0.40秒から o5b 0.46秒 |

両端の音域(o1e-o2d+、o6g-o7e)には、どの楽器にも表以外の境界はありません。シャリュモーは o2f と o2f+ が同じサンプルで、猫ハーモニカの o5c(72)は境界ではありません。

全音間隔(偶数のMIDIノート)だけで録音すると、境界のすぐ下の奇数の音を聴けないため、その上の偶数の音が境界として扱われてしまいます。3列目がそのようにずれた値で、すべて実際より半音高くなっています。サウンドパックや資料によってはこの値が使われていることがあり、試聴とゲームの音が境界付近の1音で異なる場合があります。

## 区間ごとのサンプル長

サンプルの長さはほとんどが4.3-5.8秒で、音符をどれだけ長く書いてもこの長さで音が終わります。表は各区間の最初の音を鳴らしたときに音が鳴る時間(秒)です。同じ区間のほかの音は、半音上がるごとに約0.94倍として計算すると、実測と0.1秒以内で一致します。

| --- | --- | --- |
| ピアノ | 5.31 (o2e) | 5.30 ・ 5.29 ・ 5.04 ・ 4.99 |
| リュート | 5.80 (o2d) | 4.80 ・ 5.24 ・ 4.86 |
| マンドリン | 5.67 (o2d) | 5.13 ・ 4.98 ・ 4.94 |
| ハープ | 5.26 (o2e) | 5.23 ・ 5.02 ・ 4.33 ・ 4.40 |
| フォークギター | 5.26 (o2e) | 5.26 ・ 5.27 ・ 4.44 ・ 4.67 |
| ハーモニカ | 5.25 (o2e) | 5.28 ・ 5.27 ・ 4.97 ・ 4.99 |
| 蓄音機 | 5.33 (o2e) | 5.33 ・ 5.02 ・ 4.47 ・ 5.02 |
| バイオリン | 5.49 (o3d) | 4.58 ・ 4.90 ・ 4.71 |

猫ハーモニカはサンプルが0.4-0.7秒ととても短く、長い音を出せません。

## 音域、折り返し、打楽器

音域外の音は無音になるのではなく、オクターブ単位で折り返されて音域内の音として鳴ります。

| 楽器 | 音が鳴る音域 | 備考 |
| --- | --- | --- |
| ピアノ、リュート、ハープ、フォークギター、バイオリン、ハーモニカ、オルゴール、蓄音機 | o1e-o7e (28-100) | オルゴールと蓄音機は1つの楽譜で3トラックだけ鳴ります |
| マンドリン | o1f-o7e (29-100) |  |
| フルート、シャリュモー | o2f-o7e (41-100) |  |
| 猫ハーモニカ | o4a-o7e (69-100) |  |
| シロフォン | o1e-o7e (28-100) | 書いた音より1オクターブ上で聞こえます |

大太鼓とシンバルは、どの音程で書いても同じ音が鳴ります。o1e から o7e まで全音間隔の37音を鳴らすと、6オクターブを通して周波数のピークが同じ位置にあり、長さも同じです(大太鼓 1.03-1.06秒、シンバル 2.08-2.14秒)。ゲームは鳴らすたびに、数個のサンプル(シンバル3個、大太鼓4個)の中から1つを音程に関係なく選んで使います。

## 判定で間違えやすい点

測定の途中で境界のように見えたものの、後で違うと分かったものが4つあります。同じ測定を試す方は、先にこの表をご覧ください。

| 境界のように見えたもの | 原因 | 訂正の根拠 |
| --- | --- | --- |
| シロフォン o6f(89) | 画面録画(mp4)の圧縮が第7倍音(約19.6kHz)を削った | セント誤差と減衰が連続しており、無圧縮の録音では現れない |
| o6a・o7c・o7e 付近の小さな跳ね | 分析に使う倍音の数が周波数の上限(10kHz)にかかって変わった | 音程、減衰、音量はそのまま |
| シャリュモー o2f が別サンプル | 16分音符で鳴らしたため、前の音の余韻が混ざった | 6秒音では o2f と o2f+ が同じサンプル |
| 猫ハーモニカ o5c(72) | 短い音ではセントの推定が不安定になる | 6秒音の長さが半音ごとに0.94倍で連続している |

まとめると、次の3点を守れば大丈夫です。

1. 先に半音階を録音し、長い音は境界の両側を鳴らします。偶数の音だけだと半音ずれます。
2. 短い音で境界を決めないでください。前の音の余韻が混ざり、音程の推定も不安定になります。
3. 圧縮された動画で高い倍音が1つだけ跳ねた場合は、セント、減衰、無圧縮の録音で再確認します。ゲームの音はモノラルで、12kHzより上の成分はありません。

## 制限とお知らせ

- この資料は非公式のファン制作資料であり、ゲームの運営会社とは関係ありません。ゲームのファイルを解析したものではなく、ゲームで演奏した音を録音して外側から測定した値です。
- 録音の原本と、それをもとに作った自作DLSは、ゲームの音が含まれているため公開しません。このレポートには数値と測定用の楽譜だけを載せています。
- 測定時期は2026年10月14日から11月2日までです。ゲームのアップデートでサンプルが変わると、値も変わる可能性があります。
- 対象はマビノギモバイル(韓国版)です。PC版マビノギは測定していません。
- 同じ音が鳴るスキン楽器は個別に測定していません。新しい楽器が追加された場合は、上の測定方法で測り直す必要があります。
- サンプル長は、音の終わりを判定する基準によって0.05秒ほど変わります。猫ハーモニカはサンプルが短いため、この差が大きく見えます(0.42秒または0.47秒)。
- 楽器名は韓国語版の名称を訳したもので、日本語版の正式名称と異なる場合があります。
