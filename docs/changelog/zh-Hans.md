# 更新记录

BiNote 各版本的变更内容（从 1.0.0 起）。更早的版本（beta、rc）只有韩文，在 [CHANGELOG.md](../../CHANGELOG.md)。新版本在重新打开应用后生效。当前版本可以在设置最下方或 ? → 关于 BiNote 中查看。

## 1.1.0-beta.1 (2026-11-28)

这是 1.1 的第一个 beta。只在 beta 页面（beta.binote.pages.dev）发布。在 1.0.0 的全部内容之上，加入了为 1.1 新做的功能。新功能大多在 **实验室** 中，一开始是关闭的，不开启的话就和 1.0.0 一样使用。beta 页面和正式页面的存储空间是分开的，乐曲和音色包彼此看不到。要迁移时，请先保存为项目（.mme）文件，再重新打开。

PC 版玛奇支持（切换游戏）还需完善，将在 1.1.0-beta.2 加入。本次测试版中不显示。

### 加入实验室的功能
- **五线谱视图**：在钢琴卷帘、指法谱旁边加入五线谱视图。按栏宽像乐谱一样换行绘制，并遵循乐曲的调号和弱起小节。点击音符会跳到钢琴卷帘的同一位置。目前还不能在五线谱上修改音符。
- **在音符起点写入速度·整理速度**：配合原曲在音符起点写入速度，并整理切得很碎的速度变化。
- **把用速度补的段落改成音长**：把靠改变速度来对齐长度的段落，在不动速度的情况下改写成音符长度。
- **把超出范围的速度化为音符长度**：在放入游戏速度范围（t32-255）以外速度的位置，把它化为音符长度，使其落在范围内。
- **工作备注**：在标记栏贴上待办备注（Alt+N）。备注只保存在项目（.mme）中，不会写进导出的 MML、MIDI。
- **原曲力度参考线**：在音量轨上以参考线画出原曲的力度，方便调整 v。
- **从音频扒谱**：开启了与 Basic Scriptor 的连接。

### 变更
- **可以用浮动窗口或画中画观看视频原曲。** 用原曲栏的按钮打开。
- **原曲栏始终显示原曲的偏移。** 还没载入原曲的项目也会显示已保存的偏移。
- **音频设备（耳机、音箱）变更时，会出现建议重建音频的通知。**
- **指法谱视图的变化栏会显示调号文字。**
- **导入 MIDI 的自动对齐加入四分音符 7、9 连音，以及跨拍的 5 连音（l10、l5）格。**
- **有弱起小节的乐曲**（从 Basic Scriptor 导入的乐曲中的 `BS:pickup` 标记）会画成第 0 小节，该标记不会写进导出的乐曲。

## 1.0.0 (2026-11-28)

这是 BiNote 的第一个正式版。我们在真实的 iPad 和游戏中确认了 1.0.0-rc.4，修正了当时发现的问题后，以 1.0.0 发布。1.0.0-rc.5 没有单独发布，已并入此版本。从这个版本起，更新记录也会用英文、日文、中文（繁体、简体）撰写。

### 变更
- **更新内容会以界面语言显示。** 新版本通知和 ? → 本次更新内容，在界面为英文、日文或中文时，会显示用该语言撰写的更新内容。1.0.0 之前版本（beta、rc）的内容仍然只有韩文。关于 BiNote 中的完整更新记录链接，也会打开界面语言的文件。
- **导出 MML 的粘贴顺序列表中，可以拖动一行直接移到想要的栏位。** 以前只能用 ▲ ▼ 一次移一栏，要把最下面的音轨移到最上面得点很多次。现在按住行首的 ⠿ 上下拖动，拖动时栏位会立即调换，松开的位置就是那条音轨的栏位。
  - 鼠标、手指、触控笔都能用。▲ ▼ 也照样可用。
  - 拖动移动后会变成 **自定顺序**；与乐曲顺序相同时会回到乐曲顺序。
- **重写了仓库首页（README），并新增英文版和日文版。** 把新用户需要的音色包、歌曲保存位置和兼容性说明放在了最前面，并加上了先行测试新功能的测试版页面和测试版问题反馈表单的说明。

### 修正
- **再次修正：在 iPad 上休眠或锁屏后，声音比播放线晚出现（越来越慢）。** 播放线会按浏览器报告的输出延迟往后画，但休眠后实际延迟变大时，iPad 报告的值可能不变。因此即使重建音频或对齐合成器时钟，声音仍比播放线晚。
  - 现在会用浏览器给出的实际输出时刻（当前从扬声器发出的声音的时刻）每秒测量一次延迟，如果明显（超过 20ms）大于报告值，就按测得的值延后播放线。刚唤醒时跳动的值不采用，而是用最近五次的中位数。
  - 休眠后重建音频时，会先关闭旧的音频再新建。这更接近关掉应用再打开。
  - 设置 → 播放 → **音频状态** 的 **测量** 会显示播放线使用的延迟（`used for playhead`），并在测得的延迟大幅变化时留下记录。
  - 歌曲和导出的 MML 不变。
- **修正：在 iPad、iPhone 上点 打开乐谱、添加音色包、导入 MusicXML 时，会一起出现“照片图库”和“拍照或录像”。** 现在不会有这些选项，会直接打开“文件”应用，并和以前一样可以选择 .mme、.mml、.mmi、.mid、.dls 等所有文件。
  - 打开原曲、背景视频时，仍和以前一样可以使用照片图库中的视频。
  - Android 和 PC 的打开窗口不变。
- **音符重新分配页（调整字数 → 音符重新分配）的字数、超出标记（⚠）、自动选出超出的部分和前后对照表，全部改用游戏字数。** 游戏字数是放进游戏时重写为最短形式的文字字数，与窗口上方长条的数字相同。原文会把注释、换行、重复写的 l、v 都算进去，所以可能更长。
  - 以前，只有原文较长、按游戏字数仍在上限内的音轨也会显示为超出，点 **自动选出超出的部分** 也没有可选的内容，只会显示仍然超出。现在这类音轨会提示“按游戏字数已在上限内”，并关闭自动选出按钮。
  - 前后对照表也是游戏字数，所以没有移动的音轨不会因为文字被重写而看起来大幅变短。
  - 自动选出找不到更多可选的区间时（接收的音轨也接近上限），会说明原因，并提示添加空音轨或拆分乐谱夹。
- **和弦合并页的音轨字数和前后对照表也改用游戏字数显示。** 功能与以前相同。
