# 更新紀錄

BiNote 各版本的變更內容（從 1.0.0 起）。更早的版本（beta、rc）只有韓文，在 [CHANGELOG.md](../../CHANGELOG.md)。新版本在重新開啟 App 後套用。目前的版本可以在設定最下方或 ? → 關於 BiNote 中查看。

## 1.1.0-beta.1 (2026-11-28)

這是 1.1 的第一個 beta。只在 beta 頁面（beta.binote.pages.dev）發布。在 1.0.0 的全部內容之上，加入了為 1.1 新做的功能。新功能大多在 **實驗室** 中，一開始是關閉的，不開啟的話就和 1.0.0 一樣使用。beta 頁面和正式頁面的儲存空間是分開的，樂曲和音色包彼此看不到。要搬移時，請先存成專案（.mme）檔，再重新開啟。

PC 版瑪奇支援（切換遊戲）還需完善，將在 1.1.0-beta.2 加入。本次測試版中不顯示。

### 加入實驗室的功能
- **五線譜檢視**：在鋼琴捲簾、指法譜旁邊加入五線譜檢視。依欄位寬度像樂譜一樣換行繪製，並依照樂曲的調號和弱起小節。點選音符會跳到鋼琴捲簾的同一位置。目前還不能在五線譜上修改音符。
- **在音符起點寫入速度·整理速度**：配合原曲在音符起點寫入速度，並整理切得很細的速度變化。
- **把用速度補的段落改成音長**：把靠改變速度來對齊長度的段落，在不動速度的情況下改寫成音符長度。
- **把超出範圍的速度化為音符長度**：在放入遊戲速度範圍（t32-255）以外速度的位置，把它化為音符長度，使其落在範圍內。
- **工作備註**：在標記欄貼上待辦備註（Alt+N）。備註只存在專案（.mme）中，不會寫進匯出的 MML、MIDI。
- **原曲力度參考線**：在音量軌上以參考線畫出原曲的力度，方便調整 v。
- **從音訊採譜**：開啟了與 Basic Scriptor 的連結。

### 變更
- **可以用浮動視窗或子母畫面觀看影片原曲。** 用原曲列的按鈕開啟。
- **原曲列一律顯示原曲的偏移。** 還沒載入原曲的專案也會顯示已儲存的偏移。
- **音訊裝置（耳機、喇叭）變更時，會出現建議重建音訊的通知。**
- **指法譜檢視的變化列會顯示調號文字。**
- **匯入 MIDI 的自動對齊加入四分音符 7、9 連音，以及跨拍的 5 連音（l10、l5）格。**
- **有弱起小節的樂曲**（從 Basic Scriptor 匯入的樂曲中的 `BS:pickup` 標記）會畫成第 0 小節，該標記不會寫進匯出的樂曲。

## 1.0.0 (2026-11-28)

這是 BiNote 的第一個正式版。我們在實際的 iPad 和遊戲中確認了 1.0.0-rc.4，修正了當時發現的問題後，以 1.0.0 發布。1.0.0-rc.5 沒有另外發布，已併入此版本。從這個版本起，更新紀錄也會以英文、日文、中文（繁體、簡體）撰寫。

### 變更
- **更新內容會以畫面語言顯示。** 新版本通知和 ? → 本次更新內容，在畫面為英文、日文或中文時，會顯示以該語言撰寫的更新內容。1.0.0 之前版本（beta、rc）的內容仍然只有韓文。關於 BiNote 中的完整更新紀錄連結，也會開啟畫面語言的檔案。
- **匯出 MML 的貼上順序清單中，可以拖曳一行直接移到想要的欄位。** 以前只能用 ▲ ▼ 一次移一欄，要把最下面的音軌移到最上面得按很多次。現在抓住行首的 ⠿ 上下拖曳，拖曳時欄位會立即調換，放開的位置就是那條音軌的欄位。
  - 滑鼠、手指、觸控筆都能用。▲ ▼ 也照樣可用。
  - 拖曳移動後會成為 **自訂順序**；與樂曲順序相同時會回到樂曲順序。
- **重寫了儲存庫首頁（README），並新增英文版和日文版。** 把新使用者需要的音色包、歌曲儲存位置和相容性說明放在最前面，並加上先行測試新功能的測試版頁面與測試版問題回報表單的說明。

### 修正
- **再次修正：在 iPad 上休眠或鎖定畫面後，聲音比播放線晚出現（延遲累積）。** 播放線會依瀏覽器回報的輸出延遲往後畫，但休眠後實際延遲變大時，iPad 回報的值可能不變。因此即使重建音訊或對齊合成器時鐘，聲音仍比播放線晚。
  - 現在會用瀏覽器提供的實際輸出時刻（目前從喇叭發出的聲音的時刻）每秒測量一次延遲，若明顯（超過 20ms）大於回報值，就依測得的值延後播放線。剛喚醒時跳動的值不採用，而是用最近五次的中位數。
  - 休眠後重建音訊時，會先關閉舊的音訊再建立新的。這更接近把 App 關掉再打開。
  - 設定 → 播放 → **音訊狀態** 的 **測量** 會顯示播放線使用的延遲（`used for playhead`），並在測得的延遲大幅變化時留下紀錄。
  - 歌曲和匯出的 MML 不變。
- **修正：在 iPad、iPhone 上按 開啟樂譜、新增音色包、匯入 MusicXML 時，會一起出現「照片圖庫」和「拍照或錄影」。** 現在不會有這些項目，會直接開啟「檔案」App，並和以前一樣可以選擇 .mme、.mml、.mmi、.mid、.dls 等所有檔案。
  - 開啟原曲、背景影片時，仍和以前一樣可以使用照片圖庫中的影片。
  - Android 和 PC 的開啟視窗不變。
- **和弦分配分頁（調整字數 → 和弦分配）的字數、超出標示（⚠）、自動選出超出的部分和前後對照表，全部改用遊戲字數。** 遊戲字數是放進遊戲時重寫為最短形式的文字字數，與視窗上方長條的數字相同。原文會連註解、換行、重複寫的 l、v 都算進去，所以可能比較長。
  - 以前，只有原文較長、以遊戲字數計仍在上限內的音軌也會顯示為超出，按 **自動選出超出的部分** 也沒有可選的內容，只會顯示仍然超出。現在這類音軌會告知「以遊戲字數計已在上限內」，並關閉自動選出按鈕。
  - 前後對照表也是遊戲字數，所以沒有移動的音軌不會因為文字被重寫而看起來大幅變短。
  - 自動選出找不到更多可選的區間時（接收的音軌也接近上限），會說明原因，並提示新增空音軌或分割樂譜夾。
- **和弦合併分頁的音軌字數和前後對照表也改用遊戲字數顯示。** 功能與以前相同。
