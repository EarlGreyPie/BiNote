# 更新履歴

BiNote の版ごとの変更点です（1.0.0 から）。それより前の版（beta・rc）は韓国語の [CHANGELOG.md](../../CHANGELOG.md) にだけあります。新しい版はアプリを開き直すと適用されます。今の版は設定のいちばん下か、? → BiNote について で確認できます。

## 1.0.0 (2026-11-28)

BiNote の最初の正式版です。1.0.0-rc.4 を実際の iPad とゲームで確かめ、そこで見つかった問題を直して 1.0.0 として出します。1.0.0-rc.5 は別に出さず、この版にまとめました。この版から、更新履歴を英語・日本語・中国語（繁体字・簡体字）でも書きます。

### 変わった点
- **更新内容を画面の言語で表示します。** 新しい版のお知らせと ? → 今回の更新内容 は、画面が英語・日本語・中国語ならその言語で書いた更新内容を表示します。1.0.0 より前の版（beta・rc）の内容は、これまでどおり韓国語だけです。BiNote について のすべての更新履歴リンクも画面の言語のファイルを開きます。
- **MMLで書き出す の貼り付け順リストで、行をドラッグして好きな枠へすぐ移せます。** これまでは ▲ ▼ で1枠ずつしか動かせず、いちばん下のトラックをいちばん上へ上げるには何度も押す必要がありました。これからは行頭の ⠿ をつかんで上下にドラッグすると、ドラッグ中に枠がすぐ入れ替わり、離した場所がそのトラックの枠になります。
  - マウスでも指・ペンでも使えます。▲ ▼ もそのまま使えます。
  - ドラッグで動かすと **自分で決めた順** になり、曲の順と同じになると曲の順に戻ります。
- **リポジトリのトップページ（README）を書き直し、英語版と日本語版を追加しました。** 初めて使う人向けに、サウンドパック・曲の保存場所・互換性の案内を先頭に置き、新機能を先に試すベータページとベータの不具合報告フォームの案内を加えました。

### 直した点
- **iPad でスリープや画面ロックのあと、音が再生線より遅れて鳴る（ずれる）問題をもう一度直しました。** 再生線はブラウザが知らせる出力遅延の分だけ遅らせて描きますが、スリープのあとは実際の遅延が増えても iPad が知らせる値が変わらないことがありました。そのため、オーディオを作り直してもシンセの時計を合わせても、音が再生線より遅れました。
  - これからは、ブラウザが渡す実際の出力時刻（いまスピーカーから出ている音の時刻）で遅延を 1 秒ごとに測り、知らされた値よりはっきり（20ms を超えて）大きければ、測った値だけ再生線を遅らせます。起きた直後に跳ねる値は使わず、直近 5 回の中央値を使います。
  - スリープのあとにオーディオを作り直すときは、古いオーディオを先に閉じてから作ります。アプリを閉じて開き直したときに近くなります。
  - 設定 → 再生 → **オーディオの状態** の **測る** に、再生線に使う遅延（`used for playhead`）が表示され、測った遅延が大きく変わったときの記録が残ります。
  - 曲と書き出す MML は変わりません。
- **iPad・iPhone で 楽譜を開く・サウンドパックを追加・MusicXMLを読み込む を押すと「フォトライブラリ」「写真またはビデオを撮る」も出ていた問題を直しました。** これからはこれらの項目なしでファイルアプリがすぐ開き、これまでどおり .mme・.mml・.mmi・.mid・.dls などのファイルをすべて選べます。
  - 原曲・背景動画を開くときは、フォトライブラリの動画を使えるようにこれまでどおりです。
  - Android と PC の開く画面は変わりません。
- **音符の再配分タブ（文字数を合わせる → 音符の再配分）の文字数、あふれ表示（⚠）、超えた分だけ自動で選ぶ、前後の表をすべてゲームの文字数で見ます。** ゲームの文字数は、ゲームに入れるときにいちばん短く書き直した文の文字数で、ウィンドウ上のバーと同じ数です。元の文はコメント・改行・重ねて書いた l・v まで数えるので、長くなることがあります。
  - これまでは、元の文だけが長くゲームの文字数では上限内のトラックもあふれると表示され、**超えた分だけ自動で選ぶ** を押しても選ぶものがなく「それでも超えます」とだけ出ていました。これからはそうしたトラックに「ゲームの文字数ではすでに上限内」と知らせ、自動で選ぶボタンはオフにします。
  - 前後の表もゲームの文字数なので、移していないトラックが文を書き直した分だけ大きく減ったように見えません。
  - 自動で選ぶがこれ以上選ぶ区間を見つけられないとき（受け取るトラックも上限に近い）は、その理由と、空のトラックを追加する・楽譜集に分割する方法を知らせます。
- **和音の統合タブも、トラックの文字数と前後の表をゲームの文字数で表示します。** することはこれまでと同じです。
