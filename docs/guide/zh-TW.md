# BiNote 使用指南

這是《瑪奇 Mobile》MML 樂譜編輯器 **BiNote** 的使用說明，以 1.0 Beta 為準撰寫。

> 這是與 Nexon、《瑪奇 Mobile》無關的非官方個人粉絲自製工具。遊戲名稱、樂器名稱與聲音的權利屬於 Nexon。

本指南中的遊戲上限是 BiNote 在韓國伺服器實測後採用的檢查標準；部分遊戲用語（樂器名稱、樂譜夾等）為暫定翻譯，若有錯誤，請透過[回報翻譯](https://github.com/EarlGreyPie/BiNote/issues/new/choose)表單告訴我們。

## 1. 開始使用

### 開啟方式

用網頁瀏覽器（Chrome、Edge、Safari）開啟 BiNote 網站即可，不需要安裝。第一次連線時會把應用程式檔案全部下載下來，之後沒有網路也能開啟。如果打算離線使用，請先關閉網路、確認能重新開啟。本使用指南是網路上的文件，離線時無法開啟。

如果經常使用，建議**加入主畫面（安裝應用程式）**。

- 電腦版 Chrome、Edge：網址列右側的安裝圖示
- iPad、iPhone Safari：分享 → 加入主畫面
- Android Chrome：⋮ → 加到主畫面（安裝應用程式）

安裝的應用程式與瀏覽器分頁是否共用儲存空間（音色包、自動保留），依裝置而不同。

- 電腦、Android：只要是同一個瀏覽器、同一個設定檔、同一個網址，就會共用。
- iPhone、iPad：主畫面應用程式與 Safari 分頁的儲存空間是分開的。必須在主畫面應用程式中再加入一次音色包，分頁中自動保留的樂曲也看不到。

要把作品移到其他裝置或其他瀏覽器時，請儲存為專案（.mme）檔案再開啟。

### 第一個畫面

沒有樂曲時，第一個畫面會有三個按鈕。

| 按鈕 | 功能 |
|---|---|
| 新樂譜 | 以一份鋼琴樂譜、一條空白音軌開始（t120，4/4） |
| 開啟樂譜 | 開啟 3MLE（.mml）、MabiIcco（.mmi）、MIDI（.mid）、BiNote 專案（.mme） |
| 貼上 MML@ | 貼上遊戲用 `MML@…;` 格式的樂譜文字來開啟。在編輯器外按 Ctrl+V 也能開啟 |

如果有編輯中的樂曲，下方會出現**先前的作品**清單。即使重新整理或關閉了分頁，也能在這裡還原。

### 音色包

**沒有音色包也能編輯。** 若要聽到聲音，請加入音色包（.dls、.sf2、.sf3）。瑪奇音色包屬於 Nexon 的資產，BiNote 不附帶，請另外取得。

- 加入方式：設定（⚙）→ 音色包 → 新增音色包，或點按狀態列的「沒有音色包」
- 加入多個時，**清單中越上面的音色包越優先**使用。先加入的音色包會排在上面。可用音色包旁的▲▼按鈕調整順序，下次開啟時也會保持。
- 只以 MabiIcco 編號表示的樂器（例如 `#40.3`）不論順序，只從符合 `.2`・`.3` 編號的音色包（依檔名判斷）尋找。不同音色包的同一編號可能是不同樂器，因此若沒有該音色包，不會改用其他音色包，而是顯示為找不到的樂器。豎琴（`24.2`）等已知名稱的樂器會先使用符合編號的音色包，沒有時改用其他音色包的同一樂器。
- **可以為每條音軌選擇音色包。** 在音軌編輯器標題列樂器選擇旁的音色包選擇（有兩個以上音色包時顯示）選擇後，該音軌（若音軌沒有自己的樂器則為該樂譜）會以該音色包播放。預設為 **自動（從上面的音色包）**。若選擇的音色包目前未載入，會從上面的音色包尋找並播放，並在音色包名稱後顯示「（無）」。樂曲會保留所選的音色包名稱，重新加入該音色包後就會以它播放。選擇 `.2`・`.3` 音色包時，儲存為 MabiIcco 格式時的樂器編號也會帶有該音色包編號。
- 樂器編號帶有 `.2`・`.3` 音色包編號的樂器，會在音軌編輯器的樂器選擇、音軌列的樂譜標籤、找不到樂器的提示中像 **豎琴(24.2)** 一樣一併顯示音色包編號。基本樂器只顯示名稱。
- 加入的音色包會儲存在這個瀏覽器中，下次開啟時自動載入。檔案不會傳送到伺服器。
- 若有音色包中沒有的樂器，會以「音色包中找不到的樂器」提示。

### 快速上手：製作第一份樂譜

1. 在第一個畫面點按**新樂譜**。
2. 點按鋼琴卷簾的空白格輸入音符。若要用 MML 撰寫，請在音軌面板的 MML 編輯器中輸入下面的範例。
   ```
   t120o4l4v8cdefgab>c
   ```
3. 如果已加入音色包，按**播放**（Space）試聽。沒有音色包也能編輯與複製遊戲用文字。
4. 用**檔案 → 儲存為專案**（Ctrl+S）儲存 `.mme` 檔案。儲存為 3MLE（.mml）是 Ctrl+Alt+S。
5. 在**檔案 → 匯出 MML…** 中確認錯誤、警告與字數。
6. 點按要使用的樂譜的**複製 MML@**，貼到遊戲中的空白樂譜。有多份樂譜時，一次複製一份。

上面的範例是輸入到音軌編輯器的 MML。用**貼上 MML@** 開啟時，請使用 `MML@t120o4l4v8cdefgab>c;` 這樣的完整格式。

## 2. 先了解遊戲規則

BiNote 依照《瑪奇 Mobile》的上限進行檢查與輸出。下列用語在畫面與本指南中意思相同。

| 用語 | 意思 |
|---|---|
| **樂譜** | 一次貼到遊戲中的單位。一個 `MML@音軌1,音軌2,…;` |
| **音軌** | 樂譜中的一行（旋律、和弦1~5）。一條音軌一次只能發一個音 |
| **演奏者** | 在樂譜中負責一種樂器的人。一份樂譜可以有多位演奏者 |
| **樂譜夾** | 把長曲分成多份樂譜接續演奏 |

遊戲上限：

- 一份樂譜**最多 6 條音軌**。第一位演奏者 1~3 音軌，之後的演奏者每人 1 音軌（3+1+1+1、2+1+1+1+1、1×6 可以；2+2+2、3+3 不行）
- **音樂盒、留聲機**一份樂譜為 3 音軌。6 個和弦音要分成兩份 3 音軌的樂譜同時播放（兩份貼上文字都放入全部 6 音軌，只改變順序。遊戲只演奏前 3 音軌，但曲長與速度由 6 音軌決定，兩台不會錯開）。另外設定樂器的音軌不能留在音樂盒樂譜，會移到新樂譜
- 一條音軌 **2400 字**
- **速度是每份樂譜分別讀取**。因此 BiNote 匯出 MML時會在所有樂譜中寫入速度
- 速度 t32~t255，音長 1~64（最多一個附點，最短的 64 分音符也能加附點，即 `64.` = 3/128），音量 v0~v15（v0 為無聲）
- 每種樂器的發聲音高範圍是固定的，範圍外的音不會出錯，而是以八度為單位移入範圍內發聲。本指南把這種情況稱為**音域折回**
- 用樂譜夾換到下一份樂譜時，會產生約 1 秒的間隔

上述上限是 BiNote 在韓國伺服器實測後採用的目前檢查標準（2026-10 時）。即使把介面語言改成日文或中文，檢查標準也不變，並不代表其他伺服器的上限。另外也有尚未完成實測的項目，例如同一演奏者的音軌之間相同音重疊時的行為。

### 選單

| 選單 | 內容 |
|---|---|
| 檔案 | 新樂譜、開啟樂譜、貼上 MML@、還原先前的作品、儲存（3MLE、專案、MabiIcco、MIDI、WAV）、匯出 MML、新增音色包、連接 MIDI 鍵盤 |
| 編輯 | 復原、重做、全選、刪除、剪下、複製、貼上、長度 ×2、½、琶音、滑音、裝飾音、移調、分割／合併音軌 |
| 樂曲 | 批次調整音量、變更拍號、點拍測速、清除速度、一次變更速度、每份樂譜都寫入速度、尋找偏離拍子的長度、新增音軌、新增樂譜、和弦分配、和弦合併、減少字數、分割樂譜夾 |
| 檢視 | 鋼琴卷簾／指法譜、面板在下／面板在側、並排、編輯器數量、直向卷簾、事件、音符清單、播放時琴鍵亮燈、選取音符琴鍵亮燈、在 MML 中標示停止位置、音軌顏色、MML 鍵盤、指法譜數字鍵盤、快速鍵 |

### 音軌面板

- **結構清單**：依樂譜 → 音軌的順序顯示。每條音軌都有 M（靜音）、S（獨奏）、字數長條、鎖定、⋯ 選單（上移、下移、複製音軌、移到其他樂譜、移到新樂譜／複製到新樂譜、在卷簾中隱藏）。有 MML 檢查項目的音軌，名稱旁會顯示紅點與數量。
- 點兩下名稱即可重新命名（Enter 確定，Esc 取消）。
- 拖曳左側的把手，可把音軌移到其他樂譜。長按音軌（觸控）會開啟選單。
- **MML 編輯器**：修改所選音軌的 MML 文字。語法錯誤與遊戲上限問題會以底線標示，把滑鼠移到底線上即可看到內容。
- 用工具列右側（圖層左邊）的 **橫 | 直** 按鈕移動面板。**橫**放在卷簾旁邊（適合滑鼠、觸控），**直**放在卷簾下方（3MLE 式，適合鍵盤）。與檢視選單的面板在下／面板在側相同。拖曳分界線可調整大小。
- 用 檢視 → **編輯器數量**（1~4 個，最大數量在 設定 → 畫面）在音軌面板上下排列多個 MML 編輯器，一次查看多條音軌的文字。上方為選取的音軌；在清單或音軌列中 Alt+點按的音軌會開在最久沒更換的下方編輯器（只有一個編輯器時會增加為兩個）。同一條音軌不會在兩個編輯器中開啟，每個下方編輯器可用 × 關閉。

### 狀態列

- 選取的音軌、字數 / 上限
- **檢查 N**：全曲的檢查結果。點按即展開，用「移到該位置」前往問題所在。
- 音色包數量與樂器數量
- **說明**：鋼琴卷簾、指法譜的操作摘要

## 4. 輸入音符

在鋼琴卷簾、MML 編輯器、指法譜中修改的內容，全都會反映在同一首樂曲上。

### 鋼琴卷簾

| 動作 | 滑鼠 | 觸控、觸控筆 |
|---|---|---|
| 輸入音符 | 點按空白格（拖曳則依拖曳長度） | 點按空白格 |
| 移動 | 拖曳音符 | 拖曳音符 |
| 改變長度 | 拖曳音符尾端 | 拖曳音符尾端 |
| 刪除 | 按右鍵 | 橡皮擦工具 |
| 選取多個音 | Ctrl+點按、在空白處 Ctrl+拖曳 | 用選取工具拖曳 |
| 設定播放游標 | Shift+點按 | — |
| 循環區段 | Shift+拖曳 | — |
| 與下一個音以 & 連結 | Alt+點按 | — |

- **新音符**長度：選「依格線」時為格線一格；另外選擇時則不論格線都使用該長度（含三連音）
- **連音**：在新音符長度清單最下方的 **連音…** 選擇「幾個音佔哪種音符的時間」（2～15 個；全、2分、4分、8分、16分、32分音符及其附點音符）。一個音的長度是基準數字×N：4分5連音 = l20、4分7連音 = l28、附點4分2連音 = l8.。選好的連音會成為新音符長度，**格線也設為該格**（預設開啟）會一併改變格線（4分5連音為 1/20）。遊戲只接受 l1～l64，所以像 16分5連音（l80）這樣更短的音無法選擇（不會四捨五入）。設定的連音會記在這個瀏覽器
- 格線清單也會出現所設連音的格子，以及符合新音符長度的格子。附點4分5連音（l20.）時會出現 1/40。一格比 1/64 還短的格線（1/128 等）無法把該長度的音或休止符寫給遊戲，所以不提供。要在 64. 後面接著輸入時，請用指法譜數字鍵盤或 MML 文字
- 會留下無法準確寫給遊戲的音或休止符長度的編輯（例如在 1/28 格線上切開 4分5連音的音，留下 1/70 的零碎長度）不會執行，並顯示原因。不只輸入、切開、貼上、改長度、移動、琶音、滑音、裝飾音，刪除小節、分割／合併音軌、和弦分配、和弦合併等樂曲編輯也都一樣。只有直接輸入或貼上的 MML 文字會照原樣保留
- **工具**：輸入（預設）· 選取（只點按或拖曳選取；解開旁邊的鎖頭後可拖曳移動選取的音）· 橡皮擦 · 剪刀（在點按處切開音符）
- **圖層**：在卷簾上繪製「選取的音軌」／「樂譜」／「全部」。其他音軌的音會淡淡顯示，開啟「點按其他音軌的音來切換」時，點按即可切換到該音軌。
- 點按音符會在 MML 文字中標示該位置，點兩下即可直接在那裡輸入。
- 畫面移動：滾輪（時間）· Shift+滾輪（音高）· Ctrl+滾輪（時間放大）· Ctrl+Shift+滾輪（琴鍵高度放大）· 「顯示全部」按鈕
- 也可以用卷簾右下角的按鈕放大・縮小（時間 −/+、琴鍵高度 −/+）及「顯示全部」（直向卷簾在琴鍵列上方的右側）。平時顯示得較淡；畫面非常窄時，琴鍵高度 −/+ 請用工具列或 ⋯ 選單
- 開啟 設定 → 畫面 → **音符音量數字** 後，所選音軌的音符上方會顯示 `v12` 這樣的音量（直向卷簾顯示在音符開頭右側）。**僅變化處** 只寫在音量與前一個音不同的音和畫面中第一個可見的音，**所有音符** 則每個音都寫。用 `&` 連接的後段音不寫，太擠時重疊的數字會略過（放大即可看到）
- **直向卷簾**：對照下落式音符影片輸入音符時使用把設定 → 畫面 → **播放時的卷簾**設為**連續捲動**後，播放時音符會從上方持續落到琴鍵（適合錄製直式影片）。

### MML 編輯器

直接撰寫 MML。修改的文字會反映到鋼琴卷簾與試聽上。若有語法錯誤，請查看底線與狀態列的檢查。

| 指令 | 意思 |
|---|---|
| `c d e f g a b` | 音符（`+`、`#` 升，`-` 降），後面接長度（`c8`、`e4.`） |
| `r` | 休止符 |
| `n編號` | 以音符編號撰寫 |
| `o編號` `<` `>` | 設定八度、降八度、升八度 |
| `l編號` | 預設長度 |
| `v編號` | 音量 0~15 |
| `t編號` | 速度 |
| `&` | 與下一個音連結（同音則延音，不同音則為滑音） |

- 以 `&` 連結相同的音時，& 後面的 v 在遊戲中會被忽略。
- 以 `&` 連結不同音高時，不會重新彈奏，只在連結處改變音高（並不是滑順連續的聲音）。BiNote 把這稱為滑音。刪除 `&` 後會變成分別彈奏的音，演奏也會改變。
- 在 iPad 上開啟 **MML 鍵盤**（檢視選單）後，會改用 MML 字元鍵盤取代螢幕鍵盤。

### 指法譜（吉他譜）

用「鋼琴卷簾／指法譜」按鈕（Alt+T）切換。會集合所選樂譜的音軌，自動選擇弦與琴格。

- 點按弦上放置游標，**用數字輸入琴格**（0–24，兩位數連續輸入），方向鍵移動，Delete 刪除
- 用鍵盤或數字鍵盤移動游標並移出畫面時，畫面會跟著捲動（在 檢視 → **跟隨游標** 中開關，預設開啟）
- 點按最上方的 **小節編號列** 會從該位置播放（播放中則從那裡繼續播放，再次點按播放位置即清除），拖曳則設定循環區間（與鋼琴捲簾相同，觸控時用手指拖曳即可）。播放位置與循環區間與鋼琴捲簾共用，切換檢視後保持不變。在快捷鍵設定中為 **把播放位置移到編輯游標** 指定按鍵後，可把播放位置移到指法譜游標處（預設無按鍵）
- `+` / `-`：將游標音的長度加倍 / 減半（新音符長度也一起改變）。在數字鍵盤改變**新音符**時，游標所在的音長度也會改變。加長時最多到同一音軌的下一個音之前
- `.`：加上或去掉附點。作用於選取的音符，沒有選取時為游標處的音（連音時為游標所在的音），例如四分音符 ↔ 附點四分音符。游標處也沒有音時作用於新音符長度。數字鍵盤的音符輸入列末端有 **.** 按鈕
- 在已有的音上輸入琴格只改音高，長度不變
- `L`：與緊接的下一個音以 & 連結 · `(5)` 延音 · `5/7` 滑音。後面是空的時，會依新音符長度加上同一個音並連結（八分音符 + L = 四分音符長度）
- 同一位置的和弦音會放入同一樂譜的空白音軌
- 可選擇調弦（標準、Drop D、DADGAD、Nashville、Baritone 等）與移調夾
- 若用錯調弦輸入了六線譜，請用調弦旁的 **保留六線譜並更換調弦…**。弦與格數保持不變，音高改成新調弦（含移調夾）下的音高。復原一次，調弦也會一起還原。樂譜集標示「up 1/2 step」的調弦，選同一調弦並把移調夾設為 1 即可
- 縮放按鈕在電腦（滑鼠）上和鋼琴卷簾一樣位於上方工具列（輸入 v 之後），在觸控螢幕上則位於指法譜下方的工具列（時間捲軸旁）。橫向 −/+ 調整時間縮放，電腦工具列的 **顯示全部** 會讓整首樂曲收進一個畫面（工具列太窄時，`A−` / `A+` 和指板位置在 ⋯ 選單中）
- 開啟 設定 → 畫面 → **音符音量數字** 後，指板最下方（無法彈奏的 × 下面）會多一列 `v`，以和鋼琴卷簾相同的規則顯示所選音軌音符的音量。選取的音符數字會較深。關閉後這一列就會消失
- 用 `A−` / `A+` 調整指法譜大小（行距、文字），旁邊的 **指板位置** 按鈕（⤒ / ↕ / ⤓）可在高度有剩餘時，選擇把指板放在區域的上、中或下。每按一次依序切換上 → 中 → 下（預設為中），並記在這個瀏覽器中。打開琴格數字鍵盤時，指板一律貼在上方
- 有多條音軌時，數字底色會以音軌顏色淡淡填滿，未選取音軌的數字以淺色顯示（可在 設定 → 畫面 → 指法譜數字顯示音軌顏色 關閉）
- 觸控時使用**琴格數字鍵盤**。在鍵盤上方的**新音符**選擇要輸入的音長（依格線 / l4 / l8 / 三連音等，與工具列的「新音符」是同一設定）。開啟「輸入後移到下一格」時，游標會前進該音長
- 琴格數字上方有一列**音符輸入列**（格線 / 1 / 2 / 4 / 8 / 16 / 32 / 64，寬度不夠時可左右滑動）。按下的按鈕就是新音符的音長，游標處有音時該音的音長也會跟著改變。附點用這一列末端的 **.** 按鈕加上。開啟 設定 → 畫面 → **音符輸入列顯示三連音** 後會出現三連音（3、6、12、24、48）按鈕。開啟 設定 → 畫面 → **音符輸入列顯示連音** 後，最後會出現已設定連音（例如 20）的按鈕。在 設定 → 畫面 → **在指法譜數字鍵盤按下數字後** 選擇游標要去的位置：**移到下一格**（預設，前進輸入的音長）/ **移到下一弦（和弦）**（同一位置往下一弦，已在最下面一弦則不動）
- 開啟 檢視 → **指法譜數字鍵盤** 後，用滑鼠點指板也會打開琴格數字鍵盤（關閉時只有觸控、觸控筆會打開）。設定記在這個瀏覽器中
- 用右上角的 **×** 關閉數字鍵盤（Esc 也可以）。關閉後再點一次指板的弦，或按指法譜下方工具列的 **數字鍵盤** 按鈕即可重新打開。沒有游標時放在目前看得到的第一格
- 上方的變化列和鋼琴卷簾一樣分成兩格：**上格是速度，下格是拍號・標記**（順序和顏色與鋼琴卷簾相同）。在上格 **按兩下**（觸控、觸控筆為長按），即可在該位置加入速度（即使樂曲開頭有 4/4，按上格也會加入速度）；在下格空白處按兩下則加入標記。按在速度文字上會修改該速度，按在拍號文字上會修改拍號（新的拍號請修改拍號文字，或用工具列的 **拍號** 欄）。也可用 `Alt+B`（在指法譜游標位置，沒有時為編輯游標或樂曲開頭）。滑鼠移到空白處時會依格顯示這個提示。在變化列 **按一下**，會像鋼琴捲簾的事件列一樣，把播放位置（虛線）移到該處。變化列塗上與小節號列相同的底色，與指法譜的弦線區分。文字大小可在 設定 → 畫面 → **事件列文字（指法譜・鋼琴捲簾）** 選 10・13（預設）・16・20px（鋼琴捲簾事件列也套用同一設定）。按兩下開啟的視窗同時有速度・拍號・標記欄，勾選多項會一次加在該處，取消已有的項目則刪除（復原一次）
- 用工具列的 **拍號** 欄也能從指法譜游標所在的小節（沒有游標時為播放游標所在小節或曲首）開始變更拍號
- 在鋼琴卷簾加入的標記也會顯示在下格（一首樂曲只有一組標記，兩種檢視共用）。在標記文字上 **按兩下**（觸控、觸控筆為長按）會開啟標記視窗，可修改名稱或刪除。名稱太長時只顯示前 12 個字並加上 …，滑鼠移上去會顯示完整名稱
- **選取音符**：用 `Shift+←/→` 從游標位置擴大或縮小時間範圍，會選取在該範圍內開始的所有音符，不論弦或音軌（整列）。滑鼠可用 `Shift`+點按（從游標到點按位置）或 `Shift`+拖曳；`Ctrl+A` 選取指法譜中顯示的音軌的所有音符。觸控時開啟數字鍵盤的 **選取** 按鈕，再按指板擴大範圍（再按一次或按 Esc 關閉）。選取的數字會以強調色淡淡上色；不按 `Shift` 點按、方向鍵或 Esc 會取消選取。選取音符時，`Shift+↑/↓` 會像鋼琴卷簾一樣升高或降低八度，並保留選取以便連續按（若在按鍵設定中改了八度的按鍵，則用該按鍵）
- 選取的音符可以像在鋼琴捲簾中一樣使用編輯選單和快捷鍵：刪除（Delete）、剪下、複製、貼上、長度 ×2/½（`+`/`-`，加長時只到下一個未選取音符之前）、八度與音量升降、連音（`L`）、切開（Alt+S，在指法譜游標處）、合併（Alt+G）。改變八度後若在原本的弦上無法彈奏，會重新選弦。沒有選取時，Delete、`L`、`+`/`-` 仍作用於游標處的音符。若包含鎖定的音軌，則不做變更並提示
- **和弦的複製與貼上**：在指法譜中複製會保留音軌的劃分；貼到指法譜時從指法譜游標位置（沒有時為原位置）開始，第一層放入第一條音軌，下一層放入下一條音軌。若該音軌已有重疊的音符，會尋找空音軌，不夠時在樂譜音軌上限內新增音軌。若因上限而有任何一層放不下，就什麼都不貼上並提示。貼到鋼琴捲簾時若和弦重疊，則不貼上並提示（一條音軌同一時間只能放一個音）

### MIDI 鍵盤

開啟 檔案選單 → **連接 MIDI 鍵盤** 並連接 MIDI 鍵盤後，可進行一次輸入一個音的**逐步輸入**。會以**新音符**長度在播放游標位置（沒有時為所選音軌的結尾）輸入，輸入位置再向後移動相同長度。不會依按住琴鍵的時間錄下長度。

- 同時按下的音中，最高的音放入目前的音軌，其餘依由高到低的順序放入同一樂譜的後續音軌。音數比剩餘音軌多時，多出的音不會輸入，因此輸入和弦前請先確認音軌數。
- 第一次開啟 MIDI 鍵盤時，會詢問一次是否把按鍵力度作為 v。之後可在 設定 → 播放 →「力度 → v」中更改。

> 建議使用電腦版 Chrome、Edge。Safari（Mac、iPad）與 iPad 上的其他瀏覽器無法使用 MIDI 鍵盤。

## 5. 修改音符

### 變更選取的音

| 功能 | 方法 |
|---|---|
| 一格一格移動 | 方向鍵 |
| 升高、降低八度 | Shift+↑ / Shift+↓ |
| 提高、降低音量 | Alt+↑ / Alt+↓、Alt+滾輪 |
| 直接設定音量 | Alt+數字（6~9 → v6~9，0 → v10，1~5 → v11~15，Alt+\` → v0，Alt+Shift+0~5 → v0~5） |
| 長度 ×2 / ½ | Ctrl+] / Ctrl+[、+ / -（數字鍵盤的 +/− 也可）。沒有選取音符時，改為將新音符長度（工具列的長度選擇）×2 / ½。不會刪除未選取的下一個音符，只延長到它前面 |
| 加上/去掉附點 | `.`（數字鍵盤的 `.` 也可）。為選取的音符加上或去掉附點（四分音符 ↔ 附點四分音符）；沒有選取時作用於新音符長度。三連音、連接的長度等無法寫成一個記號的長度不會改變。加上附點會與下一個音重疊時，不會只加長一部分，而是保持不變並提示（後面的音不會被移動或刪除） |
| 精確設定長度 | 在狀態列的選取音長度欄輸入 MML 長度（8、8.、16..）或分數後按 Enter。分數以全音符為單位，`1/7` 是全音符的七分之一。只接受能以 1~64 長度（最多一個附點）用 & 連接準確寫給遊戲的長度，無法寫出的長度（例如 `1/100`）不會套用，並顯示原因 |
| 連結、解除 | Alt+L |
| 切開 | 剪刀工具，或在播放游標處按 Alt+S |
| 黏合 | Alt+G（把音高相同且相鄰的音在編輯時合為一個音。與 & 連結不同） |
| 複製、剪下、貼上 | Ctrl+C / Ctrl+X / Ctrl+V（貼在播放游標位置） |

**琶音**（編輯選單）：在鋼琴卷簾中選取音符後開啟，會把和弦依序展開。方式有三種。**在一條音軌上展開** 會在選取音軌的該位置依序放入和弦音（和弦音軌的音可選擇刪除或保留）；**刷奏（保持原長度）** 保留原本的和弦音，只依序延後開始；**輪流音軌重複** 每隔一個音長輪流使用同一樂譜的音軌重新彈奏（不足時在音軌上限內增加音軌）。和弦音可取自 同時開始的音 / 只用選取的音 / 和弦名稱（大三和弦、小三和弦、7、M7、m7、sus4、sus2、dim、aug、add9），並選擇順序（往上、往下、上下、隨機）、音符長度（含三連音 l3、l6、l12、l24、l48 與已設定的連音，依長度排列）、八度範圍（1~3）與重複。先看預覽再套用，一次復原即可還原。同時開始的音可在預覽上方的 **放進和弦的音軌** 勾選（選取的音軌一定放入）。從選取音符的第一個開始到最後一個開始，勾選音軌的音一起開始的每個位置都會成為和弦，所以只選一個音也能使用該位置的整個和弦。格子若有比選取音符更長的和弦音，就到那個音的結尾（不截斷長的低音）。

- **吉他譜中的波浪線和弦** 用 **刷奏 + 64分** 製作。不新增音符，原本的和弦音留在原處（音軌、音量、指法譜的弦都不變），只依序延後開始，結尾各自保持原樣。**往上 = 從低音開始**（從吉他第 6 弦一側），往下 = 從高音開始。刷奏不使用八度範圍與重複。選「同時開始的音」時刷該位置的整個和弦，選「只用選取的音」時只刷選取的音，「和弦名稱」需要新增音符，因此改用同時開始的音來刷。在指法譜中，各弦分屬不同音軌的選取音（游標位置則為該位置的和弦）會一起使用。太短無法延後的音保持不變。
- 輪流音軌重複會新增音符，但同音高的音會沿用原本音符的音軌、音量與指法譜的弦；原本和弦音會變短的格子不會製作並會提示。取消勾選的音軌不讀取也不更改。
- 在 **指法譜檢視** 中也能使用：有在指法譜中選取的音符就用它們，沒有時用 **指法譜游標處的和弦**（同一樂譜在該位置開始的音）。

**滑音**（編輯選單）：做出像吉他一樣的滑音。**兩個音之間** 會在相連的兩個音之間填入以半音一步相連的短經過音；**滑入・滑出** 會讓音符前段從低（高）幾個半音開始，或在結尾處滑落。經過音以 `&` 相連，不重新撥弦只改變音高。可選擇滑音長度與每步長度（自動會依遊戲最短音長分割，不足時跳過半音）。距離連結第一個音超過 24 個半音的地方不會建立；往高處長時間滑動時可能在取樣結尾提早中斷，會事先提醒。每個經過音都會增加幾個字，字數增加很快，請留意視窗中的字數提示。

- 鋼琴卷簾和六線譜都能開啟。在六線譜中以選取的音為對象，沒有選取時則是從游標位置開始的整個和弦。
- **滑入並滑出** 會在同一個音上同時加上滑入與滑出（六線譜的 `/14\`、`\14/`）。滑入與滑出各自選擇方向（從下方・從上方 / 往下・往上）、距離（格 = 半音）和長度。滑出的音從該音的尾端取出。
- 滑入位置 **拍上**（預設）會削去目標音的開頭，目標音稍晚響起；**拍前** 和倚音的拍前一樣，從前一個音的尾端（或前面的休止符）取出長度，目標音準時落在拍上。前一個音剩下的長度短於 l64 或無法準確寫出時，會跳過該音。
- 選取和弦時，每條弦（音軌）在各自的音軌上一起滑。從空白處滑入整個和弦（例如 `2/1/2/1/`）一次就能完成；選取兩個和弦並選 **兩個音之間**，每條弦會從前一個和弦滑到下一個和弦。不會新增音軌，所以和弦數上限不變。
- **在音色改變處斷開**（預設開啟）：用 `&` 連接的音跨越取樣區間邊界（o3e、o4e、o5f 等，依樂器而異）時，遊戲會換成另一個取樣，音色會跳動。開啟時會在新做的連結中該處拿掉 `&` 並重新彈奏；關閉時會在預覽中以紅色虛線標示並提醒。試聽聲音因為音色包的取樣與遊戲不同而不更改，只用標示提醒。
- 原本就有的 `&` 跨越音色邊界時會出現在樂曲檢查中。用檢查欄的 **全部斷開** 可一次拿掉這些 `&`（復原一次，鎖定的音軌不變）。滑音工具不會自行刪除原本就有的 `&`。

**加入裝飾音**（編輯選單）：在選取的音（主音）前加入短的裝飾音。鋼琴捲簾用選取的音，吉他譜用選取的音，沒有選取時用游標位置的音。音高在吉他譜輸入主音所在弦的琴格號碼（例如主音在第6格時輸入 `6 8`），在鋼琴捲簾輸入相對主音的半音數（例如 `-2` 或 `-1 +1`），以空格分隔，輸入幾個就產生幾個裝飾音。裝飾音長度可選 l64、l48、l32、l24、l16。MML 沒有不佔時間的裝飾音，所以一定會真的縮短某一邊。**拍上**（預設）讓裝飾音對準拍子出現，主音延後同樣的長度開始；若主音是和弦，同一演奏者其他音軌的和弦音也一起延後，其他演奏者不變。**拍前**讓主音留在原位，裝飾音縮短前一個音（或休止符）的尾端進入；曲子的第一個音或前一個音太短時不能使用。被縮短的音至少保留遊戲最短長度（l64），而且只用能準確寫出的長度，所以長度清單會顯示這個長度最多能放幾個（例如八分音符用 l64 最多7個），超過就不加入。一起選取多個音軌的和弦音時，只在最高的音加一次。開啟 **用 & 連接**（預設關閉）會用 `&` 連接裝飾音和主音，不重新撥奏、只改變音高（像搥弦、勾弦）。被 & 連接、不重新撥奏的音不會加裝飾音。

### 樂曲層級的編輯

- **移調**（Alt+P）：以半音、八度為單位移動「選取的音」、「此音軌」、「此樂譜」或「全曲」。會預先告知在遊戲中會發生音域折回的音數。
- **批次調整音量**（樂曲選單）：改變「選取的音」（鋼琴捲簾・六線譜）、「此音軌」、「此樂譜」或「全曲」的 v。**設成一個值**把所有音設成同一個 v，**調高調低**從目前的 v 以 ± 級移動（在 v0~v15 停住，並告知停住的音數），**目標 dB** 以 v15 為 0 dB，依遊戲中實測的音量規律 dB = 40·log10(v/15) 選最接近的 v（−6 dB ≈ v11）。視窗會預先顯示改變的音數與目前/改後的 v 範圍，一次修改可一次復原。遊戲不讀 & 後面的 v，所以 & 連結會隨第一個音一起改變。也可以先用全選（Ctrl+A）選取音軌的所有音再使用。
- **分割／合併音軌**：把選取的音移到其他音軌（或新音軌）、把樂譜的音軌合併為一條、依音高順序重新分配。重疊的音不會移動，而是留在原處。
- **插入小節、刪除小節**：在播放游標位置插入或刪除一個小節（所有音軌與速度一起移動）。
- **鎖定音軌**：點按鎖頭後，該音軌在卷簾、指法譜、編輯器中都無法修改，仍可選取與複製。移調時若範圍內包含鎖定的音軌，會在確認後一起移動。工具列選取工具旁的鎖頭（拖曳移動選取的音）是與音軌鎖定不同的功能。

### 復原

Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）。全曲指令也能一次復原。

## 6. 速度・拍號・標記

### 事件列

卷簾上方兩列會顯示速度、拍號、標記。一開始就是開啟的，可用檢視 → **事件**開關（會記住你的選擇）。

- 在空白處點兩下（觸控為長按）或在標籤上按右鍵，即可新增、修改。
- 拖曳標籤可移動；在速度標籤上滾動滾輪可 ±1（Shift ±10），按 Del 刪除。
- 鍵盤：**Alt+B** 在游標位置新增速度，**Alt+M** 新增標記

### 拍號

樂曲 → 變更拍號（工具列的 **拍號** 欄相同）。從播放游標所在的小節開始變更（沒有游標時從曲首開始）。在指法譜檢視中從指法譜游標所在的小節開始變更。6/8、9/8、12/8 會以三個八分音符為一拍顯示。

### 點拍測速

樂曲 → 點拍測速。播放原曲（或影片），**在每小節第一拍按 T** 鍵或 [點拍]，停止時就會填入速度。

- 如果第一拍不容易聽清楚，請改成**每拍**，像數拍子一樣按。
- 點拍測速列的**合併細微速度變化**（弱 30ms · 普通 60ms · 強 100ms）：在所選範圍內有偏差的點拍會視為手的誤差，合併為單一速度。速度指令數與 MML 字數也會減少。
- **繼續點拍**：在 **繼續的小節** 輸入小節號並按 **繼續**，會從前一小節開始播放，並從在該小節第一拍按下的點拍開始繼續填入。已填入的速度保持不變，填入後會自動帶入最後點拍的小節。點拍中移動播放位置或循環回到開頭時，會先填入之前的點拍再重新開始。
- 速度是整數，需要捨入，但捨入誤差由下一小節承擔，因此小節再多誤差也不會累積。
- **異常點拍**（關閉 · 10% · 20%（預設） · 35%）：填入後，以小節按鈕列出與前後間隔相差超過此比例的地方（漏按或重複按）。點按即可跳到該位置。不會自動修改。爵士、自由速度或快歌請提高標準或關閉。
- **對齊波形起音**（關閉（預設） · ±30ms · ±60ms，載入原曲時）：填入後，只針對樂譜在該拍寫有音符的點拍，在附近尋找原曲聲音開始的位置，並詢問是否 **對齊**。按下之前不會修改，對齊後可一次復原。
- 原曲列的 **拖曳小節線**：**從前往後**（預設）在波形列中拖曳小節線時，修改從前一個速度位置到該小節線的速度，後面整體順移。**僅前後小節** 保持前後小節線不動，只重新計算兩側兩個小節的速度（點拍填入後修正某一處時使用）。拖曳時小節線旁會顯示新的速度。

### 整理速度

- **一次變更速度**：可將整首曲子的速度統一為一個值（**全部改為**）、全部加減相同數值（**± BPM**），或按百分比變更（**%**）。若有循環區段，則只變更區段內的速度，區段之後的速度保持不變。所有樂譜的 MML 文字也會一併修改，超出遊戲速度範圍（t32~255）時會事先提醒。按一次 Ctrl+Z 即可復原。若某樂譜在區間邊界沒有可加入速度的位置（只有會改變結尾長度的地方，或無法拆分的 n 音符），該樂譜的文字會保持不變，並告訴您是第幾份樂譜。
- **尋找偏離拍子的長度**：3MLE、MabiIcco 以整數 tick 計算長度，所以有些樂譜為了對齊拍子會寫 `r21`（= r32.）、`b19.`（= b16&b64）或在 6 個 l28 後寫 `l27` 這樣的值。它們在那裡能對齊，但 BiNote 和遊戲以精確長度演奏，後面的部分會逐漸偏移。這個視窗只尋找一組音極輕微地（不超過四分音符的 1/96）錯過十六分或八分三連音位置、且沒有再剛好回到格點的地方，並提供剛好落在那裡的整齊值（`r21 → r32.`、`d27 → d28`）。每處都有 **跳到**、**試聽原樣**、**試聽修正後**、**修正**，下方有 **全部修正**。不會自動修改，按一次 Ctrl+Z 即可復原。剛好結束的連音（5 個 l20 等）、三連音和搖擺節奏不會更動。開啟含有這類位置的 3MLE、MabiIcco 檔案或 MML@ 文字時，這個視窗會自動開啟。
- **清除全部速度**：只保留曲首的速度。若有循環區段，則只清除區段內的速度。
- **每份樂譜都寫入速度**：在缺少速度的樂譜 MML 文字中寫入樂曲速度。（即使不做這一步，「匯出 MML」和「分割樂譜夾」也會在每份樂譜寫入速度）
- 遊戲範圍（t32~t255）外的速度在編輯時也能使用，「匯出 MML」會告訴你如何修改（見下方第 9 章）。

## 7. 調整音量（v）

### 輸入 v

工具列的**輸入 v** 是新輸入音符的音量。選「沿用」時會跟隨前一個音的 v。選取音符後會變成**選取音 v**，可一次修改。

### 音量欄

鋼琴卷簾下方的 **音量 (v)** 長條就是音量欄。收起時，用琴鍵帶那一側角落的 **音量 ▲** 按鈕開啟。一根長條代表一組以 `&` 連結的音，右側數字是 v 刻度。

- **筆刷**：拖曳經過的長條，其 v 會變成該高度。
- **直線**（或 Shift+拖曳）：從按下處到放開處，把 v 改成一條直線。
- 若已選取音符，只會改變這些音。
- **一次調整多條音軌**：在音軌清單中按 Ctrl+點按，加入要一起修改的音軌。觸控時可長按音軌，在選單中選 **在音量欄一起繪製**，或點按音量欄的 **音量 ▾**（多條時為 **n 條音軌**）後勾選加入或移除。旋律音軌直接套用畫出的值，其他音軌則依上、中、下的位置各加上設定的數值。沒有旋律標記時，樂譜的第一條音軌即為旋律。
- 音量欄可切換細、大、收起。拖曳音量欄上方的把手可調到任意高度（從細條拖曳也可以），按兩下則在細與大之間切換。也可以在設定 → 畫面 → **音量欄** 選擇高度。用筆繪製時放大會比較好畫。

## 8. 對照原曲・影片採譜

### 原曲

在工具列 ⋯ → **原曲…** 選擇音訊或影片後，會與樂譜一起播放。檔案只在這台裝置上使用，不會傳送到伺服器。

- **偏移（ms）**：原曲較晚時為 +。用來對齊開頭。
- **原曲音量**：原曲的音量
- **波形**：在卷簾小節編號列下方，配合樂曲時間顯示原曲波形。
  - 點按波形即移到該位置。
  - 把波形上的**小節線拖曳**到原曲的拍點上，就會變更速度讓該小節落在那裡。
  - 拖曳波形的空白處，原曲會前後移動，偏移也會改變。
  - 指法譜檢視中，變速列下方也會顯示同樣的波形帶。點按即移到該位置，拖曳空白處可移動原曲（開啟數字鍵盤時為了讓出指板空間會隱藏）。

### 背景影片

工具列 ⋯ → **背景影片…**（在鋼琴卷簾中）。把下落式音符影片（鋼琴演奏影片等）鋪在鋼琴卷簾背景，一邊看影片一邊輸入音符。

- **對齊琴鍵**：設定影片最左端、最右端的琴鍵與琴鍵上緣線後，就會與卷簾的琴鍵重疊。開啟**用控制點對齊**後，可在卷簾上拖曳對齊。
- **對齊卷簾**：移動並縮放卷簾，配合影片的琴鍵範圍。
- 可調整不透明度、偏移（秒）、時間伸縮、影片聲音。
- **填滿畫面**（預設開啟）：自動決定時間伸縮，讓影片從琴鍵上緣線到上端蓋滿卷簾可見的整條時間軸。關閉後可自行設定時間伸縮。
- **對齊速度**：在暫停的影片中量測音符落下的速度，並據此調整卷簾的橫向縮放；播放時影片中的音符與卷簾音符會在琴鍵線上同時相遇。無法自動量測時，可用**手動量測**點兩次同一個音符的前端來量。量測期間無法編輯樂曲（仍可儲存），按 Esc 或**取消**即可停止。樂曲中途換速度時，請在該處重新對齊。
- **播放影片**：不播放樂曲，只播放影片，卷簾會跟著走。

### 搭配使用更方便

- **直向卷簾**：與下落式音符影片的方向一致。選擇設定 → 畫面 → 播放時的卷簾 → **連續捲動**，即使沒有影片也會像下落式音符一樣流動。
- **播放時琴鍵亮燈**（預設開啟）：在琴鍵上標示正在播放的音。可在檢視選單或 設定 → 播放 中關閉。
- **選取音符琴鍵亮燈**（預設 選取期間）：在琴鍵上以音軌顏色標示按下或選取的音。**按住時** 只在按住音符或琴鍵時亮燈，**選取期間** 在音符保持選取時持續亮燈。可在檢視選單或 設定 → 播放 中變更或關閉。
- 設定 → 播放 → **畫面同步校正**：播放線比聲音快時為 +，落後時為 −。iPad、藍牙耳機可能還需要多 100~300ms。

## 9. 匯出 MML

在檔案 → **匯出 MML…** 中確認輸出結果並複製。

### 「匯出 MML」視窗

和結構清單一樣，樂譜列下方是音軌列，每份樂譜的每條音軌都有核取方塊。也會顯示每份樂譜的字數、音軌數、折回的音、錯誤與警告。

1. 勾選一次貼上要放入的音軌。**可以從多份樂譜挑選，一次最多 6 條音軌**（勾滿 6 條後其餘方塊會鎖住）。樂譜列的核取方塊會一次勾選或取消該樂譜的所有音軌。
2. 點按**複製已選音軌**，會依樂曲音軌順序把已選音軌複製成一段 `MML@…;` 文字。若沒有複製成功，請確認瀏覽器的剪貼簿權限。
3. 在遊戲中開啟空白樂譜並貼上。一次貼上只放入一段 MML@ 文字。
4. 已複製的音軌會標示**已複製**，尚未複製的音軌會預先勾選供下一次複製。例如複製樂譜1的 1·2·3 和樂譜2的 1·3·6 後，下一次會勾選樂譜1的 4·5·6 和樂譜2的 2·4·5。第一次開啟時只勾選第一份樂譜。

- 用樂譜列左側的箭頭收合或展開樂譜。預設全部展開，所有音軌都已複製的樂譜會在複製時收合。
- 複製後修改音軌，會變成「複製後已變更」，再次視為要複製的音軌。已複製標示在關閉再開啟視窗後仍會保留，開啟其他樂曲時會清除。
- **寫入速度**（預設開啟）：每次複製都從樂曲開頭的速度寫起。遊戲只看貼上的文字，沒有速度時以 t120 演奏（不會沿用其他貼上的速度）。關閉時會不含速度複製，並提醒遊戲會以 t120 演奏。
- 已選樂譜的速度彼此不同時（混選了原文寫有不同 t 的樂譜），會讓你選擇要寫入的速度。選好的速度在關閉視窗前的下一次複製也會使用。BiNote 每首樂曲只有一份速度圖，因此通常不會出現。
- 整份選取音樂盒、留聲機樂譜時，會和以前一樣把其餘音軌當作不發聲的聲道一起放入，讓樂曲長度與速度一致。與其他樂譜的音軌混選而讓音樂盒音軌落在前 3 個聲道之外時，會提醒它不會發聲。
- 超過字數上限的音軌會顯示為紅色，按鈕會變成「複製已選音軌（超出）」。
- 輸出用的 MML 會以減少字數的方式重新寫出，不會改變編輯器中的文字。會配合已選音軌中最長的一條保留結尾休止符。
- 若速度標記在所有已選音軌的音符中間，為了不捨棄音符，會改寫在緊接其後的音符邊界並告知。

### 速度超出遊戲範圍時

比 t255 快時，會告訴你如何縮短該區段的音長並降低速度；比 t32 慢時，會告訴你如何延長音長並提高速度。實際快慢不變。

### 字數超出時

請依序嘗試。

1. **和弦分配**：樂曲選單 → 和弦分配（也可以從「匯出 MML」視窗中超出上限的那一行開啟）把字數超出上限的音軌（傳送音軌）中的音，**以小節區間**移到同一樂譜、同一樂器的音軌（接收音軌）正在休止的小節。勾選接收音軌後，**尋找空位**會列出可以移動的小節區間（接收音軌是空的區間在前；接收音軌有少量的音的區間，這些音和傳送音軌互換）。可以自己勾選區間，也可以按**自動選出超出的部分**；每次改變勾選都會在表中顯示移動後的字數。有跨過小節線的音或 & 連音的地方不會切開，不會移除音，聲音也不變（重新讀取遊戲輸出確認）。接收音軌不夠時，可以用**新增空音軌**在同一樂譜中新增音軌。樂譜的音軌已滿時，新增音軌會多出一份同一樂器的樂譜（遊戲中一起演奏的人多一個），想一個人演奏請用分割樂譜夾。
2. **減少字數**：保持音符的音高、開始位置與長度，把所有音軌的 MML 改寫得更短。自行輸入的空格、換行、註解會消失。若縮短會讓音符消失，則不會變更並告知。
3. **分割樂譜夾**：在同一位置切開所有音軌，分成多份。
   - **先做和弦分配再分割**（預設開啟）：分割前先在同一樂器的音軌之間移動音符，讓各聲道長度平均。若所有聲道都在上限內就不分割；若能減少份數，就用移動後的結果分割。正在編輯的曲子不會改變，按「也套用到曲子」才會移動曲子中的音符（可用 Ctrl+Z 復原）。關閉後只做樂譜夾分割，若移動音符能減少份數，只會顯示「N 份 → M 份」的提示。
   - **仔細分割**（預設關閉）：在每份的結尾多追蹤幾個接近上限的位置，尋找份數更少的分法。比較花時間，分割時下方會顯示步驟與進度條。短的曲子不開這個選項也會精確找出最少份數。
   - 優先選擇全部都在休止的位置。
   - 每份會重新寫入八度、音量、速度。
   - 下一份晚開始多少（約 1 秒），前一份就提早結束多少，以保持節拍。這段校正區間內若有音符，音可能變短或被移除。請查看結果中的「結尾被切斷的音」與長度警告，試聽每份交界前後再使用。

和弦分配、和弦合併與減少字數會在視窗中顯示變更前後的字數，確認後再套用。套用的變更可用 Ctrl+Z 復原。分割樂譜夾不會改變原本的樂曲，只會產生每一份的輸出結果。請使用每一份中各樂譜的複製按鈕。

### 和弦合併

樂曲選單 → **和弦合併** 用於同一樂譜、同一樂器的音軌組：為每條音軌選擇 **保留 / 清空 / 不參與**，就會把要清空的音軌的音移到要保留的音軌在那個時間休止的位置，並刪除清空的音軌（樂譜有兩份以上，刪除後會把後面的音軌拉進前一份樂譜時，保留為空音軌）。適合匯入 MIDI 後出現音符零星的音軌，或想減少音軌數時使用。休止處不夠時由**階段**決定：**第1階段**（預設）不移除音，該音軌保持原樣。**第2階段**只移除重複的音：那一刻其他音軌正在發出同一音（含八度）的音。**第3階段**移除沒有位置的音，盡量保留最高音和最低音，先移除中間的音。**優先**音軌（標記為旋律的音軌會先被選上）的音在任何階段都不會移除；位置不夠時改為移除其他音軌的音（保護中聲部的旋律）。要移除的音會全部列出數量和位置（小節、拍、音高），並在條上以紅色顯示，套用按鈕上也會顯示要移除的音數。除了移除的音以外，會重新讀取遊戲輸出確認聲音不變。

- 與其他音軌重疊的音沒有地方可移，會保持不動。
- 如果與接收音軌前後的音相差超過完全五度，就不放入（避免旋律跳動）。會被 & 連起來的位置也不放入。
- 如果接收音軌會因此新超出字數上限，就不移動。無法清空音軌、只移動一部分時，若字數總和增加就不移動，所以 v 不同的較弱片段可能會留下。
- 鎖定的音軌，以及靜音、獨奏、聲道音量不同的音軌之間不會移動。
- 在預覽中查看各音軌字數的前後後再套用，可以用 Ctrl+Z 復原。

在 設定 → **和弦** 中設定匯入 MIDI 時合併和弦（預設開啟）與分成樂譜書之前先和弦分配（預設開啟）。

### 樂曲檢查

在狀態列的**檢查 N** 查看全曲的問題。

- 超出字數、速度、長度、音量範圍
- 超出樂器發聲範圍而發生**音域折回**的音（卷簾中顯示為灰色）
- 遊戲取樣結束，**後段不會發出聲音的長音**（遊戲中的聲音不會循環，響一次就結束）
- 一位演奏者的音軌數超過上限、同一演奏者的音軌之間相同音重疊
- 以 & 連結的兩個音跨越了音色邊界

## 10. 匯入 MIDI

用開啟樂譜選擇 .mid 後，會出現**匯入 MIDI** 視窗。

1. 查看每個 **MIDI 聲部**的音數、音域、同時音數，選擇要分配給哪位**演奏者**。也可以略過，或改為打擊樂器。沒有對應的樂器時，會先選擇相近的樂器。
2. 為每位演奏者設定**同時發音數**。全曲的合計會顯示在上方。
3. 選擇超出時的移除順序。
   - 從中間開始（保留兩端，預設）· 從下方開始 · 從上方開始 · 從力度較小的音開始 · 從短音開始
   - 優先刪減音符的聲部（雙手各半、先移除右手和弦、先移除左手和弦）、保護旋律
4. **節拍格線**（自動或手動）與**保留三連音**
5. **和弦合併**（預設開啟）：把和弦短暫變多的位置的音移到休止中的同一樂器音軌，不讓它們單獨留在一條音軌（見第 9 章和弦合併）。在填滿空聲道之前進行。
6. **填滿空聲道**：把因壓縮而移除的和弦音再放回休止中的聲道。超過字數上限時，會先移除放回的音。
7. 查看下方摘要（移除的音、放回的音、合併的音、最長的聲道字數）後點按**匯入**。

匯入 MIDI 並不是把原檔原封不動地搬過來。超過同時發音數的音會被移除，音長也會依節拍格線整理。匯入後請試聽，並修改需要調整的地方。

## 11. 儲存與檔案格式

| 格式 | 選單 | 用途 |
|---|---|---|
| **專案 .mme** | 儲存為專案（Ctrl+S） | **建議用於保存作品與移到其他裝置。** 會保留分數位置、音軌結構、編輯畫面狀態（也能開啟舊的 .mmlce） |
| 3MLE .mml | 儲存為 3MLE（Ctrl+Alt+S） | 在 3MLE 中開啟。預設為 CP949，沒有的字元會變成 ?，必要時請儲存為 UTF-8 |
| MabiIcco .mmi | 儲存為 MabiIcco（Ctrl+Shift+S） | 在 MabiIcco 中開啟。不符合格線（四分音符 96 格）的音會提示 |
| MIDI .mid | 儲存為 MIDI | 供 DAW 等使用。樂器轉為 GM 編號，大鼓、鈸放入鼓聲道。只以編號寫的附加音色包樂器（#42.3 等）依已載入音色包中找到的實際樂器存成 GM 編號，音高維持原樣。以 `&` 連結不同音高的地方，在 MIDI 中會存成分別彈奏的音 |
| WAV | 儲存為 WAV | 用目前的音色包把整首樂曲存成音訊檔（靜音、獨奏依實際聽到的狀態）。需要音色包 |
| MML@ 文字 | 匯出 MML | 貼到遊戲中 |

### 儲存位置

在設定 → **儲存**中設定。

- 電腦版 Chrome、Edge：預設為**每次儲存時選擇資料夾與檔名**。和開啟檔案時一樣會跳出儲存視窗，選擇資料夾與檔名；下次儲存會從上次的資料夾開始。WAV 會在製作完成後出現**儲存**按鈕，按下再選擇。
- 在這個方式下，以專案（.mme）儲存過一次（或以**開啟樂譜**開啟專案）後，下次儲存（Ctrl+S）會不跳出視窗、直接寫入同一個檔案。開啟的檔案在第一次儲存時會詢問一次是否允許寫入。要存成新檔案，請選擇檔案 → **另存新檔…**（快速鍵可在按鍵設定中指定）。檔案已移動或刪除而無法寫入時，會再次跳出儲存視窗。iPad、Safari 因瀏覽器限制，每次都以分享選單或下載儲存。
- 電腦版 Chrome、Edge：選擇**直接存到指定資料夾**並設定資料夾後，所有儲存的檔案都會不經詢問放進該資料夾。同名檔案會被覆寫（未命名的新樂譜不會覆寫，而是以 `new project 2` 這類新名稱儲存，之後都用該名稱），重新開啟瀏覽器後，第一次儲存時可能會再次要求允許使用資料夾。選擇**下載資料夾**則以瀏覽器下載方式儲存。
- iPad、iPhone：開啟**透過分享選單儲存**（預設開啟）時，儲存會開啟分享選單。可用「儲存到檔案」選擇資料夾，或直接傳到 Google 雲端硬碟等 App。
- 其他瀏覽器（Firefox 等）會存到下載資料夾。

專案（.mme）中包含與不包含的內容：

- 包含：樂譜、編輯畫面狀態、原曲與背景影片的**檔名與調整值**（偏移、琴鍵位置等）
- 不包含：音色包、原曲音訊與影片的**檔案本身**、主題與語言等應用程式設定

要在其他裝置上繼續作業，請另外準備音色包與原曲、影片檔案。重新選擇同名的原曲、影片後，會載入已儲存的調整值。

### 自動保留

編輯中的樂曲會自動保留在這個瀏覽器中（最近 10 個）。重新整理或關閉分頁後，可在第一個畫面或檔案 → **還原先前的作品…** 開啟。

> 自動保留**只是臨時復原用**。清除瀏覽器資料或空間不足時可能會消失。要長期保存的樂曲，請務必**儲存為 .mme**。iPad 建議存放在「檔案」App 中。

### 新版本

有新版本時，會出現「新版本已準備好」的提示列。點按**重新整理**後，會等編輯中樂曲的自動保留完成，再切換到新版本。若保留失敗，則不會切換並告知，此時請先儲存為專案（.mme）後再按一次。重要的作品在點按前先儲存為 .mme 會更安全。也可以關閉提示繼續作業。

每次開啟應用程式時都會檢查新版本；若長時間開著，回到視窗時最多每小時再檢查一次。想立即檢查，請按頂端列的 **?** → **檢查更新**。

| 快速鍵 | 開啟快速鍵設定（按鍵配置：BiNote 預設 / MabiIcco 相容，變更按鍵） |

**實驗室**是正式版之前先試用的功能。在 設定 → 實驗室 開啟後,頂端列會出現**實驗室**選單;關閉只會隱藏選單,樂曲維持原樣。結果是普通的 MML(v 與音高),遊戲和其他程式都照常播放。實驗室標記(用於還原與六線譜顯示)只存在 BiNote 專案檔(.mme)中。鋼琴卷軸中作用於選取的音,六線譜中作用於選取的音(沒有則為游標處的音)。

- **幽靈音**:把選取的音彈得比周圍的音小 N 級(預設 4 級)。每首曲子音量不同,所以不是固定的 v,而是以同一音軌最近的普通音的 v 為準(周圍是 v9 就變成 v5)。六線譜中幽靈音的數字會變淡。
- **泛音**:**自然**依六線譜中音所在的格計算(12 格 = 空弦 +12、7 格 = +19、5 格 = +24),六線譜上顯示為 `<12>`。**人工**比按住的音高八度,顯示為 `3<15>`(鋼琴卷軸中只能用人工)。音量可以小 N 級(預設 2 級)。
- 按視窗中的**解除實驗室標記**,選取的音中改成幽靈音・泛音的音會還原成原本的 v 與音高。
- **加入殘響**:遊戲沒有殘響效果,所以用音符模仿。把長音的後段切成同音高的小音,逐漸變小地重新彈。v 順序以 v15 彈的音為準(預設 6 3 2 1),其他 v 的音等比例降低(v9 為 4 2 1 1)。可選每段長度(預設 8 分)與保留的開頭(預設 4 分)。加在選取的音或整條音軌中此長度以上的音(預設 2 分音符),勾選**只加在後面有休止符的音**就只加在樂句結尾。開啟**補斷奏空檔**會在短音後的休止符小聲(預設 v4)補同一個音。切出的音不用 & 連接(遊戲會忽略 & 後的 v)。不會增加音軌但字數會增加,請看視窗中的字數。
- **殘響印章**:開啟鋼琴捲簾工具列的殘響印章(開啟實驗室後出現)再點音,就從點的位置切開。六線譜中用 實驗室 → **在游標處加殘響** 加在游標所在的音。點在音的開頭會保留開頭、從結尾放。使用 加入殘響 的尾巴設定。
- 殘響方法參考了 MabiIcco 樂譜製作指南的殘響效果段落。

最下方有版本資訊，以及使用指南、**關於 BiNote** 的連結。

頂端列設定（⚙）旁的 **?** 選單中有使用指南、快速鍵、檢查更新、關於 BiNote。在 **關於 BiNote** 視窗中可以查看版本、檢查更新，並開啟原始碼、授權與回報問題的連結。本使用指南也可以從狀態列的說明開啟。

## 14. 在 iPad・手機上使用

- **面板在側**是觸控的預設。iPad 直向畫面（以及直長的 PC 視窗）會分成上下兩部分，用面板頂端的 **結構 | MML** 選擇顯示哪一個。在 MML 中可從編輯器上方的音軌列直接切換音軌。
- 選取音符時用**選取工具**最安全（不會輸入或移動）。刪除用**橡皮擦**。
- **長按**音軌會開啟選單（上移、下移、複製音軌、移動、在下方編輯器開啟）。
- **長按**事件列的空白處可新增速度、標記。
- 用兩根手指縮放、移動卷簾。
- 開啟 **MML 鍵盤**（檢視選單）後，不用螢幕鍵盤也能輸入 MML 字元。
- 指法譜用**琴格數字鍵盤**輸入。
- iPad 的 Safari、Chrome 使用相同的引擎（WebKit），儲存空間可能會被清理。請把 **.mme 儲存到「檔案」App**。
- iPad、iPhone 的主畫面應用程式與 Safari 分頁的儲存空間是分開的，音色包必須各自加入，自動保留的樂曲也彼此看不到。
- iPad 無法使用 MIDI 鍵盤。

## 15. 常見問題

**沒有聲音。**
請查看狀態列，確認是否已加入音色包。若出現「音色包中找不到的樂器」，請再加入含有該樂器的音色包。若優先使用了其他音色包的聲音，請在設定的音色包清單中用▲▼調整順序。iPhone、iPad 請也確認靜音開關。

**貼到遊戲後出現錯誤。**
在「匯出 MML」視窗中查看錯誤、警告數量，再用狀態列的檢查找到位置修改。也請確認每次貼上是否只放入一段 MML@ 文字。

**試聽和遊戲中的聲音不一樣。**
試聽是用加入的音色包音色與 BiNote 的播放方式發聲。依音色包種類與樂器對應不同，可能與遊戲中的聲音有差異。音域折回（灰色）與取樣結束的長音，請在檢查結果中確認。

**字數一直超出。**
請依「和弦分配 → 減少字數 → 分割樂譜夾」的順序嘗試（第 9 章）。

**作品不見了。**
請查看檔案 → 還原先前的作品。iPad、iPhone 的主畫面應用程式與 Safari 分頁的自動保留彼此看不到。網站網址不同時（例如測試網址與正式網址），儲存空間也不同，自動保留不會轉移過去。要長期保存的樂曲請儲存為 .mme。

**儲存為 3MLE 後文字變成了 ?。**
這是 3MLE 預設編碼（CP949）中沒有的字元。請儲存為 UTF-8，或修改名稱。

**在 MabiIcco 中開啟後出現錯誤。**
若有不符合 MabiIcco 格線（四分音符 96 格）的音，儲存時會提示。請把這些音的長度對齊格線。
