# BiNote 使用指南

这是《玛奇 Mobile》MML 乐谱编辑器 **BiNote** 的使用说明，基于 1.0 Beta 版本编写。

本文中的游戏上限是 BiNote 在韩国服务器上实测得到的检查标准；部分游戏术语为临时译名，如有不妥，请通过翻译反馈表单告诉我们。

> 本工具是个人粉丝制作的非官方工具，与 Nexon 及《玛奇 Mobile》无关。游戏名称、乐器名称和声音的权利归 Nexon 所有。

## 1. 入门

### 打开方法

在网页浏览器（Chrome、Edge、Safari）中打开 BiNote 网站即可，无需安装。首次访问时会下载全部应用文件，之后没有网络也能打开。如果打算离线使用，请事先断开网络，确认能否重新打开。本指南是网上的文档，离线时无法打开。

如果经常使用，建议**添加到主屏幕（安装应用）**。

- 电脑版 Chrome、Edge：地址栏右侧的安装图标
- iPad、iPhone 的 Safari：共享 → 添加到主屏幕
- Android 的 Chrome：⋮ → 添加到主屏幕（安装应用）

安装的应用与浏览器标签页是否共用存储空间（音色包、自动保留），因设备而异。

- 电脑、Android：只要是同一浏览器、同一配置文件、同一网址，就会共用。
- iPhone、iPad：主屏幕应用与 Safari 标签页的存储空间是分开的。需要在主屏幕应用中再添加一次音色包，在标签页中自动保留的乐曲也看不到。

要把作品转移到其他设备或其他浏览器时，请保存为项目（.mme）文件后再打开。

### 开始界面

没有乐曲时，开始界面上有三个按钮。

| 按钮 | 作用 |
|---|---|
| 新建乐谱 | 从一份钢琴乐谱和一条空音轨开始（t120，4/4） |
| 打开乐谱 | 打开 3MLE（.mml）、MabiIcco（.mmi）、MIDI（.mid）、BiNote 项目（.mme） |
| 粘贴 MML@ | 粘贴游戏用的 `MML@…;` 格式乐谱文本并打开。在编辑器外按 Ctrl+V 也能打开 |

如果有正在编辑的乐曲，下方会显示**以前的作品**列表。即使刷新或关闭了标签页，也能在这里恢复。

### 音色包

**没有音色包也可以编辑。**要听到声音，请添加音色包（.dls、.sf2、.sf3）。玛奇音色包属于 Nexon 的资产，BiNote 不包含，请另行获取。

- 添加：设置（⚙）→ 音色包 → 添加音色包，或点击状态栏中的“无音色包”
- 添加多个时，**列表中靠上的包优先**使用。先添加的包排在上面。可用包旁的▲▼按钮调整顺序，下次打开时也会保持。
- 只以 MabiIcco 编号表示的乐器（例如 `#40.3`）不论顺序，只从符合 `.2`・`.3` 编号的包（按文件名判断）查找。不同包的同一编号可能是不同乐器，因此若没有该包，不会改用其他包，而是显示为找不到的乐器。竖琴（`24.2`）等已知名称的乐器会先使用符合编号的包，没有时改用其他包的同一乐器。
- 添加的包会保存在此浏览器中，下次打开时自动载入。文件不会发送到服务器。
- 如果有包中没有的乐器，会以“音色包中找不到的乐器”提示。

### 快速上手：制作第一份乐谱

1. 在开始界面点击**新建乐谱**。
2. 在钢琴卷帘的空白格处点击输入音符。如果想用 MML 书写，请在音轨面板的 MML 编辑器中输入下面的示例。
   ```
   t120o4l4v8cdefgab>c
   ```
3. 如果已添加音色包，按**播放**（Space）试听。即使没有音色包，也可以编辑和复制到游戏。
4. 用**文件 → 保存为项目**（Ctrl+S）保存 `.mme` 文件。保存为 3MLE（.mml）是 Ctrl+Alt+S。
5. 在**文件 → 放入游戏…**中确认错误、警告和字数。
6. 点击要使用的乐谱的**复制 MML@**，粘贴到游戏中的空白乐谱。有多份乐谱时逐份复制。

上面的示例是输入到音轨编辑器中的 MML。用**粘贴 MML@**打开时，请使用 `MML@t120o4l4v8cdefgab>c;` 这样的完整格式。

## 2. 先要了解的游戏规则

BiNote 按照《玛奇 Mobile》的上限进行检查和输出。下列术语在界面和本指南中含义相同。

| 术语 | 含义 |
|---|---|
| **乐谱** | 一次粘贴到游戏中的单位，即一个 `MML@音轨1,音轨2,…;` |
| **音轨** | 乐谱中的一行（旋律、和弦1~5）。一条音轨同一时间只发一个音 |
| **演奏者** | 在乐谱中负责一种乐器的人。一份乐谱中可以有多名演奏者 |
| **乐谱夹** | 把一首长曲分成多份乐谱接连演奏 |

游戏上限：

- 一份乐谱**最多 6 条音轨**。第一名演奏者 1~3 条音轨，之后的演奏者每人 1 条音轨（3+1+1+1、2+1+1+1+1、1×6 可以，2+2+2、3+3 不行）
- **音乐盒、留声机**一份乐谱 3 条音轨。6 声部和弦需要分成两份 3 条音轨的乐谱同时播放（两份粘贴文本都放入全部 6 条音轨，只改变顺序。游戏只演奏前 3 条音轨，但曲长与速度由 6 条音轨决定，两台不会错开）。另外设定乐器的音轨不能留在音乐盒乐谱，会移到新乐谱
- 每条音轨 **2400 字**
- **速度按乐谱分别读取**。因此 BiNote 在放入游戏时会为每份乐谱写入速度
- 速度 t32~t255，音长 1~64（最多一个附点），音量 v0~v15（v0 为无声）
- 每种乐器的发声音高范围是固定的，范围外的音不会报错，而是以八度为单位移动后在范围内发声。本指南把这称为**音域折返**
- 通过乐谱夹进入下一份乐谱时，会有约 1 秒的间隔

上述上限是 BiNote 当前在韩国服务器上实测得到的检查标准（截至 2026-10）。即使把界面语言切换为日语或中文，检查标准也不变，并不代表其他服务器的上限。还有一些项目尚未完成实测，例如同一演奏者的音轨之间相同的音重叠时的行为。

## 3. 界面概览

```
┌ 顶栏：文件 · 编辑 · 乐曲 · 视图 · 撤销 · 播放 · 音量 · 帮助（?） · 设置 ┐
├ 工具栏：钢琴卷帘/指法谱 · 工具 · 网格 · 新音符长度 · 输入 v · 横|竖（面板位置） · 图层 · 缩放 · ⋯          ┤
├ 工作区：钢琴卷帘（或指法谱）  │  音轨面板（结构列表 + MML 编辑器）                    ┤
└ 状态栏：所选音轨 · 字数 · 检查 · 音色包 · 帮助                                       ┘
```

### 菜单

| 菜单 | 包含的内容 |
|---|---|
| 文件 | 新建乐谱、打开乐谱、粘贴 MML@、恢复以前的作品、保存（3MLE、项目、MabiIcco、MIDI、WAV）、放入游戏、添加音色包、连接 MIDI 键盘 |
| 编辑 | 撤销、重做、全选、删除、剪切、复制、粘贴、长度 ×2、½、移调、拆分与合并音轨 |
| 乐曲 | 更改拍号、敲击测速、删除速度、批量修改速度、为每份乐谱写入速度、添加音轨、添加乐谱、音符重新分配、和弦合并、减少字数、拆分乐谱夹 |
| 视图 | 钢琴卷帘/指法谱、面板在下/面板在侧、并排、双编辑器并排、竖向卷帘、事件、音符列表、播放时点亮琴键、在 MML 中标出停止位置、音轨颜色、MML 键盘、快捷键 |

### 音轨面板

- **结构列表**：按乐谱 → 音轨的顺序显示。每条音轨有 M（静音）、S（独奏）、字数条、锁定，以及 ⋯ 菜单（上移、下移、复制音轨、移到其他乐谱、移到新乐谱/复制到新乐谱、在卷帘中隐藏）。有 MML 检查项的音轨会在名称旁显示红点和数量。
- 双击名称即可重命名（Enter 确认，Esc 取消）。
- 拖动左侧手柄可以把音轨移到其他乐谱。长按音轨（触屏）会打开菜单。
- **MML 编辑器**：修改所选音轨的 MML 文本。语法错误和游戏上限问题会以下划线显示，鼠标悬停在下划线上即可查看内容。
- 用工具栏右侧（图层左边）的 **横 | 竖** 按钮移动面板。**横**放在卷帘旁边（适合鼠标和触屏），**竖**放在卷帘下方（3MLE 式，适合键盘）。与视图菜单的面板在下/面板在侧相同。拖动分界线可调整大小。
- 开启**双编辑器并排**后，可在下方编辑器中打开另一条音轨（在列表中 Alt+点击）。

### 状态栏

- 所选音轨、字数 / 上限
- **检查 N**：全曲检查结果。点击展开，用“跳到该位置”前往问题所在处。
- 音色包数量和乐器数量
- **帮助**：钢琴卷帘和指法谱的操作摘要

## 4. 输入音符

在钢琴卷帘、MML 编辑器、指法谱中所做的修改都会反映到同一首乐曲中。

### 钢琴卷帘

| 操作 | 鼠标 | 触屏、触控笔 |
|---|---|---|
| 输入音符 | 点击空白格（拖动则按拖动长度） | 点按空白格 |
| 移动 | 拖动音符 | 拖动音符 |
| 改变长度 | 拖动音符末端 | 拖动音符末端 |
| 删除 | 右键点击 | 橡皮擦工具 |
| 选择多个音符 | Ctrl+点击，在空白处 Ctrl+拖动 | 用选择工具拖动 |
| 放置播放光标 | Shift+点击 | — |
| 循环区间 | Shift+拖动 | — |
| 用 & 与下一个音符连接 | Alt+点击 | — |

- **新音符**长度：选“按网格”时为网格一格；单独选择时不论网格都按该长度输入（包括三连音）
- **工具**：输入（默认）· 选择（只能点按或拖动来选中；解开旁边的锁后可拖动所选音符移动）· 橡皮擦 · 剪刀（在点按处切开音符）
- **图层**：在卷帘中只绘制所选音轨 / 同一乐谱 / 全部。其他音轨的音符显示为浅色，开启“点击其他音轨的音符以切换”后，点击即可切换到该音轨。
- 点击音符会在 MML 文本中标出该位置，双击则直接在那里输入。
- 移动画面：滚轮（时间）· Shift+滚轮（音高）· Ctrl+滚轮（时间缩放）· Ctrl+Shift+滚轮（琴键高度缩放）· 全部显示按钮
- **竖向卷帘**：对照下落音符视频输入时使用把设置 → 显示 → **播放时的卷帘**设为**连续滚动**后，播放时音符会从上方持续落到琴键（适合录制竖屏视频）。

### MML 编辑器

直接书写 MML。修改的文本会反映到钢琴卷帘和试听中。有语法错误时，请查看下划线和状态栏的检查。

| 指令 | 含义 |
|---|---|
| `c d e f g a b` | 音符（`+`、`#` 升，`-` 降），后接长度（`c8`、`e4.`） |
| `r` | 休止符 |
| `n数字` | 用音符编号书写 |
| `o数字` `<` `>` | 设定八度、降八度、升八度 |
| `l数字` | 默认长度 |
| `v数字` | 音量 0~15 |
| `t数字` | 速度 |
| `&` | 与下一个音符连接（相同的音持续发声，不同的音为滑音） |

- 用 `&` 连接相同的音时，& 后面的 v 在游戏中会被忽略。
- 用 `&` 连接不同音高时，不会重新弹奏，只在连接处改变音高（并不是平滑滑过去的声音）。BiNote 把这称为滑音。删除 `&` 后会变成分开弹奏的音符，演奏效果也会改变。
- 在 iPad 上开启 **MML 键盘**（视图菜单）后，会用 MML 字符键盘代替屏幕键盘。

### 指法谱（吉他谱）

用钢琴卷帘/指法谱按钮（Alt+T）切换。会汇集所选乐谱的音轨，自动选择弦和品位。

- 点击弦线放置光标，**用数字输入品位**（两位数连续输入），用方向键移动，用 Delete 删除
- `+` / `-`：将光标音的长度加倍 / 减半（新音符长度也一起改变）。在数字键盘改变**新音符**时，光标处音符的长度也会改变。加长时最多到同一音轨的下一个音之前
- 在已有的音上输入品位只改音高，长度不变
- `L`：用 & 与紧接的下一个音符连接 · `(5)` 延音 · `5/7` 滑音。后面是空的时，会按新音符长度添加同一个音并连接（八分音符 + L = 四分音符长度）
- 同一位置的和弦会进入同一乐谱的空音轨
- 可以选择调弦（标准、Drop D、DADGAD、Baritone 等）和变调夹
- 有多条音轨时，数字底色会以音轨颜色淡淡填充，未选中音轨的数字显示为浅色（可在 设置 → 显示 → 指法谱数字显示音轨颜色 关闭）
- 触屏上使用**品位数字键盘**。在键盘上方的**新音符**选择要输入的音长（按网格 / l4 / l8 / 三连音等，与工具栏的「新音符」是同一设置）。开启「输入后跳到下一格」时，光标会前进该音长

### MIDI 键盘

开启 文件菜单 → **连接 MIDI 键盘** 并连接 MIDI 键盘后，可进行逐个输入音符的**步进输入**。音符按**新音符**长度输入到播放光标处（没有时为所选音轨末尾），输入位置随之后移相同长度。不会根据按住琴键的时间来录制长度。

- 同时按下的音中，最高的音放入当前音轨，其余按从高到低的顺序放入同一乐谱的后续音轨。音符比剩余音轨多时，多出的音不会输入，因此输入和弦前请先确认音轨数量。
- 第一次开启 MIDI 键盘时，会询问一次是否把按键力度作为 v。之后可在 设置 → 播放 →“力度 → v”中更改。

> 推荐使用电脑版 Chrome、Edge。Safari（Mac、iPad）以及 iPad 上的其他浏览器无法使用 MIDI 键盘。

## 5. 修改音符

### 修改所选音符

| 作用 | 方法 |
|---|---|
| 逐格移动 | 方向键 |
| 升高、降低八度 | Shift+↑ / Shift+↓ |
| 提高、降低音量 | Alt+↑ / Alt+↓，Alt+滚轮 |
| 直接输入音量 | Alt+数字（6~9 → v6~9，0 → v10，1~5 → v11~15，Alt+\` → v0，Alt+Shift+0~5 → v0~5） |
| 长度 ×2 / ½ | Ctrl+] / Ctrl+[ |
| 精确设定长度 | 在状态栏的所选音符栏中输入 MML 长度（8、8.、16..）或分数后按 Enter。分数以全音符为单位，`1/7` 即全音符的七分之一。编辑时可以使用任意分数，但放入游戏时会换算为 1~64 长度（最多一个附点）的组合，无法准确写出时会发出警告 |
| 连接、解除连接 | Alt+L |
| 切开 | 剪刀工具，或在播放光标处按 Alt+S |
| 合并 | Alt+G（在编辑中把音高相同且相邻的音符合为一个。与用 & 连接不同） |
| 复制、剪切、粘贴 | Ctrl+C / Ctrl+X / Ctrl+V（粘贴到播放光标处） |

### 以乐曲为单位编辑

- **移调**（Alt+P）：以半音或八度为单位移动所选音符、此音轨、此乐谱或整首乐曲。会事先提示游戏中将发生音域折返的音符数量。
- **拆分与合并音轨**：把所选音符移到其他音轨（或新音轨），把乐谱的音轨合并为一条，或按音高重新拆分。重叠的音符不会移动，保留原位。
- **插入小节、删除小节**：在播放光标处插入或删除一个小节（所有音轨和速度一起处理）。
- **音轨锁定**：点击锁图标后，该音轨在卷帘、指法谱和编辑器中都无法修改，但仍可选择和复制。移调时，如果范围中包含已锁定的音轨，会在确认后一起移动。工具栏中选择工具旁边的锁（拖动移动所选音符）是与音轨锁定不同的功能。

### 撤销

Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z）。全曲命令也能一次撤销。

## 6. 速度·拍号·标记

### 事件行

卷帘上方两行会显示速度、拍号、标记。一开始就是开启的，可用视图 → **事件**开关（会记住你的选择）。

- 双击空白处（触屏为长按）或右键点击标签即可添加和修改。
- 拖动标签可移动；在速度标签上滚动滚轮可 ±1（Shift ±10），按 Del 删除。
- 键盘：**Alt+B** 在光标处添加速度，**Alt+M** 添加标记

### 拍号

乐曲 → 更改拍号。从播放光标所在的小节开始改变（没有光标时从乐曲开头改变）。6/8、9/8、12/8 以三个八分音符为一拍显示。

### 敲击测速

乐曲 → 敲击测速。播放原曲（或视频），**在每小节第一拍按 T** 键或 [敲击]，停止时就会写入速度。

- 如果第一拍听不清，请改为**每拍**，像数拍子一样按。
- 敲击测速栏中的**合并细微速度变化**（弱 30ms · 中 60ms · 强 100ms）：在所选范围内偏差的敲击会视为手抖，合并为一个速度。速度指令数和 MML 字数也会减少。

### 整理速度

- **批量修改速度**：可以将整首乐曲的速度统一为一个值（**全部改为**）、全部加减相同数值（**± BPM**），或按百分比修改（**%**）。如果设置了循环区间，则只修改区间内的速度，区间之后的速度保持不变。所有乐谱的 MML 文本也会一并修改，超出游戏速度范围（t32~255）时会提前提醒。按一次 Ctrl+Z 即可撤销。
- **删除全部速度**：只保留乐曲开头的速度。如果设置了循环区间，则只处理区间内。
- **为每份乐谱写入速度**：把乐曲速度写进缺少速度的乐谱的 MML 文本中。（即使不执行此操作，“放入游戏”和“拆分乐谱夹”也会为每份乐谱写入速度）
- 超出游戏范围（t32~t255）的速度在编辑时也可以使用，“放入游戏”会告诉你如何修改（见下方第 9 章）。

## 7. 调整音量（v）

### 输入 v

工具栏中的**输入 v** 是新输入音符的音量。选“沿用”时跟随前一个音符的 v。选中音符后会变为**所选音符 v**，可一次性修改。

### 音量栏

钢琴卷帘下方的 **音量 (v)** 条就是音量栏。收起时，用琴键条一侧角落的 **音量 ▲** 按钮打开。一根竖条代表一组用 `&` 连接的音符，右侧数字是 v 刻度。

- **画笔**：把拖动经过的竖条的 v 改为该高度。
- **直线**（或 Shift+拖动）：从按下处到松开处，把 v 改成一条直线。
- 如果事先选中了音符，只会改变这些音符。
- **一次修改多条音轨**：在音轨列表中按 Ctrl+点击，加入要一起修改的音轨。旋律音轨照搬画出的值，其余音轨按上、中、下的位置分别加上设定的量。若没有旋律标记，乐谱的第一条音轨就是旋律。
- 音量栏可切换细、大、收起。拖动音量栏上方的把手可调到任意高度（从细条拖动也可以），双击则在细和大之间切换。也可以在设置 → 显示 → **音量栏** 选择高度。用笔绘制时放大会更好画。

## 8. 对照原曲和视频扒谱

### 原曲

在工具栏 ⋯ → **原曲…** 中选择音频或视频后，会与乐谱一起播放。文件只在本设备上使用，不会发送到服务器。

- **偏移（ms）**：原曲较晚时为 +。用于对齐开头。
- **原曲音量**：原曲的音量
- **波形**：在卷帘小节编号行下方，按乐曲时间显示原曲波形。
  - 点击波形即跳到该位置。
  - **拖动波形上的小节线**放到原曲的拍子上，会调整速度让该小节落在那里。
  - 拖动波形的空白处，原曲会前后移动，偏移随之改变。

### 背景视频

工具栏 ⋯ → **背景视频…**（在钢琴卷帘中）。把下落音符视频（钢琴演奏视频等）铺在钢琴卷帘背景上，一边看视频一边输入音符。

- **对齐琴键**：设定视频最左端、最右端琴键和琴键上沿线后，就会与卷帘琴键重合。开启**用控制点对齐**后，可在卷帘上拖动对齐。
- **对齐卷帘**：按视频的琴键范围移动并放大卷帘。
- 可调整不透明度、偏移（秒）、时间拉伸、视频声音。
- **播放视频**：不播放乐曲，只播放视频，卷帘会跟随。

### 搭配使用

- **竖向卷帘**：与下落音符视频的方向一致。选择设置 → 显示 → 播放时的卷帘 → **连续滚动**，即使没有视频也会像下落音符一样流动。
- **播放时点亮琴键**（默认开启）：在琴键上显示正在播放的音。可在视图菜单或 设置 → 播放 中关闭。
- 设置 → 播放 → **画面同步校正**：播放线比声音快时为 +，落后时为 −。iPad 和蓝牙耳机可能还需要多 100~300ms。

## 9. 放入游戏

在文件 → **放入游戏…** 中确认输出结果并复制。

### 放入游戏窗口

显示每份乐谱的字数、音轨数、折返的音符、错误和警告，每份乐谱都有一个**复制 MML@**按钮。

1. 点击复制按钮。按钮变为“已复制”即表示复制成功。如果没有变化，请检查浏览器的剪贴板权限。
2. 在游戏中打开空白乐谱并粘贴。**一次只能粘贴一份乐谱**。
3. 其余乐谱也逐份复制并粘贴。

- 速度会写入每份乐谱。
- 输出用的 MML 会以较少的字数重新写出，不会改变编辑器中的文本。
- 如果速度变化位于该乐谱所有音轨的音符中间，为避免舍弃音符，会写在紧随其后的音符边界上并给出提示。

### 速度超出游戏范围时

比 t255 快时，会告诉你如何缩短该区间的音长并降低速度；比 t32 慢时，会告诉你如何延长音长并提高速度。实际快慢不变。

### 字数超出时

请按顺序尝试。

1. **音符重新分配**：把超出上限的音轨中的音符移到同一演奏者的空闲音轨。由于在同一乐器内移动，音符的排布保持不变。（适用于乐谱中有多条同一乐器音轨的情况）分配后仍有超出的音轨时，可以用预览中的 **添加音轨后重新分配** 在同一乐谱添加一条空音轨。音轨已满的乐谱添加音轨会多出一份同一乐器的乐谱（游戏中一起演奏的人多一位），如果要一个人演奏请改用拆分乐谱夹。
2. **减少字数**：保持音符的音高、开始位置和长度不变，把所有音轨的 MML 重写得更短。手动写的空格、换行和注释会消失。如果压缩会导致音符丢失，则不作修改并给出提示。
3. **拆分乐谱夹**：在同一位置切开所有音轨，分成多册。
   - **先重新分配音符再拆分**（默认开启）：拆分前先在同一乐器的音轨之间移动音符，让各通道长度平均。如果所有通道都在上限之内就不拆分；如果能减少册数，就用移动后的结果拆分。正在编辑的曲子不会改变，按“也应用到曲子”才会移动曲子中的音符（可用 Ctrl+Z 撤销）。关闭后只拆分乐谱夹，如果移动音符能减少册数，只显示“N 册 → M 册”的提示。
   - **仔细拆分**（默认关闭）：在每册的结尾多追踪几个接近上限的位置，寻找册数更少的分法。比较花时间，拆分时下方会显示步骤和进度条。较短的曲子不开这个选项也会精确找出最少册数。
   - 优先选择全部休止的位置。
   - 每册都会重新写入八度、音量和速度。
   - 下一册开始得晚多少（约 1 秒），就让前一册提前结束多少，以对齐节拍。如果这段补偿区间内有音符，音符可能变短或被去掉。请查看结果中的“在末尾被截断的音符”和长度警告，试听册与册交界处前后后再使用。

音符重新分配和减少字数会在**预览**中显示修改前后的字数，确认后再应用。已应用的修改可以用 Ctrl+Z 撤销。拆分乐谱夹不会修改原来的乐曲，只生成每册的输出结果。请使用各册中每份乐谱的复制按钮。

### 和弦合并

导入 MIDI 时，和弦短暂变多的位置的音符可能会留下只有零星几个音符的音轨。乐曲菜单 → **和弦合并** 会把这类音轨中的音符，移到同一乐谱、同一乐器在那个时间休止的音轨，并删除音符全部移走后变空的音轨（乐谱有两份以上、删除会让后面的音轨移到前一份乐谱时，则保留为空音轨）。声音不变，不会去掉或缩短任何音符。

- 与其他音轨重叠的音符没有地方可移，会保持不动。
- 如果与接收音轨前后的音符相差超过纯五度，就不放入（避免旋律跳动）。会被 & 连起来的位置也不放入。
- 如果接收音轨会因此新超出字数上限，就不移动。无法清空音轨、只移动一部分时，若字数总和增加就不移动，所以 v 不同的较弱片段可能会留下。
- 锁定的音轨，以及静音、独奏、通道音量不同的音轨之间不会移动。
- 在预览中查看各音轨字数的前后后再应用，可以用 Ctrl+Z 撤销。

在 设置 → **和弦** 中设置导入 MIDI 时合并和弦（默认开启）与分成乐谱书之前先重新分配音符（默认开启）。

### 乐曲检查

在状态栏的**检查 N**中查看全曲的问题。

- 字数超出，速度、长度、音量超出范围
- 超出乐器发声范围而发生**音域折返**的音符（在卷帘中显示为灰色）
- 因游戏采样结束而**后半部分不发声的长音**（游戏的声音不会循环，响一次就结束）
- 一名演奏者的音轨数超出，同一演奏者的音轨之间相同的音重叠
- 用 & 连接的两个音符跨越了音色边界

## 10. 导入 MIDI

用“打开乐谱”选择 .mid 文件后，会弹出**导入 MIDI**窗口。

1. 查看每个 **MIDI 声部**的音符数、音域、同时发音，选择要分配给哪名**演奏者**。也可以选择排除或转为打击乐。没有对应的乐器时，会先选好相近的乐器。
2. 为每名演奏者设定**同时发音数**。全曲同时发音数的合计显示在上方。
3. 选择在超出处去除音符的顺序。
   - 从中间开始（保留两端，默认）· 从下方开始 · 从上方开始 · 从力度较小的音符开始 · 从短音开始
   - 优先删减音符的声部（双手各半、先去右手和弦、先去左手和弦）、保护旋律
4. **节拍网格**（自动或手动指定）和**保留三连音**
5. **和弦合并**（默认开启）：把和弦短暂变多的位置的音符移到休止的同一乐器音轨，不让它们单独留在一条音轨（见第 9 章和弦合并）。在填充空通道之前进行。
6. **填充空通道**：把压缩时去掉的和弦音重新放入空闲的通道。超过字数上限时，先去掉放入的音符。
7. 查看下方的摘要（去除的音、重新放入的音、合并的音、最长通道的字数）后点击**导入**。

导入 MIDI 并不是原样搬运原文件。超出同时发音数的音符会被去掉，音长也会按节拍网格整理。导入后请试听，并修改需要调整的地方。

## 11. 保存与文件格式

| 格式 | 菜单 | 适用场合 |
|---|---|---|
| **项目 .mme** | 保存为项目（Ctrl+S） | **推荐用于保存作品和转移到其他设备。**会保留分数位置、音轨结构和编辑界面状态（也能打开旧版 .mmlce） |
| 3MLE .mml | 保存为 3MLE（Ctrl+Alt+S） | 在 3MLE 中打开。默认为 CP949，不支持的字符会变成 ?，必要时请保存为 UTF-8 |
| MabiIcco .mmi | 保存为 MabiIcco（Ctrl+Shift+S） | 在 MabiIcco 中打开。不符合网格（四分音符 96 格）的音符会给出提示 |
| MIDI .mid | 保存为 MIDI | 用于 DAW 等。乐器换成 GM 编号，大鼓和钹放入鼓通道。只用编号写的附加音色包乐器（#42.3 等）按已加载音色包中找到的实际乐器保存 GM 编号，音高保持原样。用 `&` 连接不同音高的地方，在 MIDI 中会保存为分开弹奏的音符 |
| WAV | 保存为 WAV | 用当前音色包把整首乐曲保存为音频文件（静音和独奏按实际听到的状态）。需要有音色包 |
| MML@ 文本 | 放入游戏 | 粘贴到游戏中 |

### 保存位置

在设置 → **保存**中设定。

- 电脑版 Chrome、Edge：默认为**每次保存时选择文件夹和文件名**。和打开文件时一样会弹出保存窗口，选择文件夹和文件名；下次保存会从上次的文件夹开始。WAV 会在制作完成后出现**保存**按钮，按下再选择。
- 电脑版 Chrome、Edge：选择**直接保存到指定文件夹**并设定文件夹后，所有保存的文件都会不经询问放进该文件夹。同名文件会被覆盖，重新打开浏览器后，第一次保存时可能会再次请求允许使用文件夹。选择**下载文件夹**则以浏览器下载方式保存。
- iPad、iPhone：开启**通过共享菜单保存**（默认开启）时，保存会打开共享菜单。可用“存储到文件”选择文件夹，或直接发送到 Google 云端硬盘等应用。
- 其他浏览器（Firefox 等）保存到下载文件夹。

项目（.mme）中包含和不包含的内容：

- 包含：乐谱、编辑界面状态、原曲和背景视频的**文件名及对齐数值**（偏移、琴键位置等）
- 不包含：音色包、原曲音频和视频的**文件本身**、主题和语言等应用设置

要在其他设备上继续编辑，请另行准备音色包以及原曲和视频文件。重新选择同名的原曲或视频后，会载入保存的对齐数值。

### 自动保留

正在编辑的乐曲会自动保留在此浏览器中（最近 10 首）。刷新或关闭标签页后，可在开始界面或文件 → **恢复以前的作品**中打开。

> 自动保留**仅用于临时恢复**。清除浏览器数据或空间不足时可能会丢失。需要长期保存的乐曲请务必**保存为 .mme**。在 iPad 上建议保存到“文件”App 中。

### 新版本

有新版本时，会显示“新版本已就绪”提示条。点击**刷新**后，会等待正在编辑的乐曲完成自动保留，再切换到新版本。如果保留失败，则不会切换并给出提示，此时请先保存为项目（.mme），然后再点一次。重要的作品在点击前先保存为 .mme 会更安全。也可以关闭提示继续工作。

每次打开应用时都会检查新版本；如果长时间开着，回到窗口时最多每小时再检查一次。想立即检查，请点顶栏的 **?** → **检查更新**。

## 14. 在 iPad 和手机上使用

- 触屏默认为**面板在侧**。iPad 竖屏时分为上下两部分。
- 选择音符时用**选择工具**更安全（不会输入或移动音符）。删除用**橡皮擦**。
- **长按**音轨会打开菜单（上移、下移、复制、移动、在下方编辑器中打开）。
- **长按**事件行的空白处可以添加速度和标记。
- 用两根手指缩放和移动卷帘。
- 开启 **MML 键盘**（视图菜单）后，无需屏幕键盘即可输入 MML 字符。
- 指法谱用**品位数字键盘**输入。
- iPad 上的 Safari 和 Chrome 使用相同的引擎（WebKit），存储空间可能会被清理。请把 **.mme 保存到“文件”App 中**。
- iPad、iPhone 上的主屏幕应用与 Safari 标签页存储空间分开，需要分别添加音色包，自动保留的内容也互相看不到。
- iPad 上无法使用 MIDI 键盘。

## 15. 常见问题

**没有声音。**
请查看状态栏，确认是否已添加音色包。如果出现“音色包中找不到的乐器”，请再添加包含该乐器的包。如果优先使用了其他包的声音，请在设置的音色包列表中用▲▼调整顺序。iPhone、iPad 还请检查静音开关。

**粘贴到游戏中后出错。**
在“放入游戏”窗口中查看错误和警告数量，再用状态栏的检查找到位置并修改。还请确认是否一次只粘贴了一份乐谱。

**试听和游戏中的声音不一样。**
试听使用所添加音色包的音色和 BiNote 的播放方式发声。根据包的种类和乐器对应关系，可能与游戏中的声音不同。音域折返（灰色）和采样结束的长音请在检查结果中确认。

**字数一直超出。**
请按音符重新分配 → 减少字数 → 拆分乐谱夹的顺序尝试（第 9 章）。

**作品不见了。**
请查看文件 → 恢复以前的作品。在 iPad、iPhone 上，主屏幕应用与 Safari 标签页的自动保留互相看不到。网站地址不同时（例如测试地址与正式地址），存储空间也不同，自动保留不会转移过去。需要长期保存的乐曲请保存为 .mme。

**保存为 3MLE 后，字符变成了 ?。**
这些是 3MLE 默认编码（CP949）中没有的字符。请保存为 UTF-8，或修改名称。

**在 MabiIcco 中打开时出错。**
如果有不符合 MabiIcco 网格（四分音符 96 格）的音符，保存时会给出提示。请把这些音符的长度调整到符合网格。
