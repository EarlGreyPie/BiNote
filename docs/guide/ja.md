# BiNote ガイドブック

マビノギモバイル向けMML楽譜エディタ **BiNote（バイノート）** の使い方の案内です。1.0 Beta 時点の内容です。

> ネクソン・マビノギモバイルとは関係のない、非公式の個人ファン制作ツールです。ゲーム名・楽器名・音の権利はネクソンに帰属します。

このガイドのゲームの上限は韓国サーバーで実測したBiNoteの検査基準であり、一部のゲーム用語は暫定的な翻訳のため、誤りがあれば[翻訳の報告](#16-問題翻訳の報告)でお知らせください。

## 1. はじめに

### 開き方

Webブラウザ（Chrome・Edge・Safari）でBiNoteのサイトを開きます。インストールせずに使えます。最初のアクセスでアプリのファイルをすべて受け取っておけば、それ以降はインターネットなしでも開けます。オフラインで使う予定なら、事前にネットワークを切って開き直せるか確認しておいてください。このガイドブックはインターネット上の文書のため、オフラインでは開けません。

よく使う場合は **ホーム画面に追加（アプリのインストール）** をおすすめします。

- PCのChrome・Edge: アドレスバー右側のインストールアイコン
- iPad・iPhoneのSafari: 共有 → ホーム画面に追加
- AndroidのChrome: ⋮ → ホーム画面に追加（アプリをインストール）

アプリをインストールすると、ファイルを直接BiNoteで開けます。

- PCのChrome・Edgeにインストールしたアプリ: エクスプローラーなどで .mme・.mml・.mmi・.mid ファイルを **BiNoteで開く**（プログラムから開く）で開きます。ファイルごとに新しいウィンドウで開きます。
- Androidにインストールしたアプリ: ほかのアプリの **共有** メニューにBiNoteが表示されます。MML@ テキストや楽譜・音源ファイルを共有すると、BiNoteですぐに開きます。

インストールしたアプリとブラウザのタブが保存領域（サウンドパック・自動保存）を共有するかどうかは、端末によって異なります。

- PC・Android: 同じブラウザ、同じプロファイル、同じアドレスなら共有します。
- iPhone・iPad: ホーム画面のアプリはSafariのタブと保存領域が別です。ホーム画面のアプリでもう一度サウンドパックを追加する必要があり、タブで自動保存された曲も表示されません。

別の端末や別のブラウザに作業を移すときは、プロジェクト（.mme）ファイルとして保存して開いてください。

### 最初の画面

曲がないとき、最初の画面にはボタンが3つあります。

| ボタン | 内容 |
|---|---|
| 新しい楽譜 | ピアノの楽譜1つ、空のトラック1つで開始（t120、4/4） |
| 楽譜を開く | 3MLE（.mml）、MabiIcco（.mmi）、MIDI（.mid）、BiNoteプロジェクト（.mme）を開く |
| MML@ を貼り付け | ゲーム用の `MML@…;` 形式の楽譜テキストを貼り付けて開く。エディタの外でCtrl+Vを押しても開けます |

編集中の曲があると、その下に **以前の作業** の一覧が出ます。再読み込みしたりタブを閉じたりしても、ここから復元できます。

### ファイルのドラッグ＆ドロップ

ファイルをBiNoteのウィンドウのどこかにドラッグして離すと、すぐに開きます。ドラッグ中はウィンドウ全体に案内が表示されます。

- 楽譜（.mme・.mml・.mmi・.mid・.musicxml）は「楽譜を開く」と同じように開きます。原曲の音源・動画は原曲として、サウンドパック（.dls・.sf2・.sf3）はサウンドパックとして追加します。
- 楽譜1つと原曲1つは一緒にドロップできます。プロジェクトに保存された原曲の合わせ値（ずれなど）を、一緒にドロップした原曲に使います。楽譜や原曲を2つ以上ドロップすると最初のものだけを開き、開かなかったファイルをお知らせします。サウンドパックはドロップした分だけ追加します。
- プロジェクトとして保存せずに直した曲があると、今の楽譜を閉じるか先に確認します。
- エディタの外にMML@ テキストをドロップすると **MML@ を貼り付け** の画面が開きます。

### MML@ を貼り付け

ゲーム用の `MML@…;` テキストを貼り付けて開きます。画面下の **新しい曲として開く** は新しい曲として、**今の曲に追加** は今の曲に楽譜を追加します。

- テキストに楽譜が複数あると、**演奏者に分ける** と **冊としてつなぐ** から選べます。演奏者に分けると楽譜ごとに演奏者1人になり、一緒に鳴ります。冊としてつなぐと1人の演奏者の楽譜集の冊（1冊目、2冊目…）とみなし、ゲームが次の冊へ移るときに休む間だけ空けて順につなぎます。文字数は冊ごとに数えます。
- 楽譜のすぐ上の行に楽器名や「2冊目」「(1/3)」「2권」のような冊の表記があれば読み取り、演奏者名・楽器・冊の順番をあらかじめ入れます。演奏者ごとに楽器を変えられ、上の行がなければ選んだ楽器を使います。冊としてつなぐときは、冊の表記を除いた名前が同じ楽譜どうしが1人の演奏者になります（上の行がなくすぐ続く楽譜は前の楽譜と同じ演奏者）。
- **今のトラックに上書き**: テキストの中のトラック1つ（複数あれば選んで）で、今選んでいるトラックのMMLテキストを置き換えます。元に戻すことができ、ロックしたトラックには使えません。

### サウンドパック

**編集はサウンドパックがなくてもできます。** 音を聞くには、サウンドパック（.dls・.sf2・.sf3）を追加してください。マビノギのサウンドパックはネクソンの資産のためBiNoteには含まれていません。別途ご用意ください。

- 追加: 設定（⚙）→ サウンドパック → サウンドパックを追加、またはステータスバーの「サウンドパックなし」をクリック
- 複数追加すると、**一覧の上にあるパックが優先** されます。先に追加したパックが上に置かれます。パックの横の▲▼ボタンで順序を変えられ、変えた順序は次に開いたときもそのままです。
- MabiIccoの番号だけで書かれた楽器（例: `#40.3`）は順序に関係なく、`.2`・`.3`の番号に合うパック（ファイル名で判別）だけから探します。パックごとに同じ番号が別の楽器のことがあるため、そのパックがなければ他のパックで代わりに鳴らさず、見つからない楽器としてお知らせします。ハープ（`24.2`）のように名前が分かる楽器は番号に合うパックを先に使い、なければ他のパックの同じ楽器を使います。
- **トラックごとに鳴らすパックを選べます。** トラックエディターの見出しで楽器の選択の横にあるパックの選択（パックが2つ以上のとき表示）でパックを選ぶと、そのトラック（トラックの楽器がなければその楽譜）はそのパックで鳴ります。既定は **自動（上のパックから）** です。選んだパックが今なければ上のパックから探して鳴らし、パック名の後ろに「（なし）」を付けて表示します。曲には選んだパック名が残るので、そのパックを再び追加するとそのパックで鳴ります。`.2`・`.3`のパックを選ぶと、MabiIcco形式で保存するときの楽器番号にもそのパック番号が入ります。
- 楽器番号に`.2`・`.3`のパック番号がある楽器は、トラックエディターの楽器の選択、トラック帯の楽譜チップ、見つからない楽器のお知らせで **ハープ(24.2)** のようにパック番号も表示します。基本の楽器は名前だけ表示します。
- 追加したパックはこのブラウザに保存され、次に開いたときに自動で読み込まれます。ファイルをサーバーへ送信することはありません。
- パックにない楽器があると「サウンドパックで見つからなかった楽器」としてお知らせします。

### クイックスタート: 最初の楽譜を作る

1. 最初の画面で **新しい楽譜** をクリックします。
2. ピアノロールの空いているマスをクリックして音を入力します。MMLで書く場合は、トラックパネルのMMLエディタに次の例を入力します。
   ```
   t120o4l4v8cdefgab>c
   ```
3. サウンドパックを追加していれば、**再生**（Space）で聞いてみます。サウンドパックがなくても、編集とゲーム用のコピーはできます。
4. **ファイル → プロジェクトとして保存**（Ctrl+S）で `.mme` ファイルを保存します。3MLE（.mml）での保存はCtrl+Alt+Sです。
5. **ファイル → MMLで書き出す…** でエラー・警告と文字数を確認します。
6. 使う楽譜の **MML@ をコピー** をクリックし、ゲームの空の楽譜に貼り付けます。楽譜が複数ある場合は1つずつコピーします。

上の例はトラックのエディタに入れるMMLです。**MML@ を貼り付け** で開くときは、`MML@t120o4l4v8cdefgab>c;` のように全体の形式で書きます。

## 2. 先に知っておきたいゲームのルール

BiNoteはマビノギモバイルの上限に合わせてチェックと出力を行います。次の用語は、画面とこのガイドブックで同じ意味で使います。

| 用語 | 意味 |
|---|---|
| **楽譜** | ゲームに一度に貼り付ける単位。`MML@トラック1,トラック2,…;` 1つ |
| **トラック** | 楽譜の中の1行（メロディ・和音1〜5）。1つのトラックは一度に1音だけ鳴らします |
| **演奏者** | 楽譜の中で楽器1つを担当する人。1つの楽譜に複数の演奏者が入れます |
| **楽譜集** | 長い曲を複数の楽譜に分けて続けて演奏すること |

ゲームの上限:

- 1つの楽譜に **トラックは最大6個**。最初の演奏者が1〜3トラック、その後の演奏者は1トラックずつ（3+1+1+1、2+1+1+1+1、1×6は可、2+2+2、3+3は不可）
- **オルゴール・蓄音機** は1つの楽譜に3トラック。6和音は3トラックの楽譜2つに分けて同時に鳴らします（どちらの貼り付けにも6トラックをすべて入れ、順番だけ変えます。ゲームは前の3トラックだけを鳴らし、曲の長さとテンポは6トラックで決まるので2台がずれません）。別の楽器を設定したトラックはオルゴールの楽譜に置けないため、新しい楽譜に移します
- 1トラックに **2400字**
- **テンポは楽譜ごとに別々に** 読まれます。そのためBiNoteはMMLで書き出すとき、すべての楽譜にテンポを入れます
- テンポ t32〜t255、音長 1〜64（付点1つまで。いちばん短い64分音符にも付点が付き、`64.` = 3/128 まで使えます）、音量 v0〜v15（v0は無音）
- 楽器ごとに鳴る高さが決まっていて、範囲外の音はエラーにならずオクターブ単位で移され、範囲内で鳴ります。このガイドではこれを **音域の折り返し** と呼びます
- 楽譜集で次の楽譜に移るとき、約1秒のすき間ができます

上記の上限は、韓国サーバーで実測したBiNoteの現在の検査基準です（2026-10時点）。画面の言語を日本語・中国語に変えても検査基準は同じで、ほかのサーバーの上限を表すものではありません。同じ演奏者のトラック同士で同じ音が重なったときの動作など、まだ実測が終わっていない項目もあります。

## 3. 画面の見方

```
┌ 上部バー: ファイル · 編集 · 曲 · 表示 · 元に戻す · 再生 · 再生オプション · 音量 · ヘルプ(?) · 設定 ┐
├ ツールバー: ピアノロール/タブ譜 · ツール · グリッド · 新しい音 · 入力 v · 横|縦（パネル位置） · レイヤー · 拡大 · ⋯      ┤
├ 作業領域: ピアノロール(またはタブ譜)  │  トラックパネル(構成一覧 + MMLエディタ)           ┤
└ ステータスバー: 選択中のトラック · 文字数 · MMLカーソル · チェック · サウンドパック · ヘルプ   ┘
```

### メニュー

| メニュー | 項目 |
|---|---|
| ファイル | 新しい楽譜、楽譜を開く、MML@ を貼り付け、以前の作業を復元、プロジェクトとして保存（.mme）・名前を付けて保存、**別の形式で保存 ▸**（3MLE・MabiIcco・MIDI・WAV）、MMLで書き出す、サウンドパックを追加、MIDI鍵盤を接続 |
| 編集 | 元に戻す・やり直し、すべて選択、編集カーソルより前の音・後ろの音をすべて選択、削除・切り取り・コピー・貼り付け、音を複製、**音を直す ▸**（長さ ×2・½、付点、音量・オクターブの上げ下げ、タイ、分割、結合）、アルペジオ、スライド、装飾音、元に戻す(作る前へ)・もう一度直す、アルペジオとして認識 |
| 曲 | 曲の情報、移調、音量の一括調整、和音減衰、トラックの分割・結合、拍子を変更、**テンポ ▸**（タップテンポ・テンポを削除・テンポを一括変更・楽譜ごとにテンポを入れる）、ずれた長さを探す、トラック・楽譜を追加、**文字数を合わせる ▸**（音符の再配分・和音の統合・文字数を減らす・楽譜集に分割） |
| 表示 | ピアノロール/タブ譜、パネルを下/横、並べて表示、**エディタ数 ▸**、縦ロール、イベント、音一覧、停止位置をMMLに表示、他のトラックの音をクリックして選択、MMLキーパッド、タブのフレット数字パッド、カーソルを追う、ショートカット、**言語 · Language ▸** |

▸ が付いた行はサブメニューです。押すと開きます。PCでは横に開き、マウスを乗せても開きます。iPadや狭い画面では同じパネルがサブメニューに切り替わり、一番上の ‹ の行で戻ります。キーボードでは、メニューボタンで ↓ を押して入り、↑↓ で選び、→（または Enter）で開き、← で閉じます。サブメニューの中の項目でもショートカットはそのまま使えます。再生中に鍵盤を光らせる・選んだ音の鍵盤を光らせる・トラックの色は設定にあります。

### 再生

上部バーの再生ボタン（先頭へ・再生・停止・ループ区間）の横にあるメーターのボタンが **メトロノーム・予備拍・再生速度** メニューです。選んだ内容はこのブラウザに記憶します（既定はすべてオフ、100%）。再生速度が100%でないときは、ボタンの横に75%のように表示されます。

- **メトロノーム**: 再生中、拍ごとにクリック音を鳴らします。小節の1拍目は高い音です。再生中にオン・オフしてもすぐに反映されます。
- **1小節の予備拍**: 止まった状態から再生を始めると、1小節分の拍を数えてから始めます。拍の途中から始めても、クリックは曲の拍に合います。再生中に位置を移したときは数えません。
- **再生速度**（100・90・75・60・50%）: 原曲・MML・背景動画が一緒に遅くなります。原曲はテープのように音が低くなります（75%で約5半音、50%で1オクターブ）。曲のテンポは変わりません。タップテンポのバーが開いている間は、そのバーの再生速度を使います。

再生カーソルはキーボードでも移せます。**Home** は曲の先頭、**End** は曲の終わり（一番遅く終わる音の終わり）、**Ctrl+←/→** は前・次の小節の頭です（MabiIcco互換のキー設定ではF4/F6）。小節は拍子の変化に沿って数えます。再生中に押すとその位置から続けて再生し、前の小節へを続けて押すとさらに前の小節へ戻ります。タブ表示ではタブカーソルも一緒に移ります。MMLエディタで入力している間は、Home・End・Ctrl+←→ はテキストのカーソルを動かします。

### トラックパネル

- **構成一覧**: 楽譜 → トラックの順に表示されます。トラックごとにM（ミュート）・S（ソロ）、文字数バー、ロック、⋯ メニュー（上へ移動・下へ移動・トラックを複製・別の楽譜へ移動・新しい楽譜へ移動/複製・ロールで非表示）があります。MMLのチェックがあるトラックは、名前の横に赤い点と件数が表示されます。 トラックの文字数は**書き出すとき(ゲームに入れる文字列)の文字数**です。コメント・改行・空白や重なったv・lは書き出しで省かれるため、エディタの原文より短いことがあり、違うときはエディタの見出し行に原文の文字数も表示します。赤くなるのは書き出し時の文字数が上限を超えるときだけです。
- 名前はダブルクリックで変更します（Enterで確定、Escでキャンセル）。
- 左のハンドルをドラッグして、トラックを別の楽譜に移せます。トラックを長押しする（タッチ）とメニューが開きます。
- **トラックの色**: トラックを右クリック（タッチは長押し）→ **トラックの色…** で12色のどれかかほかの色を選ぶと、その色がトラックに固定されます。トラックの順番を変えたり別の楽譜に移したりしても色がついて回り、ファイルに保存されます。**今の色で固定** は今見えている色をそのまま固定し、**色の固定を解除** は設定のトラックの色の方式に戻します。固定したトラックはメニューに（固定）が付きます。すべてのトラックの色を順番に関係なく保つには、設定 → 画面 → トラックの色を **トラックごとに固定** にします（楽譜内の位置・楽譜ごとの色系統は順番を変えると色も変わります）。
- **MMLエディタ**: 選択中のトラックのMMLテキストを編集します。文法エラー・ゲームの上限の問題は下線で示され、下線にマウスを乗せると内容が表示されます。
- パネルはツールバー右側（レイヤーの左）の **横 | 縦** ボタンで移動します。**横** はロールの横（マウス・タッチ向け）、**縦** はロールの下（3MLE式、キーボード向け）です。表示メニューのパネルを下/横と同じです。境目をドラッグしてサイズを変えます。
- 表示 → **エディタの数**（1〜4個、最大数は設定 → 画面）でトラックパネルにMMLエディタを上下に並べ、複数のトラックの文を一度に見られます。上は選んだトラックで、一覧・トラック帯でAlt+クリックしたトラックは一番長く変えていない下のエディタで開きます（エディタが1つなら2つに増やします）。同じトラックを2つのエディタで開くことはなく、下のエディタはそれぞれ × で閉じます。

### ステータスバー

- 選択中のトラック、文字数 / 上限
- **MMLカーソル 3:2**: MMLエディタのテキストカーソルがある位置の小節:拍です（エディタにカーソルがあるとき）。
- **自動保存されていません**: 自動保存ができていないときだけ表示されます。[もう一度試す]・[.mmeで保存] を押せます（11章 自動保存）。
- **チェック N**: 曲全体のチェック結果。クリックすると展開され、「その位置へ移動」で問題の位置に移動します。
- サウンドパック数と楽器数
- **ヘルプ**: ピアノロール・タブ譜の操作のまとめ

## 4. 音を入力する

ピアノロール・MMLエディタ・タブ譜で編集した内容は、すべて同じ曲に反映されます。

### ピアノロール

| 操作 | マウス | タッチ・ペン |
|---|---|---|
| 音を入力 | 空いているマスをクリック（ドラッグした分だけ長く） | 空いているマスをタップ |
| 移動 | 音をドラッグ | 音をドラッグ |
| 長さの変更 | 音の端をドラッグ | 音の端をドラッグ |
| 削除 | 右クリック | 消しゴムツール |
| 複数の音を選択 | Ctrl+クリック、空いている所でCtrl+ドラッグ | 選択ツールでドラッグ |
| 再生カーソルを置く | Shift+クリック | — |
| ループ区間 | Shift+ドラッグ | — |
| 次の音と & でつなぐ | Alt+クリック | — |

- **ドラッグ中にグリッドを切る**: 音をつかんでドラッグしている間に **Alt** を押し続けると、グリッドを一時的に切り、ゲームで使える一番短いマス（1/64、今のグリッドの方が細かければそのグリッド）で動きます。Alt+クリックは & でつなぐ操作なので、音をつかんでから押します。
- **端での自動スクロール**: 音のドラッグ、四角での選択、ループ区間の指定で画面の端まで持っていくと、手を止めていても画面がついてスクロールします。
- **消える音のプレビュー**: 1つのトラックは一度に1音しか出さないので、置いた音と重なった前の音は終わりが切られ、その中で始まる音は削除されます。音を描く・移動する・長さを変える間、失われる部分（切られる音は後ろの部分、削除される音は全体）を赤い斜線で表示します。置いたあとは「重なった音2個の終わりを切りました」のように、いくつ切られたか・削除されたかをステータスバーでお知らせします。矢印キーでの移動・貼り付け・複製・ステータスバーの選択した音の欄での長さ入力も同じようにお知らせします。元に戻すで戻せます。

- **新しい音** の長さ: 「グリッドどおり」ならグリッド1マス分、別に選ぶとグリッドに関係なくその長さ（3連符を含む）
- **連符**: 新しい音の長さ一覧の一番下の **連符…** で「N個をどの音符の長さに」を選びます（2〜15個、全・2分・4分・8分・16分・32分音符とその付点音符）。1音の長さは基準の数字×Nです: 4分5連符 = l20、4分7連符 = l28、付点4分2連符 = l8.。選んだ連符が新しい音の長さになり、**グリッドもそのマスにする**（既定オン）でグリッドも変わります（4分5連符なら1/20）。ゲームは l1〜l64 しか受け付けないので、16分5連符（l80）のように短い音は選べません（丸めません）。決めた連符はこのブラウザに記憶します
- グリッド一覧には、決めた連符のマスと新しい音の長さに合うマスも出ます。付点4分5連符（l20.）なら 1/40 が出ます。1マスが 1/64 より短いグリッド（1/128 など）は、その長さの音・休符をゲーム用に書けないため出しません。64. の後ろに続けて入れるときはタブの数字パッドか MML テキストを使います
- ゲーム用に正確に書けない長さの音や休符が残る編集（例: 4分5連符の音を 1/28 グリッドで切ると 1/70 の切れ端が残る）は行わず、理由を表示します。入力・切る・貼り付け・長さ変更・移動・アルペジオ・スライド・装飾音・トリルだけでなく、小節を削除、トラックの分割・結合、音符の再配分・和音の統合のような曲の編集もすべて同じです。MMLテキストを直接書いたり貼り付けたりしたものだけは書いたとおりに残します
- **ツール**: 入力（標準）・選択（クリックやドラッグで選ぶだけ。横の鍵を外すと選択した音をドラッグして移動）・消しゴム・はさみ（クリックした位置で音を分割）
- **レイヤー**: ロールに選択中のトラックだけ / 楽譜 / すべてを描きます。他のトラックの音は薄く表示され、「他のトラックの音をクリックして選択」をオンにするとそのトラックに切り替えます。
- 音をクリックするとMMLテキストでその位置を表示し、ダブルクリックするとその場で入力できます。
- 画面の移動: ホイール（時間）・Shift+ホイール（音の高さ）・Ctrl+ホイール（小節を広く・狭く）・Ctrl+Shift+ホイール（鍵盤を大きく・小さく）・曲全体を表示ボタン。Ctrl+ホイールはマウスの下の位置を、Ctrl+Shift+ホイールはマウスの下の音をそのままにして拡大・縮小します。拡大ボタンとメニューは画面に見えている再生線（なければカーソル）を基準にし、どちらも画面の外なら画面の始まりを基準にします
- ロール右下の隅のボタンでも拡大・縮小（⇆−/+ 小節を狭く・広く、⇅−/+ 鍵盤を小さく・大きく）と曲全体を表示ができます（縦ロールでは鍵盤の帯の上の右側）。ふだんは薄く表示されます。設定 → 実験室 で **ボタン名を表示** をオンにすると、マウスや浮かせたペン（Apple Pencil のホバー・Sペンのエアビュー）を乗せるかキーボードで来たときにボタンの上に名前が出ます。タッチでは長押しで出ます（長押しは押したことになりません）。画面がとても狭いときは鍵盤を小さく・大きくをツールバーや ⋯ メニューで使います
- 設定 → 画面 → **音符の音量の数字** をオンにすると、選んだトラックの音の上に `v12` のように音量が出ます（縦ロールでは音の始まりの右）。**変わるところだけ** は前の音と音量が違う音と画面で最初に見える音に、**すべての音** はすべての音に書きます。`&` でつないだ後ろの音には書かず、混み合うと重なる数字は飛ばします（拡大すると見えます）
- 設定 → 画面 → **音色の境目を表示** をオンにすると、選んだトラックの楽器がゲームでサンプル（音色）を切り替える高さ（ピアノ・ギターは o3e・o4e・o5f・o6f、楽器ごとに違う）に薄いアクセントカラーの線が引かれ、区間が一つおきに薄い背景で塗られます。左の鍵盤にも境目の位置に短い線が出ます。`&` でつないだ音が境目をまたいでゲームで音色が跳ねる所は、タイ線が赤くなり後ろの音の始まりに赤い点が付きます（すべてのトラック、トラックごとにその楽器で判断）。範囲外の音は折り返して鳴る高さの区間に従い、範囲外の境目は薄い点線です。音の選択やドラッグには影響しません（既定はオフ）
- **縦ロール**: 落ちてくるノーツの動画を見ながら打ち込むとき設定 → 画面 → **再生中のロール**を**連続スクロール**にすると、再生中に音が上から鍵盤へ降り続けます（縦動画の録画用）。

### MMLエディタ

MMLを直接書きます。編集したテキストはピアノロールと試聴に反映されます。文法エラーがあれば、下線とステータスバーのチェックを確認してください。

| コマンド | 意味 |
|---|---|
| `c d e f g a b` | 音（`+`・`#` でシャープ、`-` でフラット）、後ろに長さ（`c8`、`e4.`） |
| `r` | 休符 |
| `n番号` | 音番号で書く |
| `o番号` `<` `>` | オクターブの指定、下げる、上げる |
| `l番号` | 基本の長さ |
| `v番号` | 音量 0〜15 |
| `t番号` | テンポ |
| `&` | 次の音とつなぐ（同じ音はタイ、異なる音はスライド） |

- 同じ音を `&` でつなぐと、& の後の v はゲームで無視されます。
- 異なる高さを `&` でつなぐと、弾き直さずにつないだ位置で高さだけが変わります（滑らかにつながる音ではありません）。BiNoteではこれをスライドと呼びます。`&` を消すと別々に弾く音になり、演奏が変わります。
- iPadでは **MMLキーパッド**（表示メニュー）をオンにすると、画面キーボードの代わりにMML文字のキーパッドを使えます。
- **検索・置換**: **Ctrl+F** で検索、**Ctrl+H** で置換し、**F3**・**Shift+F3** で次・前の見つかった位置へ移ります。大文字と小文字を区別・正規表現・単語単位でも検索できます。エディタ1つはトラック1つなので、選んでいるトラックのテキストの中だけを検索します。エディタの外で押しても、選んでいるトラックのエディタに移ります。すべて置換も元に戻す1回で戻ります。ロックしたトラックは検索だけできます。
- **テキストカーソルに追従**: エディタでテキストカーソルを動かすと（クリック・矢印キー・検索）、再生カーソルがその位置へ移り、音の文字の上ならピアノロールでその音を選んで見える位置へ移ります。再生中は再生位置を変えません。ステータスバーにはテキストカーソル位置の小節:拍が「MMLカーソル 3:2」のように表示されます。

### タブ譜（ギター譜）

ピアノロール/タブ譜ボタン（Alt+T）で切り替えます。選択した楽譜のトラックをまとめ、弦・フレットを自動で選びます。

- 弦の上をクリックしてカーソルを置き、**数字でフレットを入力**（0〜24、2桁は続けて入力）、矢印キーで移動、Deleteで削除
- キーボードや数字パッドでカーソルを動かして画面の外に出ると、画面が追って送られます（表示 → **カーソルを追う** でオン・オフ。既定はオン）
- 一番上の **小節番号の行** を押すとその位置から再生し（再生中ならそこから続けて再生、再生位置をもう一度押すと消去）、ドラッグすると繰り返し区間を決めます（ピアノロールと同じ。タッチも指でドラッグ）。再生位置・繰り返し区間はピアノロールと共通なので、表示を切り替えてもそのままです。キー設定の **再生位置を編集カーソルへ** にキーを割り当てると、再生位置をタブのカーソル位置へ移せます（既定のキーなし）
- `+` / `-`：カーソルの音の長さを2倍 / 半分に（新しい音の長さも変わります）。数字パッドでは **新しい音** を変えるとカーソルの音の長さも変わります。伸ばすときは同じトラックの次の音の手前まで
- `.`：付点を付ける・外す。選んだ音、選んでいなければカーソルの音（つないだ音ならカーソルのある音）に付点を付けたり外したりします（4分音符 ↔ 付点4分音符）。カーソルの音もなければ新しい音の長さに付けます。数字パッドには音符入力パッドの端に **.** ボタンがあります
- 既存の音の上でフレットを打つと高さだけ変わり、長さはそのままです
- `L`: すぐ後の音と & でつなぐ・`(5)` タイ・`5/7` スライド。後ろが空いていれば同じ音を新しい音の長さだけ足してつなぎます（8分音符 + L で4分音符の長さ）
- 同じ位置の和音は、同じ楽譜の空いているトラックに入ります
- チューニング（スタンダード・ドロップD・DADGAD・ナッシュビル・バリトンなど）とカポを選べます
- 違うチューニングでTABを入力してしまったら、チューニングの横の **TABはそのままチューニング変更…** を使います。弦・フレットの数字はそのままで、音の高さを新しいチューニング（カポ含む）のものに変えます。元に戻す1回でチューニングも一緒に戻ります。楽譜集の「up 1/2 step」チューニングは同じチューニングにカポ1で表せます
- 一覧にないチューニングは、チューニング欄の **直接入力…** で弦ごとに開放弦の音とオクターブを決めます。1弦がいちばん高い弦（TABのいちばん上）で、ナッシュビルのように1オクターブ上に張った弦はそのオクターブのまま入力します。プリセットを読み込んで直したり、**全体を半音下げる・上げる** で全部の弦を一度に動かしたり、弦の数（1-12弦）を変えたりできます。直接入力したチューニングは楽譜ごとに .mme に保存されます。カポでは下げられない「down 1/2 step」チューニング（例: 半音下げた部分ナッシュビル・バリトン A♭ D♭ G♭ B E♭ A♭）はこの方法で決めてください。入力済みのTABの数字をそのままにするには、**TABはそのままチューニング変更…** で **直接入力** を選びます
- 拡大ボタンは、PC（マウス）ではピアノロールと同じく上のツールバー（入力 v の後ろ）に、タッチ画面ではタブ譜下のツール帯（時間スクロールバーの横）にあります。小節を狭く・広く（⇆−/+）で小節の幅を、PCツールバーの **曲全体を表示** で曲全体が一画面に収まるように合わせます（ツールバーが狭いときは `A−` / `A+` と指板の位置は ⋯ メニューにあります）
- 設定 → 画面 → **音符の音量の数字** をオンにすると、指板の一番下（弾けない音の × の下）に `v` の行ができ、選んだトラックの音の音量をピアノロールと同じ決まりで書きます。選んだ音の数字は濃く出ます。オフにすると行はなくなります
- `A−` / `A+` でタブ譜の大きさ（弦の間隔・文字）を、その横の **指板の位置** ボタン（⤒ / ↕ / ⤓）で、高さに余りがあるとき指板を枠の上・中央・下のどこに置くかを選びます。押すたびに上 → 中央 → 下と変わり（既定は中央）、このブラウザに記憶します。フレット数字パッドを開いても同じ位置のまま（パッドを除いた残りの高さの中で）で、パッドの一番上の列にも同じ指板の位置ボタンがあります
- トラックが複数あると数字の枠がトラックの色で薄く塗られ、選択中でないトラックの数字は薄く表示されます（設定 → 画面 → タブ譜の数字にトラックの色 でオフにできます）
- タッチでは **フレット数字パッド** を使います。パッド上部の **新しい音** で入れる音の長さを選びます（グリッド通り / l4 / l8 / 3連符など。ツールバーの「新しい音」と同じ設定）。「入力後に次のマスへ」をオンにすると、その長さだけ進みます
- フレット数字の上には **音符入力パッド** が1列あります（グリッド / 1 / 2 / 4 / 8 / 16 / 32 / 64。幅が足りなければ横にスクロール）。押されているボタンが新しい音の長さで、カーソルに音があればその音の長さも変わります。付点は列の端の **.** ボタンで付けます。3連符（3・6・12・24・48）のボタンは 設定 → 画面 → **音符入力パッドに3連符** をオンにすると表示されます。決めた連符（例: 20）のボタンは 設定 → 画面 → **音符入力パッドに連符** をオンにすると末尾に表示されます。設定 → 画面 → **タブの数字パッドで数字を押した後** でカーソルの移動先を選びます: **次のマスへ**（既定、入れた長さだけ）/ **下の弦へ（和音）**（同じ位置で1本下、一番下の弦ならそのまま）
- 表示 → **タブのフレット数字パッド** をオンにすると、マウスで指板を押してもフレット数字パッドが開きます（オフならタッチ・ペンのみ）。このブラウザに記憶します
- 数字パッドは右上の **×** で閉じます（Esc も同じ）。閉じた後は指板の弦をもう一度押すか、タブ下のツールバーの **数字パッド** ボタンで開き直します。カーソルがなければ今見えている最初のマスに置きます
- 上の変化の行はピアノロールと同じく2段です：**上の段はテンポ、下の段は拍子・マーカー**（ピアノロールと同じ順番・色）。上の段を **ダブルクリック**（タッチ・ペンは長押し）すると、その位置にテンポを入れます（曲の最初に4/4があっても、上の段ならテンポが入ります）。下の段の空いた場所をダブルクリックするとマーカーを入れます。テンポの文字ならそのテンポを、拍子の文字なら拍子を直します（新しい拍子は拍子の文字を直すか、ツールバーの **拍子** 欄で）。`Alt+B` でもできます（タブのカーソル位置、なければ編集カーソルか曲の最初）。空いた場所にマウスを乗せると段ごとにこの案内が出ます。変化の行を **1回クリック** すると、ピアノロールのイベント行と同じく、その位置へ再生位置（点線）が移ります。変化の行は小節番号の行と同じ背景色で塗られ、タブの線と見分けられます。文字の大きさは 設定 → 画面 → **イベント行の文字（タブ・ピアノロール）** で 10・13（標準）・16・20px から選びます（ピアノロールのイベント行も同じ設定）。ダブルクリックで開く画面にはテンポ・拍子・マーカーの欄が並び、複数チェックするとその位置にまとめて入れ、既にあるもののチェックを外すと消します（元に戻す1回）
- ツールバーの **拍子** 欄でも、タブのカーソルがある小節（カーソルがなければ再生カーソルの小節か曲の最初）から拍子を変えられます
- ピアノロールで入れたマーカーも下の段に出ます（マーカーは曲に1組で、2つの表示が共有します）。マーカーの文字を **ダブルクリック**（タッチ・ペンは長押し）するとマーカーのウィンドウが開き、名前を直したり消したりできます。長い名前は最初の12文字だけを書いて…を付け、マウスを乗せると全体の名前が出ます
- **音の選択**: `Shift+←/→` でカーソル位置から時間の範囲を広げたり狭めたりすると、その範囲で始まる音を弦・トラックに関係なくすべて選びます（縦1列すべて）。マウスは `Shift`+クリック（カーソルからクリックした位置まで）・`Shift`+ドラッグ、`Ctrl+A` はタブ譜に表示中のトラックの音をすべて選びます。タッチでは数字パッドの **選択** ボタンをオンにして指板を押しながら範囲を広げます（もう一度押すか Esc でオフ）。選んだ数字はアクセント色で薄く塗られ、`Shift` なしのクリック・方向キー・Esc で解除されます。音を選んでいるときの `Shift+↑/↓` はピアノロールと同じくオクターブを上げ下げし、選択は残るので続けて押せます(キー設定でオクターブのキーを変えた場合はそのキー)
- 選んだ音には編集メニューとショートカットがピアノロールと同じように使えます: 削除（Delete）・切り取り・コピー・貼り付け、長さ ×2・½（`+`/`-`、伸ばすときは選んでいない次の音の手前まで）、オクターブ・音量の上げ下げ、タイ（`L`）、分割（Alt+S、タブのカーソル位置）、結合（Alt+G）。オクターブを変えてその弦で弾けなくなると弦を選び直します。何も選んでいなければ Delete・`L`・`+`/`-` はこれまでどおりカーソルの音に使われます。ロックしたトラックが含まれると変更せずにお知らせします
- **和音のコピー・貼り付け**: タブ譜でコピーするとトラックの分け方のまま保ち、タブ譜に貼り付けるとタブのカーソル位置（なければ元の位置）から、最初の層を最初のトラック、次の層を次のトラックに入れます。そのトラックに重なる音があれば空いたトラックを探し、足りなければ楽譜のトラック上限までトラックを追加します。上限のため1つでも入らなければ何も貼り付けずにお知らせします。ピアノロールに貼り付けるとき和音が重なる場合は貼り付けずにお知らせします（1つのトラックには一度に1音しか入りません）

### MIDI鍵盤

ファイルメニュー → **MIDI鍵盤を接続** をオンにしてMIDI鍵盤をつなぐと、1音ずつ入力する **ステップ入力** ができます。再生カーソルの位置（なければ選択中のトラックの末尾）に **新しい音** の長さで入力し、入力位置がその長さだけ後ろへ進みます。鍵盤を押していた時間で長さを録音するわけではありません。

- 一緒に押した鍵盤は、どれかを離したときに1つの和音として入ります（押すタイミングが少しずれても構いません）。最も高い音が現在のトラックに、残りが高い順に同じ楽譜の次のトラックへ入ります（ロックしたトラックは飛ばします）。次のトラックが足りなければ楽譜のトラック上限までトラックを追加し、上限を超える音は入力せずにお知らせします。
- 鍵盤をオンにしている間は、数字キーで新しい音の長さを直接選びます: **1〜6** は全音符・2分・4分・8分・16分・32分、**7・8** は8分・16分3連符、**0** は休符（カーソルを新しい音の長さだけ進める）、**.** は付点です。このとき数字キーはグリッドの代わりに新しい音の長さを変えます（文字入力欄ではそのまま）。
- MIDI鍵盤を初めてオンにしたとき、ベロシティを v として入れるかを一度だけ聞きます。あとで 設定 → 再生 →「ベロシティ → v」で変えられます。

> 推奨ブラウザはPCのChrome・Edgeです。Safari（Mac・iPad）とiPadのその他のブラウザでは、MIDI鍵盤を使えません。

**アルペジオ**（編集メニュー）: ピアノロールで音を選んで開くと、和音を順番に広げます。方式は3つです。**1つのトラックに広げる** は選んだトラックのその位置に和音の音を順に入れ（和音トラックの音は消すか残すかを選べます）、**分散和音（元の長さのまま）** は元の和音の音を残したまま開始だけ順に遅らせ、**トラックを順に繰り返す** は音の長さごとに同じ楽譜のトラックを順に使って弾き直します（足りなければトラック上限の範囲でトラックを足します）。和音の音は 同じ時刻に始まる音 / 選んだ音だけ / コード名（メジャー・マイナー・7・M7・m7・sus4・sus2・dim・aug・add9）から取り、順序（上へ・下へ・上下・ランダム）、音の長さ（三連符 l3・l6・l12・l24・l48 と決めた連符を含み長さ順）、オクターブの幅（1〜3）、繰り返しを選びます。**別の長さ**で、いちばん低い音・いちばん高い音・その両方に別の長さを付けられます。長さはその音から次の音が出るまでの間隔なので、いちばん低い音 8・音の長さ 16 なら、広げる・繰り返しはベースを8分音符で弾いてから上の音を16分音符で続け、分散和音はベースの後に8分音符あけて上の音を16分音符間隔で鳴らします。いちばん低い・高いは、一巡する順番の中での音です。プレビューで確かめて適用し、元に戻す1回で戻ります。同じ時刻の音では、プレビューの上の **和音に入れるトラック** をチェックで選びます（選んだトラックは常に入ります）。選んだ音の最初の開始から最後の開始まで、チェックしたトラックの音が一緒に始まる位置ごとに和音になるので、音を1つ選ぶだけでもその位置の和音全体を使えます。枠は選んだ音より長い和音の音があればその音の終わりまでです（長いベースを切りません）。

- **ギター譜の波線の和音** は **分散和音 + 64分** で作ります。新しい音を作らず、元の和音の音をその場（トラック・音量・タブの弦はそのまま）に残して開始だけ順に遅らせ、終わりはそれぞれ元のままです。**上へ = 低い音から**（ギターの6弦側から）、下へ = 高い音から。分散和音はオクターブの幅・繰り返しを使いません。同じ時刻の音ならその位置の和音全体を、選んだ音だけなら選んだ音だけを分散し、コード名は新しい音が要るため同じ時刻の音で分散します。タブでは弦ごとに別トラックにある選んだ音（カーソル位置ならその位置の和音）をまとめて使います。短すぎて遅らせられない音はそのままにします。
- トラックを順に繰り返す方式は新しい音を作りますが、同じ高さの元の音のトラック・音量・タブの弦を引き継ぎ、元の和音の音が短くなる枠は作らずにお知らせします。チェックを外したトラックは読みも変えもしません。
- **タブ譜表示**でも使えます。タブ譜で選んだ音があればその音、なければ **タブのカーソル位置の和音**（その位置で始まる同じ楽譜の音）を使います。

**スライド**（編集メニュー）: ギターのように滑る音を作ります。**2つの音の間** は続いている2つの音の間を半音ずつつなぐ短い音で埋め、**スライドイン・アウト** は音の前の部分を何半音か下（上）から始めたり、終わりの部分で落としたりします。つなぐ音は `&` で結ぶので弾き直さず高さだけが変わります。スライドの長さと1歩の長さ（自動ならゲームの最短音長に合わせて分け、足りなければ半音を飛ばします）を選びます。つなぎの最初の音から24半音を超える所は作らず、高い方へ長く滑るとサンプルの終わりで音が早く切れることがあるので事前に知らせます。つなぐ音1つごとに数文字増えて文字数が早く増えるので、ウィンドウの文字数の案内を確かめてください。

- ピアノロールとタブ譜のどちらからも開けます。タブ譜では選んだ音、選んだ音がなければカーソル位置から始まる和音全体が対象です。
- **スライドイン・アウト** は1つの音にスライドインとスライドアウトを両方付けます（タブ譜の `/14\`、`\14/`）。イン・アウトごとに方向（下から・上から / 下へ・上へ）、距離（フレット = 半音）、長さを別々に選びます。アウトの音は音の終わりの部分から取ります。
- 入る位置 **拍の上**（既定）は到着音の頭を削るので到着音が少し遅れて聞こえ、**拍の前** は装飾音の拍の前と同じく前の音の終わり（または前の休符）から長さを取るので到着音が拍どおりに聞こえます。前の音が l64 より短く残るか正確に書けない場合、その音は飛ばします。
- 和音を選ぶと弦（トラック）ごとに自分のトラックで一緒にスライドします。空いた所から和音全体へのスライドイン（例: `2/1/2/1/`）が一度ででき、2つの和音を選んで **2つの音の間** を選ぶと弦ごとに前の和音から次の和音へ滑ります。トラックを新しく作らないので和音数の上限は変わりません。
- **音色が変わる所で切る**（既定オン）: ゲームは `&` でつないだ音がサンプル区間の境目（o3e・o4e・o5f など、楽器ごとに違う）をまたぐと別のサンプルに切り替えるため音色が跳ねます。オンにすると作ったつなぎのその位置で `&` を外して弾き直します。オフならプレビューに赤い点線で示して知らせます。試聴の音はサウンドパックのサンプルがゲームと違うので変えず、表示だけで知らせます。
- 元からある `&` が音色の境目をまたぐと曲の検査に出ます。検査欄の **すべて切る** でそのような `&` を一度に外せます（元に戻す1回、ロックしたトラックはそのまま）。スライドは元からある `&` を勝手に消しません。

**装飾音を入れる**（編集メニュー）: 選んだ音（主音）の前に短い装飾音を付けます。ピアノロールでは選んだ音、タブでは選んだ音か、選んでいなければカーソル位置の音に付けます。高さはタブでは主音の弦のフレット番号（例: 主音6フレットに `6 8`）、ピアノロールでは主音からの半音数（例: `-2` または `-1 +1`）を空白で区切って入力し、入力した数だけ装飾音ができます。装飾音の長さは l64・l48・l32・l24・l16 から選びます。MML には長さのない装飾音がないため、どちらかの長さを実際に短くします。**拍の上で**（既定）は装飾音が拍に合わせて鳴り、主音がその分遅れて始まります。主音が和音なら同じ奏者のほかのトラックの和音の音も一緒に遅れ、ほかの奏者はそのままです。**拍の前で**は主音がそのままの位置で鳴り、装飾音が前の音（または休符）の終わりを削って入ります。曲の最初の音や前の音が短すぎる場合は使えません。短くなる音はゲームの最短の長さ（l64）以上を残し、正確に書ける長さだけを使うので、長さの一覧にその長さで入れられる最大数（例: 8分音符に l64 なら7個）が表示され、それより多いと入れません。複数のトラックの和音の音を一緒に選ぶと、いちばん高い音に1回だけ付けます。**&でつなぐ**をオンにすると（既定はオフ）装飾音と主音を `&` でつなぎ、弾き直さずに高さだけが変わります（ハンマリング・プリングのような音）。&でつながれて弾き直さない音には付けません。

**トリル・トレモロ**（編集メニュー）: 選んだ音を同じ長さの短い音いくつかに分けます。ゲームのMMLにはトリル記号がないので、音を実際に分けて書きます。選び方は装飾音と同じです（ピアノロールは選んだ音、タブは選んだ音か、何も選んでいなければカーソル位置の音）。**トリル**は主音と相手の音を交互に弾きます。相手の音はタブでは主音の弦のフレット番号（例: 5フレットの音に `7`）、ピアノロールでは主音からの半音数（`+1` 半音上、`+2` 全音上、`-1` 半音下）で入力します。同じ奏者の和音をまとめて選ぶと一番高い音にだけかけ、ほかはそのままです。**トレモロ**は同じ音を繰り返し、選んだ和音の音はトラックごとに全部繰り返します。速さは**音1つの長さ**（l64-l8）で選ぶのでテンポに合わせて変わり、画面に最初の音の位置のテンポで毎秒何回かも出ます。主音の長さが割り切れないときは余りを最後の音に足します（例: 3連の4分音符をl32で分けるとl32を4つとl24を1つ）。丸めないので、最後の長さを正確に書けないときや主音が音1つの長さの2倍より短いときはその音を飛ばし、理由を出します。トリルには**相手の音から弾く**、**主音で終える**（最後が相手の音なら前の主音にまとめる）、**&でつなぐ**（弾き直さず高さだけ変える。ハンマリングのようにだんだん小さくなります）があります。音がとても増えて文字数も大きく増えるので（4分音符1つをl32で分けると2文字が13文字ほど）、画面の下に増える文字数と上限を超えるかを出します。相手の音が楽器の音域外でゲームがオクターブごと折り返すと間隔が変わるので、その音は飛ばします。タブの弦は主音のままで、vもvの形が全部同じ（既定）なら主音のままです。 **vの形**で分けた音の強さを変えられます: 全部同じ（既定）・1つおきに小さく・最初の音だけ強く・拍ごとに強く（4分音符の位置で始まる音）・だんだん大きく・だんだん小さく。小さい音は主音のvから**小さい音を下げる**段階だけ低く、**全体を下げる**は分けた音全体を下げます（速く弾き直すと大きく聞こえるとき）。vの範囲（0-15）の外には出ず、vが変わるたびに2-3文字増えます。**切って弾く**をオンにすると音ごとに前半だけ鳴らし、後半は休符にします（音1つの長さl32以上、次の音と&でつながった音は飛ばす、&でつなぐとは一緒に使わない、トラックの最後の音なら最後の音は切らないので曲の終わりが短くならない）。&でつなぐをオンにするとゲームは最初の音のvだけで鳴らすので、vの形は使わず全体を下げるだけを使います。選んだ速さがゲームでぼやけるほど速いと（毎秒20回超え、バイオリン・フルートは12回超え）知らせます。ゲーム実測では、だんだん大きく・小さくが一番はっきりし、拍ごとに強くは中くらい、1つおきに小さくは速いとほとんど聞こえません。切って弾くは強さが同じでくっきりします。速く弾き直すと1音より大きくなって減らないので、**全体を下げる**は既定が**自動**（1音 −3、和音 −5）です。

**元に戻す(作る前へ)・もう一度直す**（編集メニュー）: アルペジオ・スライド・装飾音・トリルの画面で作った音は曲に作った記録が残るので、後で別の編集をした後でも直せます。作った音を一つでも選び（タブは選んだ音がなければカーソル位置の和音）**元に戻す(作る前へ)**を押すと、作った音を消して元の音を元の場所に戻します（元に戻す1回）。アルペジオは戻すトラックをチェックで選ぶ画面が出ます。和音の音を取ったトラックを外すとそのトラックの元の音は戻らず、アルペジオがあるトラックを外すとアルペジオは残し、後でまた戻せます。スライド・装飾音は画面なしですぐ戻します。**もう一度直す**は元の音に戻した状態でその画面を作ったときの設定のまま開きます。設定を変えて適用すると戻すと作り直すが元に戻す1回で、キャンセルすると何も変わりません。画面の中の**元に戻す**ボタンでその場で戻すこともできます。作った後に手で直した音があれば何個か聞いて、その音も元に戻します。曲全体を移調したり丸ごと動かしたりしていれば、元の音も一緒に動かして戻します。元の音の場所に後から入れた音があったり、その上に別の画面でまた作ったりしていれば（アルペジオの音に装飾音など）、戻さずにかかる音を選んで見せます。記録はプロジェクトファイル（.mme）にだけ保存され、MML・3MLE・.mmi・MIDIの出力と文字数は変わりません。.mmlなどで開いた曲、この機能の前に作った音、コピーして貼り付けた音は普通の音です。そのようなアルペジオは音を選んで**アルペジオとして認識**を押すと、音の並びから方式・順番・長さと元の和音を推測して記録を残すので、その後「元に戻す(作る前へ)」「もう一度直す」が使えます。同じ長さで続く音（一つのトラックに広げる）や、同じ楽譜のトラックを順に同じ間隔で遅れて始まる音（トラックを回って繰り返す・ずらして弾く）を見ます。元の和音はマスの最初から最後まで続く音と推測し、広げる方式では一番低い音をそのトラックに、残りは同じ楽譜でその場所が空いているトラックに置きます（他のトラックに和音の音が残っていればそのまま）。選んだ音だけを見て曲を自動では調べず、入れる前に推測した和音を見せて確認します。音は変わらず、元に戻す1回で取り消せます。

### 曲単位の編集

- **移調**（Alt+P）: 選択した音・このトラック・この楽譜・曲全体を、半音・オクターブ単位で移します。ゲームで音域の折り返しが起こる音の数を事前に知らせます。
- **音量の一括調整**（曲メニュー）: 選択した音（ピアノロール・タブ）・このトラック・この楽譜・曲全体のvを変えます。**一つの値に**はすべて同じvに、**上げ下げ**は今のvから±段階分（v0-v15で止まり、止まった音の数を知らせます）、**目標dB**はv15を0 dBとし、ゲームで測った音量の法則 dB = 40·log10(v/15) で最も近いvに合わせます（−6 dB ≈ v11）。ウィンドウで変わる音の数と今/変更後のvの範囲を前もって見せ、一度に変えたものは元に戻す一回で戻ります。ゲームは&の後ろのvを読まないので、&のつながりは最初の音のvで一緒に変わります（つながりの途中・最後の音だけを選んでもつながり全体が変わります）。すべて選択（Ctrl+A）でトラックの音を全部選んでから使うこともできます。このトラック・この楽譜・曲全体では、**小節**の行で変える小節をしぼれます。**選択した小節だけ**はリピート範囲（ロールでShift+ドラッグ、または小節番号の行をドラッグ）がかかる小節を、**小節を入力**は `12-16, 20` のように入力した小節を変えます（`20-` は20小節から最後まで、小節番号は小節番号の行と同じ）。その小節の中で始まる音だけが変わり、前の小節から&でつながって入る音は最初の音のvで鳴るのでそのままにします（小節の中で始まり後ろの小節へつながるつながりは一緒に変わります）。
- **和音減衰**（曲メニュー）: 同じ楽譜で一緒に鳴る音の数を数え、和音の中の音のvを今のvから下げます。同じvで鳴る音が多いほどゲームでは大きくなるので、和音が単音より飛び出さないようにそろえるのに使います。範囲（選択した音・このトラック・この楽譜・曲全体）と**小節**の行は音量の一括調整と同じで、数えるときは範囲外の音も同じ楽譜なら一緒に鳴る音に入れます。**重なって鳴る音まで**（既定）は同時に始まる音だけでなく、先に鳴っている音と**ロール幅**（既定1/16）の中にロールで入る音も数えます。音の始まりからロール幅の中で最も多く一緒に鳴った瞬間の音数を使うので、ロール和音・引きずった和音はすべての音が同じ和音として下がり、速い単旋律は一瞬に一音なので下がりません。**同時に始まる音だけ**はMIDI読み込みの和音減衰のように同じ位置で始まる音だけを数えます。**分けて数える**は**音の高さの隙間**（その瞬間に鳴る音の間に8半音以上の隙間があれば上・下を別に、既定）、**トラックの役割**（メロディ・ベース・その他を別に）、**楽譜全体をまとめて**から選びます。**下げ方**は**段階**（既定 2音 −1、3音 −2、4音以上 −3、MMLCSの和音減衰と同じ、数字は変更可）と**音量法則**（同じvの音が2倍になると3 dB大きくなる実測どおり、和音全体が単音の大きさになるv）から選び、**最小**のv（既定5）より下げません（最初からそれより小さい音はそのまま）。**基準**を**すべて一つの値から**にすると、選んだ音をまずそのvにしてから下げます。ウィンドウで変わる音の数、一緒に鳴った音数ごとの個数、同時に始まる音だけを数えるより多く数えた音の数、今/変更後のvの範囲を前もって見せ、元に戻す1回で戻ります。&のつながりはつながりの最後まで鳴る一つの音として数え、最初の音のvで一緒に変わります（ゲームは&の後ろのvを読みません）。すでに減衰した所にもう一度かけるとさらに下がるので、やり直すときは元に戻すか基準を一つの値にしてください。選んだ設定はこのブラウザーに記憶されます。
- **トラックの分割・結合**: 選択した音を別のトラック（または新しいトラック）に移す、楽譜のトラックを1つに結合する、高さ順に分け直す。重なる音は移さずに残します。
- **小節を挿入・小節を削除**: 再生カーソルの位置に1小節を挿入または削除します（すべてのトラックとテンポ・拍子も一緒に）。曲の先頭に挿入しても最初のテンポは曲の先頭に残るので、挿入した小節もそのテンポで演奏されます。その位置の後ろに音がないトラック（テンポだけを書いたトラック、末尾の休符で楽譜の長さを保つトラックなど）も、原文のテンポ（t）と末尾の休符を一緒に押したり引いたりします。音が移ったトラックはMMLテキストを書き直し（コメント・空白はなくなります）、原文の末尾の休符で保っていた長さはそのまま保ちます。
- **曲の情報**（曲メニューの一番上）: 曲のタイトル・作者・メモを書きます。3MLE・MabiIcco・プロジェクトファイルで保存するときに一緒に入ります。3MLEファイルには作者がSource欄、メモがMemo欄に入り、MabiIccoファイルにはタイトルと作者だけが入ります。この2つは欄が1行なので、改行は空白に変わります。元に戻すことができます。
- **トラックのロック**: 鍵アイコンをクリックすると、そのトラックはロール・タブ譜・エディタで編集できなくなります。選択・コピーはできます。移調は、ロックしたトラックが範囲に含まれると確認したうえで一緒に移します。ツールバーの選択ツール横の鍵（選択した音をドラッグして移動）は、トラックのロックとは別の機能です。

### 元に戻す

Ctrl+Z / Ctrl+Y（またはCtrl+Shift+Z）。曲全体のコマンドも一度に元に戻せます。

## 6. テンポ・拍子・マーカー

### イベントの行

ロールの上の2段にテンポ・拍子・マーカーが表示されます。最初からオンになっていて、表示 → **イベント** でオン・オフできます（選んだ状態は記憶されます）。

- 空いている所をダブルクリック（タッチは長押し）するか、ラベルを右クリックして追加・編集します。
- ラベルをドラッグして移動し、テンポのラベル上でホイールを回すと±1（Shiftで±10）、Delで削除します。
- キーボード: **Alt+B** でカーソル位置にテンポ、**Alt+M** でマーカー

### 拍子

曲 → 拍子を変更（ツールバーの **拍子** 欄も同じ）。再生カーソルのある小節から（なければ曲の最初から）変わります。タブ譜表示ではタブのカーソルがある小節から変わります。6/8・9/8・12/8は8分音符3つを1拍として表示します。

### タップテンポ

曲 → タップテンポ。原曲（または動画）を再生し、**小節の1拍目ごとにTキー** か［タップ］を押すと、停止したときにテンポが入ります。

- 1拍目が聞き取りにくい場合は **拍ごと** に切り替え、拍を数えるように押します。
- タップテンポのバーの **タップのばらつきを補正**（弱 30ms・標準 60ms・強 100ms）: 選んだ範囲内のずれたタップは手のぶれとみなし、1つのテンポにまとめます。テンポ命令の数とMMLの文字数も減ります。
- **続きから**: **続ける小節** に小節番号を入れて **続ける** を押すと、1小節前から再生し、その小節の1拍目に押したタップから続けて入力します。すでに入れたテンポはそのままで、入力後は最後にタップした小節が入ります。タップ中に再生位置を移したりループが先頭に戻ったりしても、それまでのタップを入力してから新しく始めます。
- テンポは整数なので丸めますが、その誤差は次の小節が受け持つため、小節が多くてもずれがたまりません。
- **ずれたタップ**（オフ・10%・20%（既定）・35%）: 入力後、前後の間隔とこれ以上違う所（押し忘れ・二度押し）を小節ボタンで知らせます。押すとその位置へ移動します。修正はしません。ジャズ・ルバート・速い曲は基準を上げるか切ってください。
- **再生速度**（100%（既定）・85%・75%・60%・50%）: 速い曲は遅くして叩きます。原曲・MML・背景動画が一緒に遅くなり、タップは曲の時間で測るので元の速さのテンポで入ります（50%で2秒ごとに叩けば曲では1秒間隔）。手のぶれも曲の時間ではその分小さくなります。原曲はテープのように音が低くなります（75%で約5半音、50%で1オクターブ）が、拍の位置は正確です。続きからの1小節前の準備も同じ速度で再生され、ずれたタップ・波形の立ち上がりに合わせるはそのまま使えます。再生中に変えると今の位置から新しい速度で再生し直し、タップテンポのバーを閉じると、再生ボタンの横のメニューで選んだ再生速度（3章 再生）に戻ります。**閉じるときのタップ**（捨てる（既定）・確認する・入れる）で、バーを閉じるときにまだ入れていないタップをどうするか選びます。
- **波形の立ち上がりに合わせる**（オフ（既定）・±30ms・±60ms、原曲を読み込んだとき）: 入力後、楽譜でその拍に音が書かれているタップだけ、近くで原曲の音が始まる所を探して **合わせる** か確認します。押すまでは変わらず、合わせたものは1回の元に戻すで戻ります。
- 原曲バーの **小節線ドラッグ**: **前から順に**（既定）は波形帯で小節線をドラッグすると、前のテンポ位置からその小節線までのテンポを変え、後ろはずれます。**前後の小節だけ** は前後の小節線をそのままにして、両側の2小節のテンポだけ計算し直します（タップ入力後に1か所だけ直すとき）。ドラッグ中に変わるテンポが小節線の横に表示されます。

### テンポの整理

- **テンポを一括変更**: 曲全体のテンポを1つの値にそろえる（**すべてこの値に**）、すべて同じだけ上げ下げする（**± BPM**）、または何%かに変える（**%**）ことができます。ループ区間があればその中だけを変え、区間の後ろのテンポはそのままです。すべての楽譜のMMLテキストも一緒に直し、ゲームのテンポ範囲（t32〜255）を外れるときは事前に知らせます。Ctrl+Zを1回押せば元に戻ります。区間の境目にテンポを入れる場所がない楽譜（終わりの長さを変える所か、分けられないn音符だけ）は、その楽譜の文をそのままにして何番の楽譜かをお知らせします。
- **ずれた長さを探す**: 3MLE・MabiIccoは長さを整数ティックで数えるため、拍に合わせようと `r21`（= r32.）、`b19.`（= b16&b64）、l28 6つの後の `l27` のような値を使った楽譜があります。そこでは合いますが、BiNoteとゲームは正確な長さで演奏するので、その後ろが少しずつずれます。このウィンドウは、まとまりが16分や3連8分の位置をごくわずか（4分音符の1/96以下）外れ、ぴったりの位置に戻らない箇所だけを探し、そこにぴったり合うきれいな値（`r21 → r32.`、`d27 → d28`）を表示します。箇所ごとに **移動**、**元のまま聴く**、**直して聴く**、**直す** があり、下に **すべて直す** があります。直す値の欄には長さを直接入力でき（`32.`、`16&64`）、提案と違うとそのまとまりがどれだけ遅く・早く終わって後ろがずれるかをすぐ表示します。聴くときは曲全体をミュート（M）・ソロ（S）の設定どおりに再生するので、ウィンドウに今のソロ・ミュートのトラックを表示し、その箇所のトラックが鳴らないときは「今は鳴らないトラック」と知らせます。勝手に直すことはなく、Ctrl+Z 1回で元に戻せます。ぴったり終わる連符（l20 5つなど）や3連符・スウィングには触れません。3MLE・MabiIccoファイルやMML@テキストを開いたときに該当箇所があれば、このウィンドウが自動で開きます。
- **折り返しの見直し**: ゲームは楽器がそのまま出せない高さ(実測音域)の音を1音ずつオクターブ単位で折り返すため、区間の一部だけが折り返すと旋律が途中で跳びます。このウィンドウは休符で区切った区間ごとに**そのまま**と**区間ごとオクターブ上げ・下げ**を比べ、移したあとの折り返し数・オクターブの跳び・他のトラックと同じ高さで重なる音・音色境界をまたぐ&を表示し、おすすめを選んでおきます。区間ごとに**移動**、**今のまま聴く**、**直したあと聴く**、**移す**があり、下に**選んだ区間を移す**があります(Ctrl+Z 1回)。トラックの音をすべてそのまま出せる他の楽器も表示します。自動では変えません。ステータスバーのチェックの折り返し行からも開けます。
- **テンポをすべて削除**: 曲の最初のテンポだけを残します。ループ区間があればその中だけ。
- **楽譜ごとにテンポを入れる**: テンポがない楽譜のMMLテキストに曲のテンポを書き込みます。（MMLで書き出す・楽譜集に分割は、これを使わなくても楽譜ごとに入れます）
- ゲームの範囲（t32〜t255）外のテンポも編集中は使え、MMLで書き出すときに変え方を案内し、**実時間を保って変換** ボタンですぐに変えることもできます（下の9章）。

## 7. 音量（v）を整える

### 入力 v

ツールバーの **入力 v** は、新しく入力する音の音量です。「引き継ぎ」なら前の音の v に従います。音を選ぶと **選択した音の v** に変わり、まとめて変更できます。

### 音量レーン

ピアノロール下部の **音量 (v)** の帯が音量レーンです。閉じている場合は鍵盤帯側の角にある **音量 ▲** ボタンで開きます。バー1本が `&` でつないだ音のまとまり1つで、右側の数字が v の目盛りです。

- **ブラシ**: ドラッグで通ったバーの v をその高さに変えます。
- **直線**（またはShift+ドラッグ）: 押した位置から離した位置まで、v を直線で変えます。
- 音を選んでおくと、その音だけが変わります。
- **複数のトラックに一度に**: トラック一覧でCtrl+クリックして、一緒に変更するトラックを追加します。タッチではトラックを長押ししてメニューの **音量レーンに一緒に描く** を選ぶか、レーンの **音量 ▾**（複数なら **nトラック**）を押してチェックで追加・除外します。メロディトラックには描いた値をそのまま使い、ほかは上・中・下の位置ごとに決めた分だけ加えます。メロディの指定がなければ、楽譜の最初のトラックがメロディです。
- レーンは細く・大きく・閉じるを切り替えます。レーン上の取っ手をドラッグすると好きな高さに広がり（細い帯からドラッグしても構いません）、ダブルクリックで細く・大きくが切り替わります。設定 → 画面 → **音量レーン** でも高さを選べます。ペンで描くときは大きくしておくと楽です。

## 8. 原曲・動画を見ながら採譜する

### 原曲

ツールバーの ⋯ → **原曲…** で音源や動画を選ぶと、楽譜と一緒に再生します。ファイルはこの端末の中でだけ使い、サーバーへは送信しません。

- **ずれ（ms）**: 原曲が遅ければ＋。開始位置を合わせます。
- **原曲の音量**: 原曲の音量
- **波形**: ロールの小節番号の行の下に、原曲の波形を曲の時間に合わせて表示します。
  - 波形をクリックすると、その位置に移動します。
  - 波形上の **小節線をドラッグして** 原曲の拍に置くと、その小節がそこに来るようにテンポを変えます。
  - 波形の空いている所をドラッグすると、原曲が前後に動いてずれが変わります。
  - タブ譜表示でも変化の行の下に同じ波形の帯が出ます。クリックするとその位置に移動し、空いている所をドラッグして原曲を動かせます(数字パッドを開いている間は指板の場所を空けるため隠します)。

### 背景動画

ツールバーの ⋯ → **背景動画…**（ピアノロールで）。落ちてくるノーツの動画（ピアノ演奏動画など）をピアノロールの背景に敷き、動画を見ながら音を入力します。

- **鍵盤に合わせる**: 動画の左端・右端の鍵盤と鍵盤の上端線を決めると、ロールの鍵盤と重なります。**ハンドルで合わせる** をオンにすると、ロール上でドラッグして合わせます。
- **ロールを合わせる**: ロールを動画の鍵盤範囲に合わせて移動・拡大します。
- 濃さ、ずれ（秒）、時間の伸縮、動画の音を調整します。
- **画面を埋める**（初期はオン）: 鍵盤の上端線から動画の上端までがロールの見えている時間軸全体を覆うように、時間の伸縮を自動で決めます。オフにすると時間の伸縮を自分で決めます。
- **速さを合わせる**: 止めた動画で音が落ちる速さを測り、ロールの横の拡大を合わせます。再生すると動画の音とロールの音が鍵盤の線で同時に重なります。自動で測れないときは **手で測る** で1つの音の先端を2回押して測ります。測っている間は曲を編集できません（保存はできます）。Esc か **キャンセル** でやめます。曲の途中でテンポが変わる場合は、そこで合わせ直してください。
- **動画を再生**: 曲なしで動画だけを再生し、ロールが追従します。

### 一緒に使うと便利な機能

- **再生速度・メトロノーム**（再生ボタンの横のメニュー、3章 再生）: 速いところは遅くして聞きながら打ち込み、メトロノームで原曲と拍を合わせます。
- **縦ロール**: 落ちてくるノーツの動画と向きを合わせます。設定 → 画面 → 再生中のロール → **連続スクロール**を選ぶと、動画がなくても落ちてくるノーツのように流れます。
- **再生中に鍵盤を光らせる**（既定でオン）: 再生中の音を鍵盤に表示します。設定 → 再生 でオフにします。
- **選んだ音の鍵盤を光らせる**（既定は 選んでいる間ずっと）：押した音や選んだ音を鍵盤にトラックの色で表示します。**押している間だけ** は音や鍵盤を押している間だけ、**選んでいる間ずっと** は音が選ばれている間光ったままです。設定 → 再生 で変更・オフにできます。
- 設定 → 再生 → **画面の同期補正**: 再生線が音より先に進むなら＋、遅れるなら−。iPad・Bluetoothイヤホンはさらに100〜300ms必要な場合があります。

## 9. MMLで書き出す

ファイル → **MMLで書き出す…** で出力結果を確認してコピーします。

### 「MMLで書き出す」ウィンドウ

構成リストのように楽譜の行の下にトラックの行があり、すべての楽譜のトラックにチェックボックスがあります。楽譜ごとの文字数・トラック数・折り返し・エラー・警告も表示します。

1. 1回の貼り付けに入れるトラックにチェックを入れます。**複数の楽譜から選んでもよく、一度に6トラックまで**選べます（6つ選ぶと残りのボックスはロックされます）。楽譜の行のチェックボックスは、その楽譜のトラックをまとめて選んだり外したりします。
2. **選んだトラックをコピー** をクリックすると、選んだトラックを曲のトラック順に `MML@…;` テキスト1つとしてコピーします。コピーされない場合は、ブラウザのクリップボード権限を確認してください。
3. ゲームで空の楽譜を開いて貼り付けます。1回の貼り付けに入るのは MML@ テキスト1つだけです。
4. コピーしたトラックには **コピー済み** が付き、まだコピーしていないトラックが次のコピー用にあらかじめチェックされます。たとえば楽譜1の1・2・3と楽譜2の1・3・6をコピーすると、次は楽譜1の4・5・6と楽譜2の2・4・5がチェックされています。最初に開いたときは最初の楽譜だけがチェックされます。

- 楽譜の行の左の矢印で楽譜をたたんだり広げたりします。最初はすべて広げた状態で、すべてのトラックをコピーした楽譜はコピーしたときにたたまれます。
- コピーしたあとトラックを直すと「コピー後に変更」になり、もう一度コピーするトラックとして扱います。コピー済みの表示はウィンドウを閉じて開き直しても残り、別の曲を開くと消えます。
- **テンポを入れる**（初期設定オン）：コピーするたびに曲の最初のテンポから入れます。ゲームは貼り付けたテキストだけを見て、テンポがなければ t120 で演奏します（ほかの貼り付けのテンポは引き継ぎません）。オフにするとテンポなしでコピーし、ゲームでは t120 で演奏されることを知らせます。 最初のテンポがt120ならゲームの既定値と同じなので書きません(4文字の節約)。
- 選んだ楽譜のテンポが互いに違う場合（元のテキストに違う t が書かれた楽譜を混ぜて選んだ場合）は、入れるテンポを選びます。選んだテンポはウィンドウを閉じるまで次のコピーでも使います。BiNote は曲にテンポマップが1つなので、通常は表示されません。
- オルゴール・蓄音機の楽譜1つをまるごと選ぶと、これまでどおり残りのトラックを鳴らないチャンネルとして一緒に入れ、曲の長さとテンポをそろえます。ほかの楽譜のトラックと混ぜてオルゴールのトラックが最初の3チャンネルの外に置かれると、鳴らないことを知らせます。
- 文字数が上限を超えるトラックは赤く表示され、ボタンが「選んだトラックをコピー（超過）」に変わります。
- 出力用のMMLは文字数を減らして新しく書きます。ただしトラックごとに、原文（テンポだけを合わせ、コメント・空白を除いたテキスト）の方が短く、音とテンポが同じなら原文の方を使うので、原文より長く書くことはありません。エディタのテキストは変更しません。選んだトラックのうち一番長いトラックに合わせて末尾の休符を保ちます。
- トラックはチェックした順にMML@文字列へ入ります。下の**貼り付け順**の行の ‹ › で入れ替えたり曲の順に戻したりでき、曲のトラック順は変わりません。折り返し・エラー・警告の表示を押すとステータスバーのチェック一覧が開きます。
- テンポの位置が選んだすべてのトラックで音の途中にある場合は、音を切り捨てないよう、すぐ後の音の境目に書いてお知らせします。

### テンポがゲームの範囲外のとき

t255より速い場合はその区間の音長を短くしてテンポを下げる方法を、t32より遅い場合は音長を長くしてテンポを上げる方法を案内します。速さは同じです。

案内の行ごとにある **実時間を保って変換** を押すと、そのとおりに変えてくれます（MabiIccoの「ティック変換」と同じ作業）。

- そのテンポの位置から次のテンポの前まで（最後のテンポなら曲の終わりまで）だけを変えます。テンポを範囲内に変えながら、音長と拍子記号を同じ倍率で合わせます。たとえば t300 は t150 になり、その区間の4分音符は8分音符、4/4は4/8になります。聞こえる速さと小節線はそのままで、区間の後ろは伸びた・縮んだ分だけずれます。
- 元に戻す1回で戻ります。変えたあとは案内の一番上に、変えたテンポと倍率が表示されます。テンポ × 倍率が整数でないときは四捨五入してお知らせします（その区間の速さがごくわずかに変わります）。
- ゲームの音長で正確に書けない長さ（l64の半分など）ができる場合は変えず、どのトラックの何小節何拍かをその行の下でお知らせします。
- 区間にかかるトラックのMMLテキストは書き直すので、コメント・空白はなくなります。そのトラックのテキストに文法エラーがあれば先に直してください。ロックしたトラックが変わる場合は先に確認します。
- 変えたテンポもゲームの範囲外になる場合、ボタンは表示されません。そのテンポの後ろに音がなければ変えるものがないとお知らせするので、テンポを削除するか範囲内の値に直してください。

### 文字数が上限を超えるとき

順番に試してください。

1. **音符の再配分**: 曲メニュー → 文字数を合わせる → 音符の再配分（「MMLで書き出す」ウィンドウの上限を超えた行からも開けます）は、文字数が上限を超えるトラック（送るトラック）の音を、同じ楽譜・同じ楽器のトラック（受け取るトラック）が休んでいる小節へ **区間ごと** 移します。受け取るトラックをチェックで選ぶと **空きを探す** に移せる小節区間が並びます（受け取るトラックが空の区間が先、受け取るトラックに音が少しある区間はその音を送るトラックと入れ替え）。区間を自分でチェックするか **超えた分だけ自動で選ぶ** を押すと、チェックを変えるたびに移したあとの文字数が表に出ます。小節線をまたぐ音・&のまとまりがある所では切らず、音を外さず、音も同じです（ゲーム出力を読み直して確認）。受け取るトラックが足りなければ **空のトラックを追加** で同じ楽譜にトラックを足せます。トラックがすでに埋まっている楽譜では、トラックを足すと同じ楽器の楽譜がもう1つでき（ゲームで一緒に弾く人が1人増える）、1人で弾くなら楽譜集に分割を使ってください。
2. **文字数を減らす**: 音の高さ・開始位置・長さは保ったまま、すべてのトラックのMMLをより短く書き直します。自分で書いたスペース・改行・コメントは失われます。短くすると音が消える場合は、変更せずにお知らせします。
3. **楽譜集に分割**: すべてのトラックを同じ位置で切り、複数の冊に分けます。
   - **音符を再配分してから分割**（初期設定オン）：分割の前に、音符の再配分の画面と同じ基準（同じ楽譜・楽器で、ミュート・ソロ・音量・パンが同じトラック）どうしで音を移し、チャンネルの長さをそろえます。移したあとにゲームの音が変わる場合は移しません。すべてのチャンネルが上限内に収まれば分割せず、冊数が減る場合は移した結果で分割します。編集中の曲はそのままで、「曲にも適用」を押すと曲にも移します（Ctrl+Zで元に戻せます）。オフにすると楽譜集への分割だけを行い、音を移すと減る場合は「N冊 → M冊」の案内だけが出ます。
   - **じっくり分割**（初期設定オフ）：冊の終わりごとに上限近くの位置をさらにいくつもたどり、冊数がより少ない分け方を探します。時間がかかるため、分割中は下に段階と進行バーが表示されます。短い曲はこのオプションがなくても最も少ない冊数を正確に求めます。
   - 全員が休んでいる位置を優先して選びます。次の冊が遅れて始まる約1秒の間、すべてのトラック（低すぎ・高すぎて折り返される音も含む）が休んでいれば音を失わないので、冊の中のどこにあってもその位置で切ります（t120なら2分音符、t240なら1小節ほどの休み）。そういう位置がなければ、切り落とされる音がいちばん短い位置を選びます。
   - 冊ごとにオクターブ・音量・テンポを書き直します。
   - 次の冊が遅れて始まる分（約1秒）だけ前の冊を早く終わらせ、拍を合わせます。この補正区間に音があると、音が短くなったり外れたりすることがあります。結果の「末尾で途切れる音」と長さの警告を見て、冊の境目の前後を聞いてから使ってください。

音符の再配分・和音の統合・文字数を減らすは、ウィンドウで変更前後の文字数を見てから適用します。適用した変更はCtrl+Zで元に戻せます。楽譜集に分割は元の曲を変えず、冊ごとの出力結果だけを作ります。各冊で楽譜ごとのコピーボタンを使ってください。

### 和音の統合

曲メニュー → 文字数を合わせる → **和音の統合** は、同じ楽譜・同じ楽器のトラックのまとまりで、トラックごとに **残す / 空にする / 外す** を選ぶと、空にするトラックの音を残すトラックがその時間に休んでいる所へ移し、空になったトラックを削除します（楽譜が2つ以上あり、削除すると後ろのトラックが前の楽譜に詰められる場合は空のトラックとして残します）。MIDI を読み込んで音がまばらなトラックができたときや、トラック数を減らしたいときに使います。休みが足りなければ **段階** で決めます。**1段階**（既定）は音を外さず、そのトラックをそのままにします。**2段階** はその瞬間ほかのトラックで同じ音（オクターブ含む）が鳴っている重なった音だけ外します。**3段階** は場所のない音を外し、いちばん上・いちばん下の音はなるべく守って内側の音から外します。**優先** トラック（メロディに設定したトラックが最初に選ばれます）の音はどの段階でも外さず、場所が足りなければほかのトラックの音を代わりに外します（内声の旋律を守る）。外す音は数と位置（小節・拍・高さ）をすべて表示し、帯に赤く示し、適用ボタンにも外す音の数が出ます。和音の音を外した所では、同じ位置で一緒に弾いていた同じ手の残りの音のvを上げ、和音全体の大きさを外す前とそろえます（上げた音の数をウィンドウに表示）。外す音と上げたv以外は音が同じか、ゲーム出力を読み直して確かめます。

- ほかのトラックと重なる音は移す先がないので、そのまま残ります。
- 受け取るトラックの前後の音と完全5度より離れていると入れません（旋律が跳ねないように）。& でつながってしまう位置にも入れません。
- 受け取るトラックが文字数の上限を新しく超えるときは移しません。トラックを空にできず一部だけ移すときは、文字数の合計が増えるなら移しません。そのため v が違う弱い断片は残ることがあります。
- ロックしたトラックや、ミュート・ソロ・チャンネル音量が違うトラックどうしでは移しません。
- プレビューでトラックごとの文字数の前後を見てから適用し、Ctrl+Z で元に戻せます。

設定 → **和音** で、MIDI を読み込むときに和音を統合する（既定でオン）と、楽譜帳に分ける前に音符を再配分する（既定でオン）を決めます。

### 曲のチェック

ステータスバーの **チェック N** で、曲全体の問題を確認します。

- 文字数の超過、テンポ・音長・音量の範囲外
- 楽器の音域外のため **音域の折り返し** が起こる音（ロールではグレーで表示されます）
- ゲームのサンプルが終わり、**後半が鳴らない長い音**（ゲームの音はループせず1回鳴って終わります）
- 1人の演奏者のトラック数の超過、同じ演奏者のトラック同士での同じ音の重なり
- & でつないだ2つの音が音色の境目をまたぐ
- ゲームの範囲外のオクターブ（o10など）、MMLで書けない高さの音（o0c-より低い、またはo9b+より高い音。書き直すときにオクターブ単位で範囲内に移して書きます）

## 10. MIDIの読み込み

楽譜を開くで .mid を選ぶと、**MIDIの読み込み** ウィンドウが開きます。

1. **MIDIパート** ごとに音数・音域・同時発音を見て、どの **演奏者** に割り当てるかを選びます。除外・打楽器へも選べます。合う楽器がない場合は、近い楽器を選んでおきます。
2. 演奏者ごとに **同時発音数** を決めます。曲全体の合計が上に表示されます。
3. あふれる位置で外す順序を選びます。
   - 中間から（両端を維持、標準）・下から・上から・弱い音から・短い音から
   - 優先して音を減らすパート（両手半々・右手の和音から・左手の和音から）、メロディを保護
4. **拍子グリッド**（自動または手動）と **3連符を残す**。3連符を残すをオンにすると、拍をまたぐ4分・2分の3連符も細切れにせず3連符に合わせ、グリッドが16分かそれより細かいときは4分の5連符もl20に合わせます。少し揺れた普通のリズムは3連符・5連符にしません。オフにすると5連符も使いません
5. **和音の統合**（既定でオン）: 和音が一瞬増えた所の音だけが別のトラックに残らないよう、休んでいる同じ楽器のトラックへ移します（9章の和音の統合）。空のチャンネルを埋めるより先に行います。
6. **空のチャンネルを埋める**: 圧縮で外れた和音の音を、休んでいるチャンネルに入れ直します。文字数の上限を超えると、入れ直した音から外します。
7. 下のまとめ（外した音・入れ直した音・統合した音・最も長いチャンネルの文字数）を見て **読み込む**。

MIDIの読み込みは、元のデータをそのまま移すものではありません。同時発音数を超える音は外れ、音長は拍子グリッドに合わせて整えられます。読み込んだ後に聞いてみて、必要な所を直してください。

## 11. 保存とファイル形式

| 形式 | メニュー | 用途 |
|---|---|---|
| **プロジェクト .mme** | プロジェクトとして保存（Ctrl+S） | **作業の保管と別の端末への移動におすすめ。** 分数の位置・トラック構成・編集画面の状態が残ります（以前の .mmlce も開けます） |
| 3MLE .mml | 3MLE形式で保存（Ctrl+Alt+S） | 3MLEで開く。既定はCP949で、ない文字は ? になるため、必要ならUTF-8で保存 |
| MabiIcco .mmi | MabiIcco形式で保存（Ctrl+Shift+S） | MabiIccoで開く。グリッド（4分音符96分割）に合わない音はお知らせします。.mmiを開いて保存し直しても、歌の欄・歌の楽器・パン・トラックの表示が残り、原文を直していないトラックは自分で書いた表記と開始位置をそのまま使います |
| MIDI .mid | MIDIで保存 | DAWなど。楽器はGM番号で、バスドラム・シンバルはドラムチャンネルに。番号だけで書かれた追加サウンドパックの楽器（#42.3 など）は、読み込んだパックで見つかった実際の楽器のGM番号で保存し、音の高さは書かれたままにします。高さの異なる音を `&` でつないだ所は、MIDIでは別々に弾く音として保存されます |
| WAV | WAVで保存 | 今のサウンドパックで曲全体を音声ファイルに（ミュート・ソロは聞こえるとおり）。サウンドパックが必要です |
| MML@ テキスト | MMLで書き出す | ゲームに貼り付け |

曲 → **曲の情報…** に書いたタイトル・作者・メモは、プロジェクト・3MLE・MabiIccoファイルに一緒に入ります（5章 曲の情報）。

プロジェクト（.mme）を開いて保存するだけでも、このバージョンが知らない内容（より新しいBiNoteが加えた情報）は消えず、そのまま書き戻されます。より新しいBiNoteで保存したファイルも、「このバージョンで読んでもよい」と書かれていれば案内とともに開きます。そう書かれていないファイルは開かないので、ページを再読み込みして最新のBiNoteで開いてください。このバージョンで保存したファイルは1.0.0-beta.32でも開けます。

### 保存先

設定 → **保存**で決めます。

- PCのChrome・Edge: 既定は**保存のたびにフォルダーと名前を選ぶ**です。ファイルを開くときと同じように保存ダイアログが開き、フォルダーとファイル名を選びます。次の保存は前回のフォルダーから開きます。WAVはでき上がったあとに出る**保存**ボタンを押して選びます。
- この方式でプロジェクト(.mme)として一度保存すると(または**楽譜を開く**でプロジェクトを開くと)、次の保存(Ctrl+S)はダイアログなしで同じファイルに直接書き込みます。開いたファイルは最初の保存で一度だけ書き込みの許可を求められます。新しいファイルに保存するにはファイル → **名前を付けて保存…**を選びます(ショートカットはキー設定で決められます)。ファイルが移動・削除されて書き込めないときは保存ダイアログがもう一度開きます。iPad・Safariではブラウザーの制限により毎回共有メニュー・ダウンロードで保存します。
- PCのChrome・Edge: **決めたフォルダーにそのまま保存**を選んでフォルダーを決めると、確認せずに保存するファイルはすべてそこに入ります。同じ名前のファイルは上書きされ(名前のない新しい楽譜は上書きせず `new project 2` のような新しい名前で保存し、次からその名前を使います)、ブラウザーを開き直すと最初の保存でフォルダーの使用をもう一度許可するよう求められることがあります。**ダウンロードフォルダー**を選ぶとブラウザーのダウンロードで保存します。
- iPad・iPhone: **共有メニューで保存**（既定でオン）なら、保存するときに共有メニューが開きます。「"ファイル"に保存」でフォルダーを選んだり、Google ドライブなどのアプリへ直接送ったりできます。
- そのほかのブラウザー（Firefoxなど）はダウンロードフォルダーに保存します。

プロジェクト（.mme）に含まれるものと含まれないもの:

- 含まれる: 楽譜、編集画面の状態、原曲・背景動画の **ファイル名と調整値**（ずれ・鍵盤の位置など）
- 含まれない: サウンドパック、原曲の音源・動画の **ファイル自体**、テーマ・言語などのアプリ設定

別の端末で続けるには、サウンドパックと原曲・動画ファイルを別途用意してください。同じ名前の原曲・動画を選び直すと、保存しておいた調整値を読み込みます。

### 自動保存

編集中の曲はこのブラウザに自動で残ります（最新10件）。再読み込み・タブを閉じた後、最初の画面かファイル → **以前の作業を復元** から開きます。

- 自動保存が続けて失敗すると、ステータスバーに **自動保存されていません** が表示されます。**もう一度試す** で保存し直すか、**.mmeで保存** でファイルに残してください。自動保存がうまくいくと表示は消えます。保存領域がいっぱいで失敗したときはすぐに表示され、このサイトの使用量と残りの容量も一緒に表示します。使わないサウンドパックを外すと容量が増えます。使用量と残りの容量は設定 → サウンドパックでも確認できます。
- 同じ作業を別のタブで開いていると、以前の作業の一覧に **別のタブで開いています** と表示されます。復元するとコピーとして開くので、2つのタブが互いに上書きしません。コピーは最初に保存するときにファイル名を確認します。
- 画面の一部（ピアノロール・タブ・五線譜・ウィンドウ）を描く途中でエラーが起きても、アプリ全体は止まりません。その場所に案内と **表示を作り直す**・**診断情報をコピー** ボタンが出て（ウィンドウと五線譜には **閉じる** もあります）、編集中の曲はすぐに自動保存されます。予期しないエラーが起きたときもすぐに自動保存し、保存できたかどうかと理由をお知らせします。続くときは診断情報を付けて報告してください（16章）。
- 以前のバージョンで自動保存した作業もそのまま表示され、復元できます。

> 自動保存は **一時的な復旧用** です。ブラウザのデータを消去したり容量が不足したりすると、消えることがあります。長く残したい曲は必ず **.mmeで保存** してください。iPadではファイルアプリに置くことをおすすめします。

### 新しいバージョン

新しいバージョンが出ると「新しいバージョンの準備ができました」というバーが表示されます。**再読み込み** をクリックすると、編集中の曲の自動保存が終わるのを待ってから新しいバージョンに切り替わります。保存に失敗した場合は切り替えずにステータスバーの **自動保存されていません** でお知らせするので、その際はプロジェクト（.mme）として保存してから、もう一度クリックしてください。大切な作業は、クリックする前に .mme で保存しておくとより安全です。案内を閉じて作業を続けてもかまいません。

アプリは開くたびに新しいバージョンを確認し、長く開いたままの場合はウィンドウに戻ったときに1時間に1回まで再確認します。すぐに確認するには、上部バーの **?** → **アップデートを確認** を押してください。

**実験室**は正式版の前に試せる機能です。設定 → 実験室でオンにすると上部バーに**実験室**メニューが出て、オフにするとメニューが隠れるだけで曲はそのままです。結果は普通のMML(v・音の高さ)なので、ゲームや他のアプリでもそのまま鳴ります。実験室の印(元に戻す・タブ表示に使うもの)はBiNoteのプロジェクトファイル(.mme)にだけ保存されます。ピアノロールでは選んだ音、タブでは選んだ音(なければカーソルの音)に使います。

- **ゴーストノート**: 選んだ音を周りの音よりN段階小さく弾きます(初期は4段階)。曲ごとに音量が違うので、決まったvではなく同じトラックで一番近い普通の音のvを基準にします(周りがv9ならv5)。タブではゴーストノートの数字が薄く見えます。
- **ハーモニクス**: **ナチュラル**はタブで音のあるフレットから計算します(12フレット = 開放弦 +12、7フレット = +19、5フレット = +24)。タブには`<12>`のように表示されます。**人工**は押さえた音の1オクターブ上で、`3<15>`のように表示されます(ピアノロールでは人工のみ)。音量はN段階小さくできます(初期は2段階)。
- ウィンドウの**実験室の印を外す**を押すと、選んだ音のうちゴーストノート・ハーモニクスにした音が元のv・高さに戻ります。
- **響きを入れる**: ゲームには響きのエフェクトがないので音符でまねます。長い音の後半を同じ高さの小さな音に分け、少しずつ弱く鳴らし直します。vの順はv15で弾いた音が基準(初期は 6 3 2 1)で、ほかのvの音は比例して下げます(v9なら 4 2 1 1)。かけらの長さ(初期は8分)と、そのまま残す頭の部分(初期は4分)を選びます。選んだ音かトラック全体のうち、この長さ以上の音(初期は2分音符)に入れ、**後ろに休符がある音だけ**でフレーズの終わりだけにできます。**スタッカートの空きを埋める**をオンにすると、短い音の後の休符に同じ音を小さく(初期はv4)入れます。かけらは&でつなぎません(ゲームは&の後のvを無視します)。トラックは増えませんが文字数が増えるので、ウィンドウの文字数を確かめてください。
- **響きスタンプ**: ピアノロールの道具バーの響きスタンプ(実験室をオンにすると出ます)をオンにして音をクリックすると、その位置から分けます。タブでは 実験室 → **カーソル位置に響き** でカーソルの音に入れます。音の頭をクリックすると頭を残して末尾から置きます。設定は 響きを入れる の尾の設定を使います。
- **MIDI鍵盤で録音**: 実験室メニューでオンにすると録音バーが出ます。**録音**（バーが開いているときは **R** キー）を押すとカーソルのある小節から1小節の予備拍を鳴らして曲を再生し、その間に弾いた鍵盤を押した長さのまま集めます。サウンドパックがなくてもメトロノームだけ聞きながら録音できます。**録音するトラック**: 選んだトラックがある楽譜のトラックボタンのうち、オンのトラックに入れます（最初は選んだトラックとその後のトラック、ロックされたトラックは除く）。和音や重なる音は高い音からこの順に1トラック1音ずつ入れ、**足りなければトラックを追加** をオンにしておくと楽譜のトラック上限までトラックを追加します（同じ演奏者の後の楽譜があると追加できません）。弾いている間、入る形がすぐ見えます。ピアノロールは入るトラックの色の枠に録音色の縁、トラックが足りず外れる音は薄い点線、TABは録音色のフレット番号です。止めると（停止・再生ボタン、Space、R）見えていたとおり、選んだ **グリッド**（8分・8分3連符・16分（既定）・16分3連符・32分）に合わせて入れます。**重ね録り**（既定）は曲にあった音を消さず、その位置は次のトラックに入れます。**差し替え録音** は実際に弾いた音がかかる小節の録音トラックの音を消してから入れます（消す音は弾いている間薄く表示、タイでつないだ音は最初の音の位置で判定）。**速度**（100・75・50%）を下げて録音しても元の速さの位置に入り、**メトロノーム** はオフにできます。元に戻す1回で戻ります。
- **だんだん遅く・速く**: ゲームのMMLには徐々に変わるテンポがないため、範囲内に決めた間隔でtを階段状に書いてrit.・accel.を再現します。ループ範囲があればその中、なければ選択した音の範囲に書きます（実験室メニュー。実験室をオンにすると 曲 → テンポ ▸ にも出ます）。**最初**・**最後** のテンポ、**間隔**（l1・l2・l4（既定）・l8・l16ごと）、**形**（均等に・最後に大きく・最初に大きく）を選ぶと、書くテンポとトラックごとの文字数がすぐに表示されます。範囲内にあったテンポは消して階段に置き換え、範囲の後は元のテンポに戻ります（オフにすると最後の段のテンポが続きます）。段の位置が音の途中なら、その音を&で分けて書くので音は同じで、先に終わった楽譜や最後の休符は伸ばしません。ゲームのテンポ範囲（t32-t255）外の値は範囲の端に合わせます。元に戻す1回で戻ります。
- **楽譜動画の小節送りからテンポ**: 今の小節に色の箱が付き、小節が変わると箱が移る楽譜動画（楽譜練習サイトの動画など）からテンポを取ります。ピアノロールのツールバーの … → 背景動画で動画を開き、実験室メニューでオンにして **小節を探す** を押すと、動画を見えない所で一度最後まで再生し、箱が新しく付く瞬間を探します。動画の長さだけかかり（**速度** 200%なら半分、そのかわり少し不正確）、動画は端末の外に出ません。途中で **やめる** を押すと見つけた所まで使います。最初のタイトル画面や最後の画面のように離れた変化は除きます。見つけた最初の所が何小節目の始まりかを **最初は小節** に入れ（最初の値は今のテンポと動画のずれから選んだ一番近い小節）、**テンポを入れる** を押すと小節単位のタップと同じように小節ごとにテンポが入ります。まとめ・ずれたタップの表示・波形の始まり合わせはタップテンポバーの設定に従い、元に戻す1回で戻ります。精度は動画のフレーム単位（30fpsなら1小節で±33ms程度）で、動画の作者が小節合わせを間違えた所はそのまま付いてくるので、ずれた所を確認してください。再生線が滑るように動く動画はまだ使えません。
- **アルペジオのトラック畳み**: メニュー項目はなく、アルペジオ画面の **かき鳴らし** に **トラック畳み** 欄が出ます。タブに6弦の和音を全部入れるとトラックが増えますが、**4トラックに** などを選ぶとトラックバーの順で前のトラックだけを残し、後ろのトラックの和音の音を残るトラックに入れます。1トラックは一度に1音なので、順番の最初の音・いちばん低い音（ベース）・最後の音は最後まで鳴り、間の音は同じトラックの次の音の前で短く切れます。速いかき鳴らし（l48・l64）なら少ないトラックでも6弦すべてを鳴らした感じになります。ロックしたトラック、&でつないだ音、同じ高さの重なり、短すぎる音がある和音は畳まずにかき鳴らしだけにします。空になったトラックはトラックバーで削除できますが、削除すると元に戻すはできません。ピアノロール・タブどちらでも使えます。
- **原曲と比べる強弱**（表示のみ）: 原曲（背景音）を読み込んだ曲で 実験室メニュー → **原曲と比べる強弱…** を押すと、小節ごとに原曲の大きさと、今の曲がゲームでどれくらいの大きさで鳴るか（vと音の長さから計算）を比べます。原曲は録音のミックス・響きのため幅をそのまま信じられないので、今の曲と同じ平均・幅にそろえてから比べます。上のグラフは原曲（幅をそろえた値）と今の曲の2本の線、下の棒は小節ごとの差（+は原曲に合わせるにはもっと大きくすべき小節）で、表には3 dBを超えて差がある小節の原曲の時刻・差・**提案のv**（その小節のメロディの音の平均vから音量カーブで計算）が出ます。小節ごと・4小節ごとの相関は、今の曲が原曲の膨らみと沈みにどれだけ付いていけているかを見る数字です（1に近いほどよく合う）。小節番号や棒を押すとその小節へカーソルが移るので、音量の一括調整で自分で直してください。画面は表示したまま編集でき、vを直すとすぐ計算し直します。**小さく浮かべる** を押すと小さなパネルになり、見出しをドラッグして動かしたり ▾ で差の棒だけ残してたたんだりでき、⤢ でまた大きく表示します。再生線・カーソルのある小節はグラフと表で示されます。曲は変えません。**テンポの揺れに自動で合わせる**（既定でオン）は原曲の音の高さと鳴り始めを曲の音符と比べ、小節ごとに原曲の同じ位置を探して読むので、ライブ録音のように原曲のテンポが揺れても原曲のずれ（開始位置）だけ合わせておけば大丈夫です（ずれの前後10秒以内）。オンにすると**原曲のずれ**グラフと表の**ずれ**列に、小節ごとに原曲が何秒遅い（+）か速い（−）かが出て、原曲が曲より0.15秒を超えて長く（遅く）または短く（速く）弾く小節は赤い点・赤い文字で示されます。テンポを原曲に合わせて直したいときはこの小節を見てください（赤い点を押すとその小節へカーソルが移ります）。**一致度**は原曲の音の高さ・鳴り始めが曲とどれだけ合うか（開始位置だけ合わせたとき → 自動合わせの後）です。曲と原曲の音が大きく違うと（編曲を大きく変えたなど）誤って合わせることがあるので、この数字が低いときはずれを信じないでください。自動合わせを切ると以前どおり開始位置だけを合わせるので、曲のテンポが原曲どおりに進むときだけ正しく出ます。ライブ録音の拍手のように除きたい所はリピート範囲を取って **リピート範囲内の小節だけ** をオンにします。混ざった録音なので音一つ一つの強さは分からず、小節単位でだけ見ます。
- **五線譜表示**（表示のみ）: 実験室をオンにすると表示メニュー（または実験室メニュー）に **五線譜表示** が出ます。オンにするとピアノロール・タブの上にトラックごとに一段ずつ五線譜が描かれます。描くトラックはピアノロールに見えているトラックと同じです。音・休符・タイ（&）・付点音符・連符（3・5・6・7連符など、音の長さの分数から判断）・拍子記号・小節線・テンポ（t）・強弱（vをpp-ffに近似し、変わる所だけ）を描きます。調号なしでシャープで書き、トラックの音の高さの中央値でト音記号かヘ音記号を選びます。拍のマスに合わない音（MIDIから取り込んだ揺れた音、l37のような長さ）は描画用にだけ近い拍に合わせて別の色で描き、曲の実際の位置・長さはそのままです。合わせると長さが0になるごく短い音は描かず、見出し行に何個あるか表示します。音を押すとそのトラックを選んでその音へ移り（ピアノロールはその音を選択）、何もない所を押すとカーソルだけ移ります。再生すると再生線に合わせて送ります。見出し行の−・+で横幅を変え、下端をドラッグして高さを変えます。画面に見える小節だけ描くので長い曲も軽く送れます。曲は変えません。五線譜で音を入れたり直したりはできず、アーティキュレーション・装飾記号・ペダル・スラー・反復記号は描きません（トリル・装飾音はすでに実際の音で書かれているので音として見えます）。楽譜の描画部品は初めてオンにしたときに読み込みます（VexFlow、MIT）。
- **音源から採譜**: 実験室メニュー → **音源から採譜…** は音源を音のリスト（MIDI）に採譜して **MIDIの読み込み** 画面に渡します。そこでいつもどおり奏者・和音数を決めて新しい曲として読み込みます。音源は読み込んだ原曲が既定で、**別の音源…** で変えられます。採譜の方法は2つです。**Basic Scriptor (PC)** はPCでだけ表示され、別に起動したBasic Scriptorプログラム（MuScriptor・basic-pitchで採譜し、sfproxyで強さを補正）に音源を送ります。Basic Scriptorを起動すると画面が自動で見つけ、初回はBasic Scriptorの画面に出た **ペア番号** を入れてペアにします。BiNoteを起動し直すたびにペアし直します。Chromeがローカルネットワークへのアクセスを尋ねたら許可してください。**ブラウザ内 (basic-pitch)** はiPadを含むすべての機器で、このブラウザの中で採譜します。音源は機器の外に出ず、初回だけモデルと計算コード（数MB）を取得します。ピアノのような単一楽器の音源で最もよく合い、複数の楽器が混ざると誤った音や倍音を多く拾います。**探す音**（少なめ・普通・多め）と **最短の長さ** で調整します。音源は10分(200 MB)までです。曲を開いていて、タップテンポなどで原曲にテンポを合わせてあれば、**今の曲のテンポに合わせて置く** をオンにすると、そのテンポと原曲のずれで音を置き、小節線が原曲に合います。オフならブラウザ内はt120ひとつで、Basic Scriptorは送られたテンポのまま置き（音源0秒＝曲の頭）、原曲を採譜した場合は読み込み後に原曲のずれを0にします。採譜する権利のある音源だけを使ってください（MuScriptorモデルは非商用のみ）。自動採譜は下書きで、誤った音や抜けた音があるので、原曲を聞きながら直してください。
- 響きの方法はマビッコ楽譜作成ガイドの響き効果の項目を参考にしました。
- **MusicXMLの読み込み・書き出し**: 楽譜ソフト(MuseScore・Finale・Sibelius・Dorico など)と楽譜をやり取りします。ラボメニュー → **MusicXMLを読み込む…** で .musicxml・圧縮された .mxl・.xml の楽譜を選ぶと、MIDI読み込みと同じ画面が開きます。パート(大譜表は譜表ごと)を演奏者に割り当て、同時発音数と外す順序を決めるのはMIDIと同じで、違うのは楽譜に書かれた位置・長さをそのまま使うことです(グリッドに合わせないので3連符・5連符・不規則な長さも正確)。タイは1つの音にまとめ、強弱記号(pp-ff)と音ごとのベロシティはvに変え、テンポ・拍子・移調楽器(実音で)・ギタータブの弦番号も読み込みます。五線とTAB譜に同じ音を2回書いたギターパートは、五線の音に弦番号だけ移します。装飾音・アーティキュレーション・ペダル・スラー・cresc. などの記号は移さず、反復記号やD.C.などは展開せず書かれたとおり1回だけ演奏します(いくつあったかは画面の下に出ます)。**和音の減衰**は同時に弾く音の数だけvを下げるもので、BiNoteで書き出したファイルはvがすでに減衰済みなので最初からオフです。ラボメニュー → **MusicXMLで書き出す** は今の曲を .musicxml ファイルで保存します。演奏者ごとに1パート、トラックごとに1声部で、l7のような長さも連符として正確に書き、小節線をまたぐ音はタイで分けます。vは音ごとのベロシティと強弱記号で、タブの弦は弦番号で書きます。異なる音を & でつないだスライドはslide記号付きの別々の音に、v0の音は休符になります。調号なしの臨時記号(#)で書くので、見た目は楽譜ソフトで整えてください。書き出したファイルを読み込み直すと、鳴る音・テンポ・拍子は同じですが、トラックの分け方は読み込み画面の設定によって変わることがあります。 ゲームのMMLで書けない長さ・位置(128分音符など)の音は最も近い1/64・1/48の位置に移し、小数のテンポは丸め、ゲームの範囲外のテンポは範囲の端に合わせ、ベロシティ0の音は外します。どれも読み込み画面の下に数が出ます。
- **ボタン名を表示**（設定 → 実験室、実験室がオンのときだけ）: アイコンボタンにマウスや浮かせたペンを乗せるか、キーボードで来るとボタンの上に名前が出ます。タッチでは長押しで出ます。ピアノロール・タブ譜のツールバーのアイコンボタンと、ロール隅の拡大ボタンで使います。画面上側のボタンは下に、下側のボタンは上に出ます。曲には何も残りません。
- **減衰のお知らせ**（設定 → 実験室、実験室がオンのときだけ）: ギター・ピアノ・ハープのように弾いた後に自然に小さくなる楽器は、ゲームのサンプルが長くても音はすぐ小さくなります。オンにすると、一番大きい時より30 dB小さくなってほとんど聞こえなくなった後もつないである音をステータスバーのチェックで「ほとんど聞こえません」と知らせ（サンプルが先に終わる音は今まで通りサンプル終わりの案内だけ）、音を1つ選ぶとその音が終わる時どれだけ小さくなったか（**終わり -12dB** のように）がステータスバーに出ます。v 1段階は v15 付近で約1 dB、v8 付近で約2 dB なので、長い音どうしの大きさを合わせるときの目安にしてください。値はゲームの録音で測ったものです。同じ区間（音色の境目の間）では高いほど早く小さくなり、境目のすぐ上の音はまた長く響きます。たとえばギターは o5e までは20 dB 小さくなるまで2-4秒かかりますが、o5f からは1秒以内です。曲は変えません。
- 減衰のお知らせをオンにすると、さらに2つ増えます。ステータスバーのチェックは、1秒を超えて響く音が同じ楽譜の他のトラックが新しく弾く音より平均12 dB以上小さくなって埋もれる所を「v を N 上げると埋もれにくくなります」と知らせます。**音量の一括調整** ウィンドウには **長い音を合わせる** が加わり、選んだ範囲の音ごとに、響いている間の平均の大きさが0.5秒の音と同じになるよう v を上げます（上げるだけ、既定は最大3段階、0.5秒以下の音はそのまま、元に戻す1回）。v を上げると出だしも大きくなるので、最大段階を小さめにして聞きながら合わせてください。
- **演奏の欠落音チェック**（設定 → 実験室、実験室をオンにしているときだけ）: いわゆる「音抜け」、ゲームで音が抜ける箇所をステータスバーのチェックに「実測前」として知らせます。同じ楽譜で2つ以上のトラックが同じサンプル区間（ピアノ・リュート・ハープはo3e・o4e・o5fで区間が変わる、楽器ごとに違う）の中でごく短い音（約150msより短い）を続けて弾き、すぐ（40ms以内）次の音に移ると、その区間の速い音とその瞬間に始まる音をトラック順に数えて5つを超えた音が抜けます。速い音のなかったトラックの音も同じ区間なら抜け、別の区間の音と打楽器は抜けません。その行の **演奏の欠落音を直す…** を押すと、抜ける音をその位置のテンポで40ms以上（t116ではr64.）遅らせる画面が開きます。箇所ごとにもまとめても直せ、遅らせる音の数と増える文字数を前もって見せ、元に戻す1回で戻ります。遅らせたくなければ、同じ区間の速い音とその瞬間の音を合わせて5つまでにするか、大事な音を前のトラックか別のサンプル区間（1オクターブ上など）に移してください。基準は録音から見つけた暫定値です。

一番下に、バージョン情報とガイドブック・**BiNote について** へのリンクがあります。

上部バーの設定（⚙）横の **?** メニューには、ガイドブック、ショートカット、アップデートを確認、BiNote について があります。**BiNote について** の画面では、バージョンの確認とアップデートの確認ができ、ソースコード・ライセンス・問題の報告へのリンクを開けます。**診断情報をコピー** は、問題を報告するときに付ける情報をコピーします（16章）。このガイドブックはステータスバーのヘルプからも開けます。

## 13. ショートカット

ピアノロールなどで使うBiNote標準のキーです。設定 → ショートカット（Ctrl+/）で変更したり、**MabiIcco互換** のキーに切り替えたりできます。MacではCtrlの代わりにCmdも使えます。

MMLエディタで入力中は、Ctrl・Altの組み合わせとFキーだけをショートカットとして受け付けます。そのうちCtrl+A・C・X・Vと長さ ×2・½はテキスト編集に使われ、Ctrl+D（同じテキストをもう1つ選ぶ）・Ctrl+←→（単語単位で移動）もエディタ自身の動作です。音・トラック・イベントを変更するショートカット（Alt+S・G・B・M・L・P、Alt+↑↓など）は実行されません。保存・再生・元に戻す・検索・置換は使えます。

## 14. iPad・スマートフォンで使う

- タッチでは **パネルを横** が標準です。iPadの縦画面（縦長のPCウィンドウも）では上下に分かれ、パネル上部の **構成 | MML** でどちらかを表示します。MML側ではエディター上のトラック帯からすぐトラックを切り替えられます。
- 音の選択は **選択ツール** が安全です（入力も移動もしません）。削除は **消しゴム**。
- トラックを **長押しすると** メニュー（上へ移動・下へ移動・トラックを複製・移動・下のエディタで開く）が開きます。
- イベントの行の空いている所を **長押しすると**、テンポ・マーカーを追加します。
- 2本指でロールを拡大・移動します。
- **MMLキーパッド**（表示メニュー）をオンにすると、画面キーボードなしでMML文字を入力できます。
- タブ譜は **フレット数字パッド** で入力します。
- iPadのSafari・Chromeは同じエンジン（WebKit）のため、保存領域が整理されることがあります。**.mmeをファイルアプリに保存** しておいてください。
- iPad・iPhoneのホーム画面のアプリとSafariのタブは保存領域が別のため、サウンドパックをそれぞれ追加する必要があり、自動保存も互いに見えません。
- iPadではMIDI鍵盤を使えません。
- AndroidにインストールしたBiNoteは **共有** メニューに表示されます。ほかのアプリからMML@ テキストや楽譜・音源ファイルを共有すると、BiNoteですぐに開きます（1章 開き方）。

## 15. よくある質問

**音が出ません。**
サウンドパックを追加したか、ステータスバーを確認してください。「サウンドパックで見つからなかった楽器」が出たら、その楽器が入ったパックを追加してください。別のパックの音が優先される場合は、設定のサウンドパック一覧で▲▼を使って順序を変えます。iPhone・iPadは消音スイッチも確認してください。

**ゲームに貼り付けたらエラーになります。**
「MMLで書き出す」ウィンドウでエラー・警告の数を見て、ステータスバーのチェックで位置を探して直します。1回の貼り付けに MML@ テキストを1つだけ入れたかも確認してください。

**試聴とゲームの音が違います。**
試聴は、追加したサウンドパックの音色とBiNoteの再生方式で音を鳴らします。パックの種類や楽器の対応によって、ゲームの音と異なる場合があります。音域の折り返し（グレー）とサンプルが終わる長い音は、チェック結果で確認してください。

**文字数がずっと上限を超えます。**
音符の再配分 → 文字数を減らす → 楽譜集に分割の順で試してください（9章）。

**作業が消えました。**
ファイル → 以前の作業を復元を確認してください。別のタブで開いている作業は「別のタブで開いています」と表示され、コピーとして開きます。ステータスバーに **自動保存されていません** が出ているときは自動保存ができていないので、すぐに .mme で保存してください。iPad・iPhoneは、ホーム画面のアプリとSafariのタブの自動保存が互いに見えません。サイトのアドレスが異なると（例: テスト用アドレスと正式なアドレス）保存領域も異なるため、自動保存は引き継がれません。長く残したい曲は .mme で保存してください。

**画面の一部が「この画面を描く途中で問題が起きました」に変わりました。**
曲の内容はそのままで、すぐに自動保存されます。**表示を作り直す** を押してください。続くときは **診断情報をコピー** でコピーしたテキストを付けて報告してください（16章）。

**より新しいBiNoteで保存したプロジェクトなので開けないと出ます。**
ページを再読み込みして最新のBiNoteで開いてください。より新しいバージョンのファイルでも、「このバージョンで読んでもよい」と書かれていれば案内とともに開きます（11章）。

**3MLE形式で保存したら文字が ? になりました。**
3MLEの既定のエンコーディング（CP949）にない文字です。UTF-8で保存するか、名前を変えてください。

**MabiIccoで開いたらエラーになります。**
MabiIccoのグリッド（4分音符96分割）に合わない音があると、保存時にお知らせします。その音の長さをグリッドに合わせてください。

## 16. 問題・翻訳の報告

設定の一番下の **問題・翻訳の報告**、またはリポジトリの [Issue](https://github.com/EarlGreyPie/BiNote/issues/new/choose) から送ってください。

- ? → **BiNote について** → **診断情報をコピー** を押すと、バージョン・ビルド・ブラウザ・オンにした実験室の機能・最近のエラーをコピーします。報告の文（バグ報告フォームの診断情報の欄）に貼り付けてください。曲の内容は含みません。コピーできないときは、画面に表示されたテキストを選んで自分でコピーしてください。
- 診断情報を付けられないときは、バージョン情報（設定の一番下の「BiNote v…・コミット …」）と端末・ブラウザを一緒に書いていただけると助かります。
- 曲が必要な場合は、MML@ テキストか短い例で十分です。**サウンドパックのファイルは添付しないでください。**
- 翻訳の誤りや不自然な表現は「翻訳の報告」を選んでください。ゲーム内の公式表記を教えていただけると特に助かります。
