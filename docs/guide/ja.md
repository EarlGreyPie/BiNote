# BiNote ガイドブック

マビノギモバイル向けMML楽譜エディタ **BiNote（バイノート）** の使い方の案内です。1.0 Beta 時点の内容です。

> ネクソン・マビノギモバイルとは関係のない、非公式の個人ファン制作ツールです。ゲーム名・楽器名・音の権利はネクソンに帰属します。

このガイドのゲームの上限は韓国サーバーで実測したBiNoteの検査基準であり、一部のゲーム用語は暫定的な翻訳のため、誤りがあれば[翻訳の報告](#16-問題翻訳の報告)でお知らせください。

## 1. はじめに

### 開き方

Webブラウザ（Chrome・Edge・Safari）でBiNoteのサイトを開きます。インストールせずに使えます。最初のアクセスでアプリのファイルをすべて受け取っておけば、それ以降はインターネットなしでも開けます。オフラインで使う予定なら、事前にネットワークを切って開き直せるか確認しておいてください。このガイドブックはインターネット上の文書のため、オフラインでは開けません。

よく使う場合は **ホーム画面に追加（アプリのインストール）** をおすすめします。

- PCのChrome・Edge: アドレスバー右側のインストールアイコン
- iPad・iPhoneのSafari: 共有 → ホーム画面に追加
- AndroidのChrome: ⋮ → ホーム画面に追加（アプリをインストール）

インストールしたアプリとブラウザのタブが保存領域（サウンドパック・自動保存）を共有するかどうかは、端末によって異なります。

- PC・Android: 同じブラウザ、同じプロファイル、同じアドレスなら共有します。
- iPhone・iPad: ホーム画面のアプリはSafariのタブと保存領域が別です。ホーム画面のアプリでもう一度サウンドパックを追加する必要があり、タブで自動保存された曲も表示されません。

別の端末や別のブラウザに作業を移すときは、プロジェクト（.mme）ファイルとして保存して開いてください。

### 最初の画面

曲がないとき、最初の画面にはボタンが3つあります。

| ボタン | 内容 |
|---|---|
| 新しい楽譜 | ピアノの楽譜1つ、空のトラック1つで開始（t120、4/4） |
| 楽譜を開く | 3MLE（.mml）、MabiIcco（.mmi）、MIDI（.mid）、BiNoteプロジェクト（.mme）を開く |
| MML@ を貼り付け | ゲーム用の `MML@…;` 形式の楽譜テキストを貼り付けて開く。エディタの外でCtrl+Vを押しても開けます |

編集中の曲があると、その下に **以前の作業** の一覧が出ます。再読み込みしたりタブを閉じたりしても、ここから復元できます。

### サウンドパック

**編集はサウンドパックがなくてもできます。** 音を聞くには、サウンドパック（.dls・.sf2・.sf3）を追加してください。マビノギのサウンドパックはネクソンの資産のためBiNoteには含まれていません。別途ご用意ください。

- 追加: 設定（⚙）→ サウンドパック → サウンドパックを追加、またはステータスバーの「サウンドパックなし」をクリック
- 複数追加すると、**一覧の上にあるパックが優先** されます。先に追加したパックが上に置かれます。パックの横の▲▼ボタンで順序を変えられ、変えた順序は次に開いたときもそのままです。
- MabiIccoの番号だけで書かれた楽器（例: `#40.3`）は順序に関係なく、`.2`・`.3`の番号に合うパック（ファイル名で判別）だけから探します。パックごとに同じ番号が別の楽器のことがあるため、そのパックがなければ他のパックで代わりに鳴らさず、見つからない楽器としてお知らせします。ハープ（`24.2`）のように名前が分かる楽器は番号に合うパックを先に使い、なければ他のパックの同じ楽器を使います。
- **トラックごとに鳴らすパックを選べます。** トラックエディターの見出しで楽器の選択の横にあるパックの選択（パックが2つ以上のとき表示）でパックを選ぶと、そのトラック（トラックの楽器がなければその楽譜）はそのパックで鳴ります。既定は **自動（上のパックから）** です。選んだパックが今なければ上のパックから探して鳴らし、パック名の後ろに「（なし）」を付けて表示します。曲には選んだパック名が残るので、そのパックを再び追加するとそのパックで鳴ります。`.2`・`.3`のパックを選ぶと、MabiIcco形式で保存するときの楽器番号にもそのパック番号が入ります。
- 楽器番号に`.2`・`.3`のパック番号がある楽器は、トラックエディターの楽器の選択、トラック帯の楽譜チップ、見つからない楽器のお知らせで **ハープ(24.2)** のようにパック番号も表示します。基本の楽器は名前だけ表示します。
- 追加したパックはこのブラウザに保存され、次に開いたときに自動で読み込まれます。ファイルをサーバーへ送信することはありません。
- パックにない楽器があると「サウンドパックで見つからなかった楽器」としてお知らせします。

### クイックスタート: 最初の楽譜を作る

1. 最初の画面で **新しい楽譜** をクリックします。
2. ピアノロールの空いているマスをクリックして音を入力します。MMLで書く場合は、トラックパネルのMMLエディタに次の例を入力します。
   ```
   t120o4l4v8cdefgab>c
   ```
3. サウンドパックを追加していれば、**再生**（Space）で聞いてみます。サウンドパックがなくても、編集とゲーム用のコピーはできます。
4. **ファイル → プロジェクトとして保存**（Ctrl+S）で `.mme` ファイルを保存します。3MLE（.mml）での保存はCtrl+Alt+Sです。
5. **ファイル → MMLで書き出す…** でエラー・警告と文字数を確認します。
6. 使う楽譜の **MML@ をコピー** をクリックし、ゲームの空の楽譜に貼り付けます。楽譜が複数ある場合は1つずつコピーします。

上の例はトラックのエディタに入れるMMLです。**MML@ を貼り付け** で開くときは、`MML@t120o4l4v8cdefgab>c;` のように全体の形式で書きます。

## 2. 先に知っておきたいゲームのルール

BiNoteはマビノギモバイルの上限に合わせてチェックと出力を行います。次の用語は、画面とこのガイドブックで同じ意味で使います。

| 用語 | 意味 |
|---|---|
| **楽譜** | ゲームに一度に貼り付ける単位。`MML@トラック1,トラック2,…;` 1つ |
| **トラック** | 楽譜の中の1行（メロディ・和音1〜5）。1つのトラックは一度に1音だけ鳴らします |
| **演奏者** | 楽譜の中で楽器1つを担当する人。1つの楽譜に複数の演奏者が入れます |
| **楽譜集** | 長い曲を複数の楽譜に分けて続けて演奏すること |

ゲームの上限:

- 1つの楽譜に **トラックは最大6個**。最初の演奏者が1〜3トラック、その後の演奏者は1トラックずつ（3+1+1+1、2+1+1+1+1、1×6は可、2+2+2、3+3は不可）
- **オルゴール・蓄音機** は1つの楽譜に3トラック。6和音は3トラックの楽譜2つに分けて同時に鳴らします（どちらの貼り付けにも6トラックをすべて入れ、順番だけ変えます。ゲームは前の3トラックだけを鳴らし、曲の長さとテンポは6トラックで決まるので2台がずれません）。別の楽器を設定したトラックはオルゴールの楽譜に置けないため、新しい楽譜に移します
- 1トラックに **2400字**
- **テンポは楽譜ごとに別々に** 読まれます。そのためBiNoteはMMLで書き出すとき、すべての楽譜にテンポを入れます
- テンポ t32〜t255、音長 1〜64（付点1つまで。いちばん短い64分音符にも付点が付き、`64.` = 3/128 まで使えます）、音量 v0〜v15（v0は無音）
- 楽器ごとに鳴る高さが決まっていて、範囲外の音はエラーにならずオクターブ単位で移され、範囲内で鳴ります。このガイドではこれを **音域の折り返し** と呼びます
- 楽譜集で次の楽譜に移るとき、約1秒のすき間ができます

上記の上限は、韓国サーバーで実測したBiNoteの現在の検査基準です（2026-10時点）。画面の言語を日本語・中国語に変えても検査基準は同じで、ほかのサーバーの上限を表すものではありません。同じ演奏者のトラック同士で同じ音が重なったときの動作など、まだ実測が終わっていない項目もあります。

## 3. 画面の見方

```
┌ 上部バー: ファイル · 編集 · 曲 · 表示 · 元に戻す · 再生 · 音量 · ヘルプ(?) · 設定 ┐
├ ツールバー: ピアノロール/タブ譜 · ツール · グリッド · 新しい音 · 入力 v · 横|縦（パネル位置） · レイヤー · 拡大 · ⋯      ┤
├ 作業領域: ピアノロール(またはタブ譜)  │  トラックパネル(構成一覧 + MMLエディタ)           ┤
└ ステータスバー: 選択中のトラック · 文字数 · チェック · サウンドパック · ヘルプ                ┘
```

### メニュー

| メニュー | 項目 |
|---|---|
| ファイル | 新しい楽譜、楽譜を開く、MML@ を貼り付け、以前の作業を復元、保存（3MLE・プロジェクト・MabiIcco・MIDI・WAV）、MMLで書き出す、サウンドパックを追加、MIDI鍵盤を接続 |
| 編集 | 元に戻す・やり直し、すべて選択、削除・切り取り・コピー・貼り付け、長さ ×2・½、アルペジオ、スライド、装飾音、移調、トラックの分割・結合 |
| 曲 | 音量の一括調整、拍子を変更、タップテンポ、テンポを削除、テンポを一括変更、楽譜ごとにテンポを入れる、ずれた長さを探す、トラック・楽譜を追加、音符の再配分、和音の統合、文字数を減らす、楽譜集に分割 |
| 表示 | ピアノロール/タブ譜、パネルを下/横、並べて表示、エディタの数、縦ロール、イベント、音一覧、再生中に鍵盤を光らせる、選んだ音の鍵盤を光らせる、停止位置をMMLに表示、トラックの色、MMLキーパッド、タブのフレット数字パッド、ショートカット |

### トラックパネル

- **構成一覧**: 楽譜 → トラックの順に表示されます。トラックごとにM（ミュート）・S（ソロ）、文字数バー、ロック、⋯ メニュー（上へ移動・下へ移動・トラックを複製・別の楽譜へ移動・新しい楽譜へ移動/複製・ロールで非表示）があります。MMLのチェックがあるトラックは、名前の横に赤い点と件数が表示されます。
- 名前はダブルクリックで変更します（Enterで確定、Escでキャンセル）。
- 左のハンドルをドラッグして、トラックを別の楽譜に移せます。トラックを長押しする（タッチ）とメニューが開きます。
- **MMLエディタ**: 選択中のトラックのMMLテキストを編集します。文法エラー・ゲームの上限の問題は下線で示され、下線にマウスを乗せると内容が表示されます。
- パネルはツールバー右側（レイヤーの左）の **横 | 縦** ボタンで移動します。**横** はロールの横（マウス・タッチ向け）、**縦** はロールの下（3MLE式、キーボード向け）です。表示メニューのパネルを下/横と同じです。境目をドラッグしてサイズを変えます。
- 表示 → **エディタの数**（1〜4個、最大数は設定 → 画面）でトラックパネルにMMLエディタを上下に並べ、複数のトラックの文を一度に見られます。上は選んだトラックで、一覧・トラック帯でAlt+クリックしたトラックは一番長く変えていない下のエディタで開きます（エディタが1つなら2つに増やします）。同じトラックを2つのエディタで開くことはなく、下のエディタはそれぞれ × で閉じます。

### ステータスバー

- 選択中のトラック、文字数 / 上限
- **チェック N**: 曲全体のチェック結果。クリックすると展開され、「その位置へ移動」で問題の位置に移動します。
- サウンドパック数と楽器数
- **ヘルプ**: ピアノロール・タブ譜の操作のまとめ

## 4. 音を入力する

ピアノロール・MMLエディタ・タブ譜で編集した内容は、すべて同じ曲に反映されます。

### ピアノロール

| 操作 | マウス | タッチ・ペン |
|---|---|---|
| 音を入力 | 空いているマスをクリック（ドラッグした分だけ長く） | 空いているマスをタップ |
| 移動 | 音をドラッグ | 音をドラッグ |
| 長さの変更 | 音の端をドラッグ | 音の端をドラッグ |
| 削除 | 右クリック | 消しゴムツール |
| 複数の音を選択 | Ctrl+クリック、空いている所でCtrl+ドラッグ | 選択ツールでドラッグ |
| 再生カーソルを置く | Shift+クリック | — |
| ループ区間 | Shift+ドラッグ | — |
| 次の音と & でつなぐ | Alt+クリック | — |

- **新しい音** の長さ: 「グリッドどおり」ならグリッド1マス分、別に選ぶとグリッドに関係なくその長さ（3連符を含む）
- **連符**: 新しい音の長さ一覧の一番下の **連符…** で「N個をどの音符の長さに」を選びます（2〜15個、全・2分・4分・8分・16分・32分音符とその付点音符）。1音の長さは基準の数字×Nです: 4分5連符 = l20、4分7連符 = l28、付点4分2連符 = l8.。選んだ連符が新しい音の長さになり、**グリッドもそのマスにする**（既定オン）でグリッドも変わります（4分5連符なら1/20）。ゲームは l1〜l64 しか受け付けないので、16分5連符（l80）のように短い音は選べません（丸めません）。決めた連符はこのブラウザに記憶します
- グリッド一覧には、決めた連符のマスと新しい音の長さに合うマスも出ます。付点4分5連符（l20.）なら 1/40 が出ます。1マスが 1/64 より短いグリッド（1/128 など）は、その長さの音・休符をゲーム用に書けないため出しません。64. の後ろに続けて入れるときはタブの数字パッドか MML テキストを使います
- ゲーム用に正確に書けない長さの音や休符が残る編集（例: 4分5連符の音を 1/28 グリッドで切ると 1/70 の切れ端が残る）は行わず、理由を表示します。入力・切る・貼り付け・長さ変更・移動・アルペジオ・スライド・装飾音だけでなく、小節を削除、トラックの分割・結合、音符の再配分・和音の統合のような曲の編集もすべて同じです。MMLテキストを直接書いたり貼り付けたりしたものだけは書いたとおりに残します
- **ツール**: 入力（標準）・選択（クリックやドラッグで選ぶだけ。横の鍵を外すと選択した音をドラッグして移動）・消しゴム・はさみ（クリックした位置で音を分割）
- **レイヤー**: ロールに選択中のトラックだけ / 楽譜 / すべてを描きます。他のトラックの音は薄く表示され、「他のトラックの音をクリックして選択」をオンにするとそのトラックに切り替えます。
- 音をクリックするとMMLテキストでその位置を表示し、ダブルクリックするとその場で入力できます。
- 画面の移動: ホイール（時間）・Shift+ホイール（音の高さ）・Ctrl+ホイール（時間の拡大）・Ctrl+Shift+ホイール（鍵盤の高さの拡大）・全体を表示ボタン
- ロール右下の隅のボタンでも拡大・縮小（時間 −/+、鍵盤の高さ −/+）と全体を表示ができます（縦ロールでは鍵盤の帯の上の右側）。ふだんは薄く表示され、画面がとても狭いときは鍵盤の高さ −/+ をツールバーや ⋯ メニューで使います
- 設定 → 画面 → **音符の音量の数字** をオンにすると、選んだトラックの音の上に `v12` のように音量が出ます（縦ロールでは音の始まりの右）。**変わるところだけ** は前の音と音量が違う音と画面で最初に見える音に、**すべての音** はすべての音に書きます。`&` でつないだ後ろの音には書かず、混み合うと重なる数字は飛ばします（拡大すると見えます）
- **縦ロール**: 落ちてくるノーツの動画を見ながら打ち込むとき設定 → 画面 → **再生中のロール**を**連続スクロール**にすると、再生中に音が上から鍵盤へ降り続けます（縦動画の録画用）。

### MMLエディタ

MMLを直接書きます。編集したテキストはピアノロールと試聴に反映されます。文法エラーがあれば、下線とステータスバーのチェックを確認してください。

| コマンド | 意味 |
|---|---|
| `c d e f g a b` | 音（`+`・`#` でシャープ、`-` でフラット）、後ろに長さ（`c8`、`e4.`） |
| `r` | 休符 |
| `n番号` | 音番号で書く |
| `o番号` `<` `>` | オクターブの指定、下げる、上げる |
| `l番号` | 基本の長さ |
| `v番号` | 音量 0〜15 |
| `t番号` | テンポ |
| `&` | 次の音とつなぐ（同じ音はタイ、異なる音はスライド） |

- 同じ音を `&` でつなぐと、& の後の v はゲームで無視されます。
- 異なる高さを `&` でつなぐと、弾き直さずにつないだ位置で高さだけが変わります（滑らかにつながる音ではありません）。BiNoteではこれをスライドと呼びます。`&` を消すと別々に弾く音になり、演奏が変わります。
- iPadでは **MMLキーパッド**（表示メニュー）をオンにすると、画面キーボードの代わりにMML文字のキーパッドを使えます。

### タブ譜（ギター譜）

ピアノロール/タブ譜ボタン（Alt+T）で切り替えます。選択した楽譜のトラックをまとめ、弦・フレットを自動で選びます。

- 弦の上をクリックしてカーソルを置き、**数字でフレットを入力**（0〜24、2桁は続けて入力）、矢印キーで移動、Deleteで削除
- キーボードや数字パッドでカーソルを動かして画面の外に出ると、画面が追って送られます（表示 → **カーソルを追う** でオン・オフ。既定はオン）
- 一番上の **小節番号の行** を押すとその位置から再生し（再生中ならそこから続けて再生、再生位置をもう一度押すと消去）、ドラッグすると繰り返し区間を決めます（ピアノロールと同じ。タッチも指でドラッグ）。再生位置・繰り返し区間はピアノロールと共通なので、表示を切り替えてもそのままです。キー設定の **再生位置を編集カーソルへ** にキーを割り当てると、再生位置をタブのカーソル位置へ移せます（既定のキーなし）
- `+` / `-`：カーソルの音の長さを2倍 / 半分に（新しい音の長さも変わります）。数字パッドでは **新しい音** を変えるとカーソルの音の長さも変わります。伸ばすときは同じトラックの次の音の手前まで
- `.`：付点を付ける・外す。選んだ音、選んでいなければカーソルの音（つないだ音ならカーソルのある音）に付点を付けたり外したりします（4分音符 ↔ 付点4分音符）。カーソルの音もなければ新しい音の長さに付けます。数字パッドには音符入力パッドの端に **.** ボタンがあります
- 既存の音の上でフレットを打つと高さだけ変わり、長さはそのままです
- `L`: すぐ後の音と & でつなぐ・`(5)` タイ・`5/7` スライド。後ろが空いていれば同じ音を新しい音の長さだけ足してつなぎます（8分音符 + L で4分音符の長さ）
- 同じ位置の和音は、同じ楽譜の空いているトラックに入ります
- チューニング（スタンダード・ドロップD・DADGAD・ナッシュビル・バリトンなど）とカポを選べます
- 違うチューニングでTABを入力してしまったら、チューニングの横の **TABはそのままチューニング変更…** を使います。弦・フレットの数字はそのままで、音の高さを新しいチューニング（カポ含む）のものに変えます。元に戻す1回でチューニングも一緒に戻ります。楽譜集の「up 1/2 step」チューニングは同じチューニングにカポ1で表せます
- 拡大ボタンは、PC（マウス）ではピアノロールと同じく上のツールバー（入力 v の後ろ）に、タッチ画面ではタブ譜下のツール帯（時間スクロールバーの横）にあります。横 −/+ で時間を拡大し、PCツールバーの **全体を表示** で曲全体が一画面に収まるように合わせます（ツールバーが狭いときは `A−` / `A+` と指板の位置は ⋯ メニューにあります）
- 設定 → 画面 → **音符の音量の数字** をオンにすると、指板の一番下（弾けない音の × の下）に `v` の行ができ、選んだトラックの音の音量をピアノロールと同じ決まりで書きます。選んだ音の数字は濃く出ます。オフにすると行はなくなります
- `A−` / `A+` でタブ譜の大きさ（弦の間隔・文字）を、その横の **指板の位置** ボタン（⤒ / ↕ / ⤓）で、高さに余りがあるとき指板を枠の上・中央・下のどこに置くかを選びます。押すたびに上 → 中央 → 下と変わり（既定は中央）、このブラウザに記憶します。フレット数字パッドを開いているときは常に上に付きます
- トラックが複数あると数字の枠がトラックの色で薄く塗られ、選択中でないトラックの数字は薄く表示されます（設定 → 画面 → タブ譜の数字にトラックの色 でオフにできます）
- タッチでは **フレット数字パッド** を使います。パッド上部の **新しい音** で入れる音の長さを選びます（グリッド通り / l4 / l8 / 3連符など。ツールバーの「新しい音」と同じ設定）。「入力後に次のマスへ」をオンにすると、その長さだけ進みます
- フレット数字の上には **音符入力パッド** が1列あります（グリッド / 1 / 2 / 4 / 8 / 16 / 32 / 64。幅が足りなければ横にスクロール）。押されているボタンが新しい音の長さで、カーソルに音があればその音の長さも変わります。付点は列の端の **.** ボタンで付けます。3連符（3・6・12・24・48）のボタンは 設定 → 画面 → **音符入力パッドに3連符** をオンにすると表示されます。決めた連符（例: 20）のボタンは 設定 → 画面 → **音符入力パッドに連符** をオンにすると末尾に表示されます。設定 → 画面 → **タブの数字パッドで数字を押した後** でカーソルの移動先を選びます: **次のマスへ**（既定、入れた長さだけ）/ **下の弦へ（和音）**（同じ位置で1本下、一番下の弦ならそのまま）
- 表示 → **タブのフレット数字パッド** をオンにすると、マウスで指板を押してもフレット数字パッドが開きます（オフならタッチ・ペンのみ）。このブラウザに記憶します
- 数字パッドは右上の **×** で閉じます（Esc も同じ）。閉じた後は指板の弦をもう一度押すか、タブ下のツールバーの **数字パッド** ボタンで開き直します。カーソルがなければ今見えている最初のマスに置きます
- 上の変化の行はピアノロールと同じく2段です：**上の段はテンポ、下の段は拍子・マーカー**（ピアノロールと同じ順番・色）。上の段を **ダブルクリック**（タッチ・ペンは長押し）すると、その位置にテンポを入れます（曲の最初に4/4があっても、上の段ならテンポが入ります）。下の段の空いた場所をダブルクリックするとマーカーを入れます。テンポの文字ならそのテンポを、拍子の文字なら拍子を直します（新しい拍子は拍子の文字を直すか、ツールバーの **拍子** 欄で）。`Alt+B` でもできます（タブのカーソル位置、なければ編集カーソルか曲の最初）。空いた場所にマウスを乗せると段ごとにこの案内が出ます。変化の行を **1回クリック** すると、ピアノロールのイベント行と同じく、その位置へ再生位置（点線）が移ります。変化の行は小節番号の行と同じ背景色で塗られ、タブの線と見分けられます。文字の大きさは 設定 → 画面 → **イベント行の文字（タブ・ピアノロール）** で 10・13（標準）・16・20px から選びます（ピアノロールのイベント行も同じ設定）。ダブルクリックで開く画面にはテンポ・拍子・マーカーの欄が並び、複数チェックするとその位置にまとめて入れ、既にあるもののチェックを外すと消します（元に戻す1回）
- ツールバーの **拍子** 欄でも、タブのカーソルがある小節（カーソルがなければ再生カーソルの小節か曲の最初）から拍子を変えられます
- ピアノロールで入れたマーカーも下の段に出ます（マーカーは曲に1組で、2つの表示が共有します）。マーカーの文字を **ダブルクリック**（タッチ・ペンは長押し）するとマーカーのウィンドウが開き、名前を直したり消したりできます。長い名前は最初の12文字だけを書いて…を付け、マウスを乗せると全体の名前が出ます
- **音の選択**: `Shift+←/→` でカーソル位置から時間の範囲を広げたり狭めたりすると、その範囲で始まる音を弦・トラックに関係なくすべて選びます（縦1列すべて）。マウスは `Shift`+クリック（カーソルからクリックした位置まで）・`Shift`+ドラッグ、`Ctrl+A` はタブ譜に表示中のトラックの音をすべて選びます。タッチでは数字パッドの **選択** ボタンをオンにして指板を押しながら範囲を広げます（もう一度押すか Esc でオフ）。選んだ数字はアクセント色で薄く塗られ、`Shift` なしのクリック・方向キー・Esc で解除されます。音を選んでいるときの `Shift+↑/↓` はピアノロールと同じくオクターブを上げ下げし、選択は残るので続けて押せます(キー設定でオクターブのキーを変えた場合はそのキー)
- 選んだ音には編集メニューとショートカットがピアノロールと同じように使えます: 削除（Delete）・切り取り・コピー・貼り付け、長さ ×2・½（`+`/`-`、伸ばすときは選んでいない次の音の手前まで）、オクターブ・音量の上げ下げ、タイ（`L`）、分割（Alt+S、タブのカーソル位置）、結合（Alt+G）。オクターブを変えてその弦で弾けなくなると弦を選び直します。何も選んでいなければ Delete・`L`・`+`/`-` はこれまでどおりカーソルの音に使われます。ロックしたトラックが含まれると変更せずにお知らせします
- **和音のコピー・貼り付け**: タブ譜でコピーするとトラックの分け方のまま保ち、タブ譜に貼り付けるとタブのカーソル位置（なければ元の位置）から、最初の層を最初のトラック、次の層を次のトラックに入れます。そのトラックに重なる音があれば空いたトラックを探し、足りなければ楽譜のトラック上限までトラックを追加します。上限のため1つでも入らなければ何も貼り付けずにお知らせします。ピアノロールに貼り付けるとき和音が重なる場合は貼り付けずにお知らせします（1つのトラックには一度に1音しか入りません）

### MIDI鍵盤

ファイルメニュー → **MIDI鍵盤を接続** をオンにしてMIDI鍵盤をつなぐと、1音ずつ入力する **ステップ入力** ができます。再生カーソルの位置（なければ選択中のトラックの末尾）に **新しい音** の長さで入力し、入力位置がその長さだけ後ろへ進みます。鍵盤を押していた時間で長さを録音するわけではありません。

- 同時に押した音は、最も高い音が現在のトラックに、残りが高い順に同じ楽譜の次のトラックへ入ります。残りのトラックより音が多いと、あふれた音は入力されないため、和音を入れる前にトラック数を確認してください。
- MIDI鍵盤を初めてオンにしたとき、ベロシティを v として入れるかを一度だけ聞きます。あとで 設定 → 再生 →「ベロシティ → v」で変えられます。

> 推奨ブラウザはPCのChrome・Edgeです。Safari（Mac・iPad）とiPadのその他のブラウザでは、MIDI鍵盤を使えません。

## 5. 音を編集する

### 選択した音を変える

| 内容 | 方法 |
|---|---|
| 1マスずつ移動 | 矢印キー |
| オクターブを上げる・下げる | Shift+↑ / Shift+↓ |
| 音量を上げる・下げる | Alt+↑ / Alt+↓、Alt+ホイール |
| 音量を直接入力 | Alt+数字（6〜9 → v6〜9、0 → v10、1〜5 → v11〜15、Alt+\` → v0、Alt+Shift+0〜5 → v0〜5） |
| 長さ ×2 / ½ | Ctrl+] / Ctrl+[、+ / -（テンキーの +/− も）。音を選んでいなければ新しい音の長さ（ツールバーの長さ選択）を ×2 / ½。選んでいない次の音は消さず、その手前までだけ伸ばします |
| 付点を付ける・外す | `.`（テンキーの `.` も）。選んだ音に付点を付けたり外したりします（4分音符 ↔ 付点4分音符）。音を選んでいなければ新しい音の長さに。3連符・つないだ長さのように1トークンで書けない長さは変えません。付点で次の音と重なるときは中途半端に伸ばさず、変えずにお知らせします（後ろの音は動かしたり消したりしません） |
| 長さを正確に | ステータスバーの選択した音の欄にMMLの音長（8、8.、16..）か分数を書いてEnter。分数は全音符単位なので、`1/7` は全音符の7分の1です。ゲーム用に1〜64の音長（付点1つまで）を & でつないで正確に書ける長さだけ受け付け、書けない長さ（例: `1/100`）は変えずに理由を表示します |
| つなぐ・解除 | Alt+L |
| 分割 | はさみツール、または再生カーソル位置でAlt+S |
| 結合 | Alt+G（高さが同じで接している音を、編集上1つの音に。& でつなぐのとは別） |
| コピー・切り取り・貼り付け | Ctrl+C / Ctrl+X / Ctrl+V（再生カーソルの位置に貼り付け） |

**アルペジオ**（編集メニュー）: ピアノロールで音を選んで開くと、和音を順番に広げます。方式は3つです。**1つのトラックに広げる** は選んだトラックのその位置に和音の音を順に入れ（和音トラックの音は消すか残すかを選べます）、**分散和音（元の長さのまま）** は元の和音の音を残したまま開始だけ順に遅らせ、**トラックを順に繰り返す** は音の長さごとに同じ楽譜のトラックを順に使って弾き直します（足りなければトラック上限の範囲でトラックを足します）。和音の音は 同じ時刻に始まる音 / 選んだ音だけ / コード名（メジャー・マイナー・7・M7・m7・sus4・sus2・dim・aug・add9）から取り、順序（上へ・下へ・上下・ランダム）、音の長さ（三連符 l3・l6・l12・l24・l48 と決めた連符を含み長さ順）、オクターブの幅（1〜3）、繰り返しを選びます。プレビューで確かめて適用し、元に戻す1回で戻ります。同じ時刻の音では、プレビューの上の **和音に入れるトラック** をチェックで選びます（選んだトラックは常に入ります）。選んだ音の最初の開始から最後の開始まで、チェックしたトラックの音が一緒に始まる位置ごとに和音になるので、音を1つ選ぶだけでもその位置の和音全体を使えます。枠は選んだ音より長い和音の音があればその音の終わりまでです（長いベースを切りません）。

- **ギター譜の波線の和音** は **分散和音 + 64分** で作ります。新しい音を作らず、元の和音の音をその場（トラック・音量・タブの弦はそのまま）に残して開始だけ順に遅らせ、終わりはそれぞれ元のままです。**上へ = 低い音から**（ギターの6弦側から）、下へ = 高い音から。分散和音はオクターブの幅・繰り返しを使いません。同じ時刻の音ならその位置の和音全体を、選んだ音だけなら選んだ音だけを分散し、コード名は新しい音が要るため同じ時刻の音で分散します。タブでは弦ごとに別トラックにある選んだ音（カーソル位置ならその位置の和音）をまとめて使います。短すぎて遅らせられない音はそのままにします。
- トラックを順に繰り返す方式は新しい音を作りますが、同じ高さの元の音のトラック・音量・タブの弦を引き継ぎ、元の和音の音が短くなる枠は作らずにお知らせします。チェックを外したトラックは読みも変えもしません。
- **タブ譜表示**でも使えます。タブ譜で選んだ音があればその音、なければ **タブのカーソル位置の和音**（その位置で始まる同じ楽譜の音）を使います。

**スライド**（編集メニュー）: ギターのように滑る音を作ります。**2つの音の間** は続いている2つの音の間を半音ずつつなぐ短い音で埋め、**スライドイン・アウト** は音の前の部分を何半音か下（上）から始めたり、終わりの部分で落としたりします。つなぐ音は `&` で結ぶので弾き直さず高さだけが変わります。スライドの長さと1歩の長さ（自動ならゲームの最短音長に合わせて分け、足りなければ半音を飛ばします）を選びます。つなぎの最初の音から24半音を超える所は作らず、高い方へ長く滑るとサンプルの終わりで音が早く切れることがあるので事前に知らせます。つなぐ音1つごとに数文字増えて文字数が早く増えるので、ウィンドウの文字数の案内を確かめてください。

- ピアノロールとタブ譜のどちらからも開けます。タブ譜では選んだ音、選んだ音がなければカーソル位置から始まる和音全体が対象です。
- **スライドイン・アウト** は1つの音にスライドインとスライドアウトを両方付けます（タブ譜の `/14\`、`\14/`）。イン・アウトごとに方向（下から・上から / 下へ・上へ）、距離（フレット = 半音）、長さを別々に選びます。アウトの音は音の終わりの部分から取ります。
- 入る位置 **拍の上**（既定）は到着音の頭を削るので到着音が少し遅れて聞こえ、**拍の前** は装飾音の拍の前と同じく前の音の終わり（または前の休符）から長さを取るので到着音が拍どおりに聞こえます。前の音が l64 より短く残るか正確に書けない場合、その音は飛ばします。
- 和音を選ぶと弦（トラック）ごとに自分のトラックで一緒にスライドします。空いた所から和音全体へのスライドイン（例: `2/1/2/1/`）が一度ででき、2つの和音を選んで **2つの音の間** を選ぶと弦ごとに前の和音から次の和音へ滑ります。トラックを新しく作らないので和音数の上限は変わりません。
- **音色が変わる所で切る**（既定オン）: ゲームは `&` でつないだ音がサンプル区間の境目（o3e・o4e・o5f など、楽器ごとに違う）をまたぐと別のサンプルに切り替えるため音色が跳ねます。オンにすると作ったつなぎのその位置で `&` を外して弾き直します。オフならプレビューに赤い点線で示して知らせます。試聴の音はサウンドパックのサンプルがゲームと違うので変えず、表示だけで知らせます。
- 元からある `&` が音色の境目をまたぐと曲の検査に出ます。検査欄の **すべて切る** でそのような `&` を一度に外せます（元に戻す1回、ロックしたトラックはそのまま）。スライドは元からある `&` を勝手に消しません。

**装飾音を入れる**（編集メニュー）: 選んだ音（主音）の前に短い装飾音を付けます。ピアノロールでは選んだ音、タブでは選んだ音か、選んでいなければカーソル位置の音に付けます。高さはタブでは主音の弦のフレット番号（例: 主音6フレットに `6 8`）、ピアノロールでは主音からの半音数（例: `-2` または `-1 +1`）を空白で区切って入力し、入力した数だけ装飾音ができます。装飾音の長さは l64・l48・l32・l24・l16 から選びます。MML には長さのない装飾音がないため、どちらかの長さを実際に短くします。**拍の上で**（既定）は装飾音が拍に合わせて鳴り、主音がその分遅れて始まります。主音が和音なら同じ奏者のほかのトラックの和音の音も一緒に遅れ、ほかの奏者はそのままです。**拍の前で**は主音がそのままの位置で鳴り、装飾音が前の音（または休符）の終わりを削って入ります。曲の最初の音や前の音が短すぎる場合は使えません。短くなる音はゲームの最短の長さ（l64）以上を残し、正確に書ける長さだけを使うので、長さの一覧にその長さで入れられる最大数（例: 8分音符に l64 なら7個）が表示され、それより多いと入れません。複数のトラックの和音の音を一緒に選ぶと、いちばん高い音に1回だけ付けます。**&でつなぐ**をオンにすると（既定はオフ）装飾音と主音を `&` でつなぎ、弾き直さずに高さだけが変わります（ハンマリング・プリングのような音）。&でつながれて弾き直さない音には付けません。

### 曲単位の編集

- **移調**（Alt+P）: 選択した音・このトラック・この楽譜・曲全体を、半音・オクターブ単位で移します。ゲームで音域の折り返しが起こる音の数を事前に知らせます。
- **音量の一括調整**（曲メニュー）: 選択した音（ピアノロール・タブ）・このトラック・この楽譜・曲全体のvを変えます。**一つの値に**はすべて同じvに、**上げ下げ**は今のvから±段階分（v0~v15で止まり、止まった音の数を知らせます）、**目標dB**はv15を0 dBとし、ゲームで測った音量の法則 dB = 40·log10(v/15) で最も近いvに合わせます（−6 dB ≈ v11）。ウィンドウで変わる音の数と今/変更後のvの範囲を前もって見せ、一度に変えたものは元に戻す一回で戻ります。ゲームは&の後ろのvを読まないので、&のつながりは最初の音のvで一緒に変わります。すべて選択（Ctrl+A）でトラックの音を全部選んでから使うこともできます。
- **トラックの分割・結合**: 選択した音を別のトラック（または新しいトラック）に移す、楽譜のトラックを1つに結合する、高さ順に分け直す。重なる音は移さずに残します。
- **小節を挿入・小節を削除**: 再生カーソルの位置に1小節を挿入または削除します（すべてのトラックとテンポも一緒に）。
- **トラックのロック**: 鍵アイコンをクリックすると、そのトラックはロール・タブ譜・エディタで編集できなくなります。選択・コピーはできます。移調は、ロックしたトラックが範囲に含まれると確認したうえで一緒に移します。ツールバーの選択ツール横の鍵（選択した音をドラッグして移動）は、トラックのロックとは別の機能です。

### 元に戻す

Ctrl+Z / Ctrl+Y（またはCtrl+Shift+Z）。曲全体のコマンドも一度に元に戻せます。

## 6. テンポ・拍子・マーカー

### イベントの行

ロールの上の2段にテンポ・拍子・マーカーが表示されます。最初からオンになっていて、表示 → **イベント** でオン・オフできます（選んだ状態は記憶されます）。

- 空いている所をダブルクリック（タッチは長押し）するか、ラベルを右クリックして追加・編集します。
- ラベルをドラッグして移動し、テンポのラベル上でホイールを回すと±1（Shiftで±10）、Delで削除します。
- キーボード: **Alt+B** でカーソル位置にテンポ、**Alt+M** でマーカー

### 拍子

曲 → 拍子を変更（ツールバーの **拍子** 欄も同じ）。再生カーソルのある小節から（なければ曲の最初から）変わります。タブ譜表示ではタブのカーソルがある小節から変わります。6/8・9/8・12/8は8分音符3つを1拍として表示します。

### タップテンポ

曲 → タップテンポ。原曲（または動画）を再生し、**小節の1拍目ごとにTキー** か［タップ］を押すと、停止したときにテンポが入ります。

- 1拍目が聞き取りにくい場合は **拍ごと** に切り替え、拍を数えるように押します。
- タップテンポのバーの **タップのばらつきを補正**（弱 30ms・標準 60ms・強 100ms）: 選んだ範囲内のずれたタップは手のぶれとみなし、1つのテンポにまとめます。テンポ命令の数とMMLの文字数も減ります。
- **続きから**: **続ける小節** に小節番号を入れて **続ける** を押すと、1小節前から再生し、その小節の1拍目に押したタップから続けて入力します。すでに入れたテンポはそのままで、入力後は最後にタップした小節が入ります。タップ中に再生位置を移したりループが先頭に戻ったりしても、それまでのタップを入力してから新しく始めます。
- テンポは整数なので丸めますが、その誤差は次の小節が受け持つため、小節が多くてもずれがたまりません。
- **ずれたタップ**（オフ・10%・20%（既定）・35%）: 入力後、前後の間隔とこれ以上違う所（押し忘れ・二度押し）を小節ボタンで知らせます。押すとその位置へ移動します。修正はしません。ジャズ・ルバート・速い曲は基準を上げるか切ってください。
- **波形の立ち上がりに合わせる**（オフ（既定）・±30ms・±60ms、原曲を読み込んだとき）: 入力後、楽譜でその拍に音が書かれているタップだけ、近くで原曲の音が始まる所を探して **合わせる** か確認します。押すまでは変わらず、合わせたものは1回の元に戻すで戻ります。
- 原曲バーの **小節線ドラッグ**: **前から順に**（既定）は波形帯で小節線をドラッグすると、前のテンポ位置からその小節線までのテンポを変え、後ろはずれます。**前後の小節だけ** は前後の小節線をそのままにして、両側の2小節のテンポだけ計算し直します（タップ入力後に1か所だけ直すとき）。ドラッグ中に変わるテンポが小節線の横に表示されます。

### テンポの整理

- **テンポを一括変更**: 曲全体のテンポを1つの値にそろえる（**すべてこの値に**）、すべて同じだけ上げ下げする（**± BPM**）、または何%かに変える（**%**）ことができます。ループ区間があればその中だけを変え、区間の後ろのテンポはそのままです。すべての楽譜のMMLテキストも一緒に直し、ゲームのテンポ範囲（t32〜255）を外れるときは事前に知らせます。Ctrl+Zを1回押せば元に戻ります。区間の境目にテンポを入れる場所がない楽譜（終わりの長さを変える所か、分けられないn音符だけ）は、その楽譜の文をそのままにして何番の楽譜かをお知らせします。
- **ずれた長さを探す**: 3MLE・MabiIccoは長さを整数ティックで数えるため、拍に合わせようと `r21`（= r32.）、`b19.`（= b16&b64）、l28 6つの後の `l27` のような値を使った楽譜があります。そこでは合いますが、BiNoteとゲームは正確な長さで演奏するので、その後ろが少しずつずれます。このウィンドウは、まとまりが16分や3連8分の位置をごくわずか（4分音符の1/96以下）外れ、ぴったりの位置に戻らない箇所だけを探し、そこにぴったり合うきれいな値（`r21 → r32.`、`d27 → d28`）を表示します。箇所ごとに **移動**、**元のまま聴く**、**直して聴く**、**直す** があり、下に **すべて直す** があります。勝手に直すことはなく、Ctrl+Z 1回で元に戻せます。ぴったり終わる連符（l20 5つなど）や3連符・スウィングには触れません。3MLE・MabiIccoファイルやMML@テキストを開いたときに該当箇所があれば、このウィンドウが自動で開きます。
- **テンポをすべて削除**: 曲の最初のテンポだけを残します。ループ区間があればその中だけ。
- **楽譜ごとにテンポを入れる**: テンポがない楽譜のMMLテキストに曲のテンポを書き込みます。（MMLで書き出す・楽譜集に分割は、これを使わなくても楽譜ごとに入れます）
- ゲームの範囲（t32〜t255）外のテンポも編集中は使え、MMLで書き出すときに変え方を案内します（下の9章）。

## 7. 音量（v）を整える

### 入力 v

ツールバーの **入力 v** は、新しく入力する音の音量です。「引き継ぎ」なら前の音の v に従います。音を選ぶと **選択した音の v** に変わり、まとめて変更できます。

### 音量レーン

ピアノロール下部の **音量 (v)** の帯が音量レーンです。閉じている場合は鍵盤帯側の角にある **音量 ▲** ボタンで開きます。バー1本が `&` でつないだ音のまとまり1つで、右側の数字が v の目盛りです。

- **ブラシ**: ドラッグで通ったバーの v をその高さに変えます。
- **直線**（またはShift+ドラッグ）: 押した位置から離した位置まで、v を直線で変えます。
- 音を選んでおくと、その音だけが変わります。
- **複数のトラックに一度に**: トラック一覧でCtrl+クリックして、一緒に変更するトラックを追加します。タッチではトラックを長押ししてメニューの **音量レーンに一緒に描く** を選ぶか、レーンの **音量 ▾**（複数なら **nトラック**）を押してチェックで追加・除外します。メロディトラックには描いた値をそのまま使い、ほかは上・中・下の位置ごとに決めた分だけ加えます。メロディの指定がなければ、楽譜の最初のトラックがメロディです。
- レーンは細く・大きく・閉じるを切り替えます。レーン上の取っ手をドラッグすると好きな高さに広がり（細い帯からドラッグしても構いません）、ダブルクリックで細く・大きくが切り替わります。設定 → 画面 → **音量レーン** でも高さを選べます。ペンで描くときは大きくしておくと楽です。

## 8. 原曲・動画を見ながら採譜する

### 原曲

ツールバーの ⋯ → **原曲…** で音源や動画を選ぶと、楽譜と一緒に再生します。ファイルはこの端末の中でだけ使い、サーバーへは送信しません。

- **ずれ（ms）**: 原曲が遅ければ＋。開始位置を合わせます。
- **原曲の音量**: 原曲の音量
- **波形**: ロールの小節番号の行の下に、原曲の波形を曲の時間に合わせて表示します。
  - 波形をクリックすると、その位置に移動します。
  - 波形上の **小節線をドラッグして** 原曲の拍に置くと、その小節がそこに来るようにテンポを変えます。
  - 波形の空いている所をドラッグすると、原曲が前後に動いてずれが変わります。
  - タブ譜表示でも変化の行の下に同じ波形の帯が出ます。クリックするとその位置に移動し、空いている所をドラッグして原曲を動かせます(数字パッドを開いている間は指板の場所を空けるため隠します)。

### 背景動画

ツールバーの ⋯ → **背景動画…**（ピアノロールで）。落ちてくるノーツの動画（ピアノ演奏動画など）をピアノロールの背景に敷き、動画を見ながら音を入力します。

- **鍵盤に合わせる**: 動画の左端・右端の鍵盤と鍵盤の上端線を決めると、ロールの鍵盤と重なります。**ハンドルで合わせる** をオンにすると、ロール上でドラッグして合わせます。
- **ロールを合わせる**: ロールを動画の鍵盤範囲に合わせて移動・拡大します。
- 濃さ、ずれ（秒）、時間の伸縮、動画の音を調整します。
- **画面を埋める**（初期はオン）: 鍵盤の上端線から動画の上端までがロールの見えている時間軸全体を覆うように、時間の伸縮を自動で決めます。オフにすると時間の伸縮を自分で決めます。
- **速さを合わせる**: 止めた動画で音が落ちる速さを測り、ロールの横の拡大を合わせます。再生すると動画の音とロールの音が鍵盤の線で同時に重なります。自動で測れないときは **手で測る** で1つの音の先端を2回押して測ります。測っている間は曲を編集できません（保存はできます）。Esc か **キャンセル** でやめます。曲の途中でテンポが変わる場合は、そこで合わせ直してください。
- **動画を再生**: 曲なしで動画だけを再生し、ロールが追従します。

### 一緒に使うと便利な機能

- **縦ロール**: 落ちてくるノーツの動画と向きを合わせます。設定 → 画面 → 再生中のロール → **連続スクロール**を選ぶと、動画がなくても落ちてくるノーツのように流れます。
- **再生中に鍵盤を光らせる**（既定でオン）: 再生中の音を鍵盤に表示します。表示メニューか 設定 → 再生 でオフにします。
- **選んだ音の鍵盤を光らせる**（既定は 選んでいる間ずっと）：押した音や選んだ音を鍵盤にトラックの色で表示します。**押している間だけ** は音や鍵盤を押している間だけ、**選んでいる間ずっと** は音が選ばれている間光ったままです。表示メニューか 設定 → 再生 で変更・オフにできます。
- 設定 → 再生 → **画面の同期補正**: 再生線が音より先に進むなら＋、遅れるなら−。iPad・Bluetoothイヤホンはさらに100〜300ms必要な場合があります。

## 9. MMLで書き出す

ファイル → **MMLで書き出す…** で出力結果を確認してコピーします。

### 「MMLで書き出す」ウィンドウ

構成リストのように楽譜の行の下にトラックの行があり、すべての楽譜のトラックにチェックボックスがあります。楽譜ごとの文字数・トラック数・折り返し・エラー・警告も表示します。

1. 1回の貼り付けに入れるトラックにチェックを入れます。**複数の楽譜から選んでもよく、一度に6トラックまで**選べます（6つ選ぶと残りのボックスはロックされます）。楽譜の行のチェックボックスは、その楽譜のトラックをまとめて選んだり外したりします。
2. **選んだトラックをコピー** をクリックすると、選んだトラックを曲のトラック順に `MML@…;` テキスト1つとしてコピーします。コピーされない場合は、ブラウザのクリップボード権限を確認してください。
3. ゲームで空の楽譜を開いて貼り付けます。1回の貼り付けに入るのは MML@ テキスト1つだけです。
4. コピーしたトラックには **コピー済み** が付き、まだコピーしていないトラックが次のコピー用にあらかじめチェックされます。たとえば楽譜1の1・2・3と楽譜2の1・3・6をコピーすると、次は楽譜1の4・5・6と楽譜2の2・4・5がチェックされています。最初に開いたときは最初の楽譜だけがチェックされます。

- 楽譜の行の左の矢印で楽譜をたたんだり広げたりします。最初はすべて広げた状態で、すべてのトラックをコピーした楽譜はコピーしたときにたたまれます。
- コピーしたあとトラックを直すと「コピー後に変更」になり、もう一度コピーするトラックとして扱います。コピー済みの表示はウィンドウを閉じて開き直しても残り、別の曲を開くと消えます。
- **テンポを入れる**（初期設定オン）：コピーするたびに曲の最初のテンポから入れます。ゲームは貼り付けたテキストだけを見て、テンポがなければ t120 で演奏します（ほかの貼り付けのテンポは引き継ぎません）。オフにするとテンポなしでコピーし、ゲームでは t120 で演奏されることを知らせます。
- 選んだ楽譜のテンポが互いに違う場合（元のテキストに違う t が書かれた楽譜を混ぜて選んだ場合）は、入れるテンポを選びます。選んだテンポはウィンドウを閉じるまで次のコピーでも使います。BiNote は曲にテンポマップが1つなので、通常は表示されません。
- オルゴール・蓄音機の楽譜1つをまるごと選ぶと、これまでどおり残りのトラックを鳴らないチャンネルとして一緒に入れ、曲の長さとテンポをそろえます。ほかの楽譜のトラックと混ぜてオルゴールのトラックが最初の3チャンネルの外に置かれると、鳴らないことを知らせます。
- 文字数が上限を超えるトラックは赤く表示され、ボタンが「選んだトラックをコピー（超過）」に変わります。
- 出力用のMMLは文字数を減らして新しく書きます。エディタのテキストは変更しません。選んだトラックのうち一番長いトラックに合わせて末尾の休符を保ちます。
- テンポの位置が選んだすべてのトラックで音の途中にある場合は、音を切り捨てないよう、すぐ後の音の境目に書いてお知らせします。

### テンポがゲームの範囲外のとき

t255より速い場合はその区間の音長を短くしてテンポを下げる方法を、t32より遅い場合は音長を長くしてテンポを上げる方法を案内します。速さは同じです。

### 文字数が上限を超えるとき

順番に試してください。

1. **音符の再配分**: 曲メニュー → 音符の再配分（「MMLで書き出す」ウィンドウの上限を超えた行からも開けます）は、文字数が上限を超えるトラック（送るトラック）の音を、同じ楽譜・同じ楽器のトラック（受け取るトラック）が休んでいる小節へ **区間ごと** 移します。受け取るトラックをチェックで選ぶと **空きを探す** に移せる小節区間が並びます（受け取るトラックが空の区間が先、受け取るトラックに音が少しある区間はその音を送るトラックと入れ替え）。区間を自分でチェックするか **超えた分だけ自動で選ぶ** を押すと、チェックを変えるたびに移したあとの文字数が表に出ます。小節線をまたぐ音・&のまとまりがある所では切らず、音を外さず、音も同じです（ゲーム出力を読み直して確認）。受け取るトラックが足りなければ **空のトラックを追加** で同じ楽譜にトラックを足せます。トラックがすでに埋まっている楽譜では、トラックを足すと同じ楽器の楽譜がもう1つでき（ゲームで一緒に弾く人が1人増える）、1人で弾くなら楽譜集に分割を使ってください。
2. **文字数を減らす**: 音の高さ・開始位置・長さは保ったまま、すべてのトラックのMMLをより短く書き直します。自分で書いたスペース・改行・コメントは失われます。短くすると音が消える場合は、変更せずにお知らせします。
3. **楽譜集に分割**: すべてのトラックを同じ位置で切り、複数の冊に分けます。
   - **音符を再配分してから分割**（初期設定オン）：分割の前に同じ楽器のトラック間で音を移し、チャンネルの長さをそろえます。すべてのチャンネルが上限内に収まれば分割せず、冊数が減る場合は移した結果で分割します。編集中の曲はそのままで、「曲にも適用」を押すと曲にも移します（Ctrl+Zで元に戻せます）。オフにすると楽譜集への分割だけを行い、音を移すと減る場合は「N冊 → M冊」の案内だけが出ます。
   - **じっくり分割**（初期設定オフ）：冊の終わりごとに上限近くの位置をさらにいくつもたどり、冊数がより少ない分け方を探します。時間がかかるため、分割中は下に段階と進行バーが表示されます。短い曲はこのオプションがなくても最も少ない冊数を正確に求めます。
   - 全員が休んでいる位置を優先して選びます。
   - 冊ごとにオクターブ・音量・テンポを書き直します。
   - 次の冊が遅れて始まる分（約1秒）だけ前の冊を早く終わらせ、拍を合わせます。この補正区間に音があると、音が短くなったり外れたりすることがあります。結果の「末尾で途切れる音」と長さの警告を見て、冊の境目の前後を聞いてから使ってください。

音符の再配分・和音の統合・文字数を減らすは、ウィンドウで変更前後の文字数を見てから適用します。適用した変更はCtrl+Zで元に戻せます。楽譜集に分割は元の曲を変えず、冊ごとの出力結果だけを作ります。各冊で楽譜ごとのコピーボタンを使ってください。

### 和音の統合

曲メニュー → **和音の統合** は、同じ楽譜・同じ楽器のトラックのまとまりで、トラックごとに **残す / 空にする / 外す** を選ぶと、空にするトラックの音を残すトラックがその時間に休んでいる所へ移し、空になったトラックを削除します（楽譜が2つ以上あり、削除すると後ろのトラックが前の楽譜に詰められる場合は空のトラックとして残します）。MIDI を読み込んで音がまばらなトラックができたときや、トラック数を減らしたいときに使います。休みが足りなければ **段階** で決めます。**1段階**（既定）は音を外さず、そのトラックをそのままにします。**2段階** はその瞬間ほかのトラックで同じ音（オクターブ含む）が鳴っている重なった音だけ外します。**3段階** は場所のない音を外し、いちばん上・いちばん下の音はなるべく守って内側の音から外します。**優先** トラック（メロディに設定したトラックが最初に選ばれます）の音はどの段階でも外さず、場所が足りなければほかのトラックの音を代わりに外します（内声の旋律を守る）。外す音は数と位置（小節・拍・高さ）をすべて表示し、帯に赤く示し、適用ボタンにも外す音の数が出ます。外す音以外は音が同じか、ゲーム出力を読み直して確かめます。

- ほかのトラックと重なる音は移す先がないので、そのまま残ります。
- 受け取るトラックの前後の音と完全5度より離れていると入れません（旋律が跳ねないように）。& でつながってしまう位置にも入れません。
- 受け取るトラックが文字数の上限を新しく超えるときは移しません。トラックを空にできず一部だけ移すときは、文字数の合計が増えるなら移しません。そのため v が違う弱い断片は残ることがあります。
- ロックしたトラックや、ミュート・ソロ・チャンネル音量が違うトラックどうしでは移しません。
- プレビューでトラックごとの文字数の前後を見てから適用し、Ctrl+Z で元に戻せます。

設定 → **和音** で、MIDI を読み込むときに和音を統合する（既定でオン）と、楽譜帳に分ける前に音符を再配分する（既定でオン）を決めます。

### 曲のチェック

ステータスバーの **チェック N** で、曲全体の問題を確認します。

- 文字数の超過、テンポ・音長・音量の範囲外
- 楽器の音域外のため **音域の折り返し** が起こる音（ロールではグレーで表示されます）
- ゲームのサンプルが終わり、**後半が鳴らない長い音**（ゲームの音はループせず1回鳴って終わります）
- 1人の演奏者のトラック数の超過、同じ演奏者のトラック同士での同じ音の重なり
- & でつないだ2つの音が音色の境目をまたぐ

## 10. MIDIの読み込み

楽譜を開くで .mid を選ぶと、**MIDIの読み込み** ウィンドウが開きます。

1. **MIDIパート** ごとに音数・音域・同時発音を見て、どの **演奏者** に割り当てるかを選びます。除外・打楽器へも選べます。合う楽器がない場合は、近い楽器を選んでおきます。
2. 演奏者ごとに **同時発音数** を決めます。曲全体の合計が上に表示されます。
3. あふれる位置で外す順序を選びます。
   - 中間から（両端を維持、標準）・下から・上から・弱い音から・短い音から
   - 優先して音を減らすパート（両手半々・右手の和音から・左手の和音から）、メロディを保護
4. **拍子グリッド**（自動または手動）と **3連符を残す**
5. **和音の統合**（既定でオン）: 和音が一瞬増えた所の音だけが別のトラックに残らないよう、休んでいる同じ楽器のトラックへ移します（9章の和音の統合）。空のチャンネルを埋めるより先に行います。
6. **空のチャンネルを埋める**: 圧縮で外れた和音の音を、休んでいるチャンネルに入れ直します。文字数の上限を超えると、入れ直した音から外します。
7. 下のまとめ（外した音・入れ直した音・統合した音・最も長いチャンネルの文字数）を見て **読み込む**。

MIDIの読み込みは、元のデータをそのまま移すものではありません。同時発音数を超える音は外れ、音長は拍子グリッドに合わせて整えられます。読み込んだ後に聞いてみて、必要な所を直してください。

## 11. 保存とファイル形式

| 形式 | メニュー | 用途 |
|---|---|---|
| **プロジェクト .mme** | プロジェクトとして保存（Ctrl+S） | **作業の保管と別の端末への移動におすすめ。** 分数の位置・トラック構成・編集画面の状態が残ります（以前の .mmlce も開けます） |
| 3MLE .mml | 3MLE形式で保存（Ctrl+Alt+S） | 3MLEで開く。既定はCP949で、ない文字は ? になるため、必要ならUTF-8で保存 |
| MabiIcco .mmi | MabiIcco形式で保存（Ctrl+Shift+S） | MabiIccoで開く。グリッド（4分音符96分割）に合わない音はお知らせします |
| MIDI .mid | MIDIで保存 | DAWなど。楽器はGM番号で、バスドラム・シンバルはドラムチャンネルに。番号だけで書かれた追加サウンドパックの楽器（#42.3 など）は、読み込んだパックで見つかった実際の楽器のGM番号で保存し、音の高さは書かれたままにします。高さの異なる音を `&` でつないだ所は、MIDIでは別々に弾く音として保存されます |
| WAV | WAVで保存 | 今のサウンドパックで曲全体を音声ファイルに（ミュート・ソロは聞こえるとおり）。サウンドパックが必要です |
| MML@ テキスト | MMLで書き出す | ゲームに貼り付け |

### 保存先

設定 → **保存**で決めます。

- PCのChrome・Edge: 既定は**保存のたびにフォルダーと名前を選ぶ**です。ファイルを開くときと同じように保存ダイアログが開き、フォルダーとファイル名を選びます。次の保存は前回のフォルダーから開きます。WAVはでき上がったあとに出る**保存**ボタンを押して選びます。
- この方式でプロジェクト(.mme)として一度保存すると(または**楽譜を開く**でプロジェクトを開くと)、次の保存(Ctrl+S)はダイアログなしで同じファイルに直接書き込みます。開いたファイルは最初の保存で一度だけ書き込みの許可を求められます。新しいファイルに保存するにはファイル → **名前を付けて保存…**を選びます(ショートカットはキー設定で決められます)。ファイルが移動・削除されて書き込めないときは保存ダイアログがもう一度開きます。iPad・Safariではブラウザーの制限により毎回共有メニュー・ダウンロードで保存します。
- PCのChrome・Edge: **決めたフォルダーにそのまま保存**を選んでフォルダーを決めると、確認せずに保存するファイルはすべてそこに入ります。同じ名前のファイルは上書きされ(名前のない新しい楽譜は上書きせず `new project 2` のような新しい名前で保存し、次からその名前を使います)、ブラウザーを開き直すと最初の保存でフォルダーの使用をもう一度許可するよう求められることがあります。**ダウンロードフォルダー**を選ぶとブラウザーのダウンロードで保存します。
- iPad・iPhone: **共有メニューで保存**（既定でオン）なら、保存するときに共有メニューが開きます。「"ファイル"に保存」でフォルダーを選んだり、Google ドライブなどのアプリへ直接送ったりできます。
- そのほかのブラウザー（Firefoxなど）はダウンロードフォルダーに保存します。

プロジェクト（.mme）に含まれるものと含まれないもの:

- 含まれる: 楽譜、編集画面の状態、原曲・背景動画の **ファイル名と調整値**（ずれ・鍵盤の位置など）
- 含まれない: サウンドパック、原曲の音源・動画の **ファイル自体**、テーマ・言語などのアプリ設定

別の端末で続けるには、サウンドパックと原曲・動画ファイルを別途用意してください。同じ名前の原曲・動画を選び直すと、保存しておいた調整値を読み込みます。

### 自動保存

編集中の曲はこのブラウザに自動で残ります（最新10件）。再読み込み・タブを閉じた後、最初の画面かファイル → **以前の作業を復元** から開きます。

> 自動保存は **一時的な復旧用** です。ブラウザのデータを消去したり容量が不足したりすると、消えることがあります。長く残したい曲は必ず **.mmeで保存** してください。iPadではファイルアプリに置くことをおすすめします。

### 新しいバージョン

新しいバージョンが出ると「新しいバージョンの準備ができました」というバーが表示されます。**再読み込み** をクリックすると、編集中の曲の自動保存が終わるのを待ってから新しいバージョンに切り替わります。保存に失敗した場合は切り替えずにお知らせするので、その際はプロジェクト（.mme）として保存してから、もう一度クリックしてください。大切な作業は、クリックする前に .mme で保存しておくとより安全です。案内を閉じて作業を続けてもかまいません。

アプリは開くたびに新しいバージョンを確認し、長く開いたままの場合はウィンドウに戻ったときに1時間に1回まで再確認します。すぐに確認するには、上部バーの **?** → **アップデートを確認** を押してください。

上部バーの ⚙。

| タブ | 項目 |

| ショートカット | ショートカット設定を開く（キー設定: BiNote標準 / MabiIcco互換、キーの変更） |

**実験室**は正式版の前に試せる機能です。設定 → 実験室でオンにすると上部バーに**実験室**メニューが出て、オフにするとメニューが隠れるだけで曲はそのままです。結果は普通のMML(v・音の高さ)なので、ゲームや他のアプリでもそのまま鳴ります。実験室の印(元に戻す・タブ表示に使うもの)はBiNoteのプロジェクトファイル(.mme)にだけ保存されます。ピアノロールでは選んだ音、タブでは選んだ音(なければカーソルの音)に使います。

- **ゴーストノート**: 選んだ音を周りの音よりN段階小さく弾きます(初期は4段階)。曲ごとに音量が違うので、決まったvではなく同じトラックで一番近い普通の音のvを基準にします(周りがv9ならv5)。タブではゴーストノートの数字が薄く見えます。
- **ハーモニクス**: **ナチュラル**はタブで音のあるフレットから計算します(12フレット = 開放弦 +12、7フレット = +19、5フレット = +24)。タブには`<12>`のように表示されます。**人工**は押さえた音の1オクターブ上で、`3<15>`のように表示されます(ピアノロールでは人工のみ)。音量はN段階小さくできます(初期は2段階)。
- ウィンドウの**実験室の印を外す**を押すと、選んだ音のうちゴーストノート・ハーモニクスにした音が元のv・高さに戻ります。
- **響きを入れる**: ゲームには響きのエフェクトがないので音符でまねます。長い音の後半を同じ高さの小さな音に分け、少しずつ弱く鳴らし直します。vの順はv15で弾いた音が基準(初期は 6 3 2 1)で、ほかのvの音は比例して下げます(v9なら 4 2 1 1)。かけらの長さ(初期は8分)と、そのまま残す頭の部分(初期は4分)を選びます。選んだ音かトラック全体のうち、この長さ以上の音(初期は2分音符)に入れ、**後ろに休符がある音だけ**でフレーズの終わりだけにできます。**スタッカートの空きを埋める**をオンにすると、短い音の後の休符に同じ音を小さく(初期はv4)入れます。かけらは&でつなぎません(ゲームは&の後のvを無視します)。トラックは増えませんが文字数が増えるので、ウィンドウの文字数を確かめてください。
- **響きスタンプ**: ピアノロールの道具バーの響きスタンプ(実験室をオンにすると出ます)をオンにして音をクリックすると、その位置から分けます。タブでは 実験室 → **カーソル位置に響き** でカーソルの音に入れます。音の頭をクリックすると頭を残して末尾から置きます。設定は 響きを入れる の尾の設定を使います。
- 響きの方法はマビッコ楽譜作成ガイドの響き効果の項目を参考にしました。

一番下に、バージョン情報とガイドブック・**BiNote について** へのリンクがあります。

上部バーの設定（⚙）横の **?** メニューには、ガイドブック、ショートカット、アップデートを確認、BiNote について があります。**BiNote について** の画面では、バージョンの確認とアップデートの確認ができ、ソースコード・ライセンス・問題の報告へのリンクを開けます。このガイドブックはステータスバーのヘルプからも開けます。

## 15. よくある質問

**音が出ません。**
サウンドパックを追加したか、ステータスバーを確認してください。「サウンドパックで見つからなかった楽器」が出たら、その楽器が入ったパックを追加してください。別のパックの音が優先される場合は、設定のサウンドパック一覧で▲▼を使って順序を変えます。iPhone・iPadは消音スイッチも確認してください。

**ゲームに貼り付けたらエラーになります。**
「MMLで書き出す」ウィンドウでエラー・警告の数を見て、ステータスバーのチェックで位置を探して直します。1回の貼り付けに MML@ テキストを1つだけ入れたかも確認してください。

**試聴とゲームの音が違います。**
試聴は、追加したサウンドパックの音色とBiNoteの再生方式で音を鳴らします。パックの種類や楽器の対応によって、ゲームの音と異なる場合があります。音域の折り返し（グレー）とサンプルが終わる長い音は、チェック結果で確認してください。

**文字数がずっと上限を超えます。**
音符の再配分 → 文字数を減らす → 楽譜集に分割の順で試してください（9章）。

**作業が消えました。**
ファイル → 以前の作業を復元を確認してください。iPad・iPhoneは、ホーム画面のアプリとSafariのタブの自動保存が互いに見えません。サイトのアドレスが異なると（例: テスト用アドレスと正式なアドレス）保存領域も異なるため、自動保存は引き継がれません。長く残したい曲は .mme で保存してください。

**3MLE形式で保存したら文字が ? になりました。**
3MLEの既定のエンコーディング（CP949）にない文字です。UTF-8で保存するか、名前を変えてください。

**MabiIccoで開いたらエラーになります。**
MabiIccoのグリッド（4分音符96分割）に合わない音があると、保存時にお知らせします。その音の長さをグリッドに合わせてください。

## 16. 問題・翻訳の報告

設定の一番下の **問題・翻訳の報告**、またはリポジトリの [Issue](https://github.com/EarlGreyPie/BiNote/issues/new/choose) から送ってください。

- バージョン情報（設定の一番下の「BiNote v…・コミット …」）と端末・ブラウザを一緒に書いていただけると助かります。
- 曲が必要な場合は、MML@ テキストか短い例で十分です。**サウンドパックのファイルは添付しないでください。**
- 翻訳の誤りや不自然な表現は「翻訳の報告」を選んでください。ゲーム内の公式表記を教えていただけると特に助かります。
