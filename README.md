# BiNote (바이노트)

마비노기 모바일 MML 악보 편집기. 
화음별 트랙으로 MML을 쓰고, 여러 사운드팩으로 들어 보고, 
게임 한도(글자 수·화음 수)에 맞게 최적화·분할하는 키보드 중심 편집기입니다.
악보용 확장자는 .mme 입니다.

- 형태: TypeScript 웹 앱 + PWA (Windows, iPad, 안드로이드). 필요하면 나중에 Tauri로 감쌉니다.
- 만든 사람: EarlGreyPie

> 넥슨·마비노기 모바일과 관계없는 **비공식 개인 팬 제작 도구**입니다. 게임 이름·악기 이름·소리의 권리는 넥슨에 있습니다.

## 쓰기 전에

- **사운드팩**: 악보 편집은 사운드팩 없이도 됩니다. 소리를 들으려면 마비노기 사운드팩(.dls)을 따로 구해 앱에 올려 주세요. 사운드팩은 넥슨 자산이라 BiNote에 들어 있지 않고, 이 저장소에서도 배포하지 않습니다.
- **저장**: 곡·사운드팩 파일을 서버에 올리지 않습니다. 이 기기의 브라우저 안에만 저장됩니다. 앱에 분석·광고 스크립트를 넣지 않았습니다. 브라우저 정리로 지워질 수 있으니 오래 둘 곡은 프로젝트(.mme) 파일로 저장해 두세요.
- **언어**: 한국어·English·日本語·繁體中文·简体中文. 한국어 외 번역은 사람이 다 검수하지 못했고, 일본·대만 서버에서 아직 공식 표기를 찾지 못한 악기 이름 등은 임시 번역입니다. 틀리거나 어색한 문구는 [이슈](../../issues/new/choose)의 "번역 신고"로 알려 주세요. 게임 안 공식 표기를 알려 주시면 특히 도움이 됩니다.

## 사용법

[가이드북](docs/가이드북.md)에 화면, 음 넣기, 게임에 넣기, 저장 형식, 단축키를 정리해 두었습니다.

다른 언어: [English](docs/guide/en.md) · [日本語](docs/guide/ja.md) · [繁體中文](docs/guide/zh-TW.md) · [简体中文](docs/guide/zh-Hans.md)

## 개발

```sh
pnpm install
pnpm check      # 타입 검사 + 테스트
pnpm dev        # 편집기 앱 (http://localhost:5173)
pnpm build      # 배포용 빌드 (apps/web/dist)

# 저장소 밖의 실제 곡 파일로 읽기·쓰기 확인 (.mml/.mmi가 든 폴더)
MMLCE_SAMPLES=/경로/samples pnpm test
```

## 구조

| 경로 | 내용 |
| --- | --- |
| `packages/core` | 분수 시간, 악보 모델, 게임 프로필, 실행 취소 |
| `packages/mml` | 파서, 출력기, 템포 채널 배치, 검사기, 원문 편집 명령, 글자 수 최적화, 화음 분산, 악보책 나누기, 트랙 나누기·합치기, 음 복사·붙여넣기 |
| `packages/audio` | 재생 일정, 사운드팩 등록부(여러 팩 동시), 오프라인 렌더, 실시간 예약 재생 |
| `packages/midi` | MIDI 가져오기(분석·양자화·6/12 화음 압축), MIDI 저장 |
| `packages/fileio` | 3MLE .mml(CP949), 마비꼬 .mmi, 게임 MML@ 글, BiNote 프로젝트(.mme) 읽기·쓰기 |
| `packages/i18n` | 화면 문구·진단 메시지 (KO 원본, EN·JA·zh-TW·zh-Hans) |
| `apps/web` | Svelte 편집기(PWA): 악보 열기·저장, 작업 자동 보존·복구, 트랙별 MML 편집(검사 밑줄, 실행 취소), 피아노롤(가로·세로)·타브 보기, MIDI 건반 입력, 여러 사운드팩으로 재생, 원곡 동시 재생·배경 영상 |

## 파일

- **프로젝트(.mme)**: BiNote 전용. 분수 위치·트랙 구조·편집 화면 상태를 그대로 남기는 UTF-8 JSON입니다. 작업을 오래 보관할 때는 이것으로 저장합니다.
- **자동 보존**: 고치던 곡은 이 브라우저(IndexedDB)에 최근 10개까지 저절로 남고, 새로고침이나 탭을 닫은 뒤 첫 화면에서 되살릴 수 있습니다. 브라우저 정리나 기기에 따라 지워질 수 있는 임시 복구용입니다.
- **호환 형식**: 3MLE .mml, 마비꼬 .mmi, MIDI, 게임 붙여넣기용 MML@ 글.

## 지켜야 할 것

- 3MLE, 마비꼬(mmlTools) 코드는 쓰지 않습니다. 기능과 동작만 참고합니다.
- 사운드팩(DLS)은 넥슨 자산이므로 저장소에 넣거나 앱에 포함하지 않습니다. 사용자가 직접 불러옵니다.
