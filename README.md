# MMLCE

마비노기 모바일 악보(MML) 편집기입니다. 화음별 트랙으로 MML을 쓰고, 사운드팩으로 들어 보고, 게임 한도(글자 수·화음 수)에 맞게 줄이고 악보책으로 나눕니다.

> 지금은 공개 준비 중입니다. 소스와 웹 주소는 준비가 끝나면 이 저장소에 올립니다.

## 할 수 있는 것

- 3MLE(.mml), 마비꼬(.mmi), 게임용 `MML@` 글, MIDI 열기·저장
- 피아노롤(가로·세로)과 트랙별 MML 편집, 이음줄(&)·슬라이딩 입력, MIDI 건반 입력
- 직접 불러온 사운드팩(.dls·.sf2)으로 재생, 반복 구간, 원곡과 맞춰 듣기
- 글자 수 줄이기, 화음 분산, 악보책 나누기(권 사이 지연까지 맞춤), 오르골 3화음 나누기
- 인게임 실측값(음역·샘플 길이·이음줄 동작·화음 감쇠)에 맞춘 재생과 검사
- 웹 앱 + PWA (Windows, macOS, iPad, 안드로이드). MIDI 건반은 Chrome·Edge에서 됩니다

## 알아 둘 것

- 사운드팩과 악기 소리 등 게임 자산의 권리는 넥슨에 있으며, MMLCE에는 들어 있지 않습니다. 사용자가 직접 불러옵니다.
- 3MLE·마비꼬는 동작만 참고했고 코드는 쓰지 않았습니다.
