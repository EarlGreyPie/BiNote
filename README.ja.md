# BiNote (バイノート)

[한국어](README.md) · [English](README.en.md) · 日本語 · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-Hans.md)

BiNoteは、マビノギモバイル用のMML楽譜エディタです。ピアノロールとタブ譜でMMLを作成できます。
和音ごとにトラックを分けて書き、複数のサウンドパックで試聴し、ゲームの制限(文字数・和音数)に合わせて最適化・分割できます。

**アプリを開く: [binote.pages.dev](https://binote.pages.dev)**

**マビノギ**(PC版)用の楽譜とは、一部で**互換性の問題**が起きることがあります。下の「互換性について」をご覧ください。

- 形式: TypeScript製のWebアプリ + PWA (Windows、iPad、Android)
- 入力: ピアノロール、タブ譜
- 操作: キーボード、マウス、タッチ
- 制作: EarlGreyPie

> ネクソンおよびマビノギモバイルとは関係のない、**非公式の個人ファン制作ツール**です。ゲーム名・楽器名・音の権利はネクソンにあります。

## 使う前に

- **サウンドパック**: 楽譜の編集はサウンドパックがなくてもできます。音を聴くには、マビノギのサウンドパック(.dls)をご自身で用意してアプリに読み込んでください。サウンドパックはネクソンの資産のため、BiNoteには含まれておらず、このリポジトリでも配布していません。
- **保存**: 曲やサウンドパックのファイルをサーバーに送信しません。お使いの端末のブラウザ内にのみ保存されます。アプリに解析・広告スクリプトは入っていません。ブラウザのデータ削除で消えることがあるため、長く残したい曲はプロジェクト(.mme)ファイルとして保存してください。
- **言語**: 한국어・English・日本語・繁體中文・简体中文。
- **翻訳**: 韓国語以外の翻訳は、人がすべてを確認できていません。日本・台湾サーバーでの正式名称が分からなかった楽器名などは仮の翻訳です。誤りや不自然な表現は、[Issue](../../issues/new/choose)の「翻訳の報告」からお知らせください。ゲーム内の正式名称を教えていただけると、とても助かります。

## ベータプログラム

ベータのアドレス: [beta.binote.pages.dev](https://beta.binote.pages.dev)

BiNote は新機能を試すために、ベータページを別に運営しています。
新しく追加される機能は、ベータページで一定期間試してから正式ページに反映されます。

- ベータページには試験中の機能が入っているため、不安定なことがあります。大切な曲はプロジェクト（.mme）ファイルで保存しておいてください。
- ベータページと正式ページは保存場所が別です。曲とサウンドパックはお互いに見えないので、移すときはファイルで保存してからもう一方で開き直してください。
- ベータページで問題を見つけたら、[ベータの不具合報告](../../issues/new?template=beta.yml)でお知らせください。開発の大きな助けになります。

## お問い合わせ・貢献

- 不具合や翻訳の誤りは[Issue](../../issues/new/choose)でお知らせください。設定の一番下にあるバージョン情報も書いていただけると助かります。サウンドパックのファイルは添付しないでください。

## ファイル

- **プロジェクト(.mme)**: BiNote専用の形式です。作業を残すときはこの形式で保存します。
- **対応形式**: 3MLE .mml、MabiIcco .mmi、MIDI、ゲームに貼り付ける `MML@` テキスト。

## 互換性について

一部の楽譜(連符)は、マビノギ(PC版)で正しく再現されないことがあります。マビノギ(PC版)用の複雑な楽譜には、BiNoteの使用をおすすめしません。

> マビノギは整数のティックで長さを計算します。マビノギモバイルは分数の長さも受け付け、BiNoteは分数を基準に設計されています。そのため、整数ティックを使うツールやゲームでは、一部のMMLでエラーが起きることがあります。

- 企画、ゲーム内の実測、QA: EarlGreyPie
- コード作成: Claude

- ゲームの動作は、実際に録音して測定した値を基準にしています。測定資料: [楽器の音色境界 実測レポート](docs/measure/timbre-boundaries.ja.md)

**既存ツールとの関係**

- 既存のエディタである3MLE、MabiIcco(mmlTools)のコードは使用していません。動作と機能のみを開発時の参考にしました。
- 既存のツールとは長さの計算方法が異なります。互換性はできるだけ保つようにしましたが、完全ではありません。問題が見つかった場合は、GitHubのIssueにご登録ください。
